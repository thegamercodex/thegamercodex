## Qué es

Tenno Tools es un tracker web del estado del mundo de Warframe con foco en notificaciones. Cubre alertas, invasiones, sorties y actividades en curso en las cuatro plataformas (PC, PlayStation, Xbox, Switch), y permite configurar notificaciones de browser para avisarte cuando aparece algo específico. Es gratuito.

Es una alternativa más enfocada en alertas activas que el dashboard panorámico de Warframe Hub, aunque ambos beben de los mismos datos de estado del mundo.

## Qué problema resuelve

Mucho contenido de Warframe es rotativo y con tiempo límite: una invasión con recompensa específica, una alerta puntual, la sortie del día. Si no estás mirando, se pasa. Un dashboard como Warframe Hub te muestra el estado, pero requiere que lo abras y lo revises.

Tenno Tools resuelve eso con notificaciones: configuras qué te interesa (cierto recurso de invasión, cierto tipo de fissure) y el sitio te avisa cuando aparece, sin que tengas que estar chequeando. Convierte el seguimiento pasivo en alertas activas.

## Diferenciación

Frente a Warframe Hub, la diferencia es el enfoque. Hub es el dashboard completo para mirar todo el estado del mundo de un vistazo; Tenno Tools prioriza las notificaciones para que no te pierdas recompensas time-gated. Hub para revisar el panorama, Tenno Tools para que te avise solo.

Frente a Cephalon Navis (app de Android nativa), Tenno Tools es web con notificaciones de browser; Navis es la app mobile con push notifications.

## Para qué la usa la gente

**Recibir alertas de invasiones**: avisa cuando aparece una invasión con la recompensa que buscas.

**Seguir la sortie y actividades diarias**: el estado de las tareas rotativas.

**Notificaciones multiplataforma**: timers para PC y consolas.

**No perder contenido time-gated**: el caso de uso central — que el sitio te avise en lugar de tener que revisar.

## Para quién NO es esta herramienta

Si prefieres un dashboard completo para mirar todo de un vistazo (incluyendo ciclos día/noche con detalle), Warframe Hub es más panorámico.

Si quieres notificaciones en el celular sin tener el browser abierto, Cephalon Navis (Android) encaja mejor.

## Cómo se usa en la práctica

1. Entras a `tenno.tools`.
2. Eliges tu plataforma.
3. Configuras qué notificaciones quieres recibir (tipos de alerta, recompensas).
4. Permites notificaciones de browser.
5. El sitio te avisa cuando aparece lo que configuraste.

## Limitaciones honestas

**Solo en inglés**: la interfaz no está traducida.

**Notificaciones atadas al browser**: requiere tener el navegador disponible para las alertas; para push real en mobile, Navis.

**Menos panorámico que Hub**: su fuerte son las alertas, no mostrar todo el estado del mundo con el detalle de Hub.

## Cómo empezar

Entra a `tenno.tools`, elige tu plataforma y configura las notificaciones de lo que te interesa. Permite las notificaciones del navegador y déjalo correr. A partir de ahí, te avisa cuando aparece el contenido rotativo que configuraste.
