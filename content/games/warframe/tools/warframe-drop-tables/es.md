## Qué es

Official Drop Tables es el listado de probabilidades de drop generado automáticamente por Digital Extremes. Cubre misiones, relics, bounties, caches y enemigos: para cada fuente, qué puede dropear y con qué probabilidad. Es oficial y gratuito, publicado en `warframe.com/droptables`.

Es la fuente que todas las herramientas de drops de terceros parsean para construir sus interfaces. El dato sale de acá; lo que cambia es la presentación.

## Qué problema resuelve

Warframe no muestra drop rates dentro del juego. Saber la probabilidad exacta de que un boss suelte cierta parte, o qué tira un relic, requiere consultar esta tabla. Como es la fuente oficial, no hay ambigüedad: es el número con el que el juego efectivamente calcula.

Resuelve la necesidad de certeza: cuando una wiki o herramienta de terceros tiene un dato dudoso o desactualizado, los drop tables oficiales son el árbitro final.

## Diferenciación

Frente a WFCD Drop Data (el mirror buscable), los drop tables oficiales son la fuente cruda. Drop Data parsea exactamente estos números y los presenta con búsqueda y navegación amigable. Para una consulta rápida, Drop Data; para la verdad de tierra sin intermediarios, los drop tables oficiales.

Frente a la wiki, los drop tables son números crudos sin explicación ni contexto.

## Para qué la usa la gente

**Verificar drop rates exactos**: la probabilidad oficial de cualquier drop.

**Resolver discrepancias**: cuando una herramienta de terceros tiene data dudosa, esta es el árbitro.

**Consultar contenido recién lanzado**: tras un patch, los drop tables oficiales se actualizan en la fuente antes que algunos mirrors.

## Para quién NO es esta herramienta

Si quieres buscar "dónde dropea X" de forma rápida y amigable, WFCD Drop Data hace eso mucho mejor — los drop tables oficiales son una lista enorme y difícil de navegar.

Si buscas explicación de mecánicas o contexto, la wiki es el lugar.

## Cómo se usa en la práctica

1. Entras a `warframe.com/droptables`.
2. Usas Ctrl+F del navegador para buscar la fuente o el item (no hay buscador propio cómodo).
3. Lees la probabilidad de drop listada.
4. Para una experiencia más amigable, pasas la misma consulta a WFCD Drop Data.

## Limitaciones honestas

**Cruda y difícil de navegar**: es una página enorme sin un buscador cómodo; la consulta real se hace mejor desde el mirror buscable.

**Solo en inglés**: el contenido está en inglés.

**Sin contexto**: son números, no explicaciones. Para entender mecánicas, la wiki.

## Cómo empezar

Entra a `warframe.com/droptables` cuando necesites la probabilidad oficial de un drop. Para uso diario, sin embargo, la mayoría consulta WFCD Drop Data —que parsea estos mismos números— y reserva los drop tables oficiales para verificar un dato cuando hay duda.
