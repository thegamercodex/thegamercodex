## What it is

Profit-Taker Analytics is an open-source desktop tool with a GUI that parses your game logs to time and break down Profit-Taker —the Orb Vallis Orb boss— runs phase by phase. Speedrunners and squad leaders use it to optimize the fight: see how long each phase takes, where time is lost and how to improve.

It's developed by Basiiii on GitHub. It's free. It's a niche tool with a slow development cadence (the most recent commit is from mid-2025), but it's not abandoned — it's the most specialized tool in the catalog.

## What problem it solves

Profit-Taker is a recurring farming fight for platinum, credits and resources. Those who run it repeatedly want to do it fast, but the game gives you no breakdown of how long each phase took or where time went. Without metrics, optimizing is guesswork.

Profit-Taker Analytics solves that by parsing your logs and showing you the time for each phase of the fight. With that data you identify the bottleneck —a certain damage phase, a certain transition— and adjust your loadout or execution to cut the total time.

## Differentiation

It's the only tool in the catalog dedicated to Profit-Taker run analysis. AlecaFrame and other overlays cover economy and inventory, but don't break the fight down phase by phase like this. For the specific case of optimizing Profit-Taker, it has no direct competitor — it's specialized and standalone.

## What people use it for

**Timing runs phase by phase**: the time breakdown of each stage of the fight.

**Identifying bottlenecks**: see which phase slows you down to focus optimization.

**Comparing loadouts**: measure the impact of a build change on run time.

**Coordinating squads**: squad leaders use the data to improve collective execution.

## Who this tool isn't for

If you don't farm Profit-Taker recurrently or care about optimizing times, you won't use it — it's ultra-specific.

If you play on console or mobile, it doesn't apply: it's Windows software that reads PC logs.

## How it's used in practice

1. Download the app from Basiiii's GitHub repo.
2. Install it and let it read your game logs.
3. Do a Profit-Taker run.
4. The tool shows you the time breakdown per phase.
5. Identify where you lost time and adjust loadout or execution.

## Honest limitations

**Slow development cadence**: the most recent commit is from mid-2025. It's not abandoned, but it moves slower than the rest of the catalog — verify it still works with the current patch before relying on it.

**Ultra niche**: it only serves Profit-Taker. Outside that case, it adds nothing.

**Windows only + reads logs**: it requires a PC and access to your game logs.

## How to get started

Download the app from Basiiii's GitHub, let it read your logs and do a Profit-Taker run to see the breakdown. It's a tool for those who already run the boss repeatedly and want to squeeze every second — not a first resource for someone just reaching endgame.
