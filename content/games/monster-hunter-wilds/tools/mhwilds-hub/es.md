## Qué es

MH Wilds Hub es una herramienta web gratuita que junta dos cosas que normalmente viven separadas: un set builder y una calculadora de daño. Armas tu armadura, skills y decoraciones, y ves una estimación de daño del set en la misma página. Es mantenida por la comunidad y no requiere cuenta.

## Qué problema resuelve

El flujo típico de optimización obliga a saltar entre un builder (para armar el set) y una calculadora (para comparar el daño). Cada salto significa reintroducir datos a mano. MH Wilds Hub elimina ese ida y vuelta: cambias una decoración y el daño estimado se actualiza al instante, así que puedes iterar sobre la pregunta "¿este cambio vale la pena?" sin fricción.

## Diferenciación

WildsBuilder es más rápido para el armado puro y para compartir, pero no calcula daño. Una calculadora dedicada como MH Wilds Calculator modela la fórmula con más detalle, pero no arma el set por ti. MH Wilds Hub ocupa el medio: suficiente builder y suficiente calculadora para la mayoría de las decisiones, en un solo lugar.

## Para qué la usa la gente

- **Comparar dos sets**: armar dos variantes y ver cuál pega más sin abrir otra herramienta.
- **Validar un swap de decoración**: ver el impacto en daño de cambiar Attack por Affinity.
- **Theorycrafting con feedback inmediato**: iterar skills viendo el número moverse.
- **Decidir entre armas**: estimar qué arma rinde más con un set parecido.

## Para quién NO es esta herramienta

Si solo quieres armar y compartir un set lo más rápido posible, WildsBuilder es más ágil. Si necesitas precisión de daño a nivel de cada motion value y matchup contra un monstruo específico, una calculadora especializada es más fiel. Y si buscas guías escritas, esto no las trae.

## Cómo se usa en la práctica

1. Abre mhwildshub.com y elige arma.
2. Arma el set con la sección de builder.
3. Marca skills y decoraciones objetivo.
4. Revisa el daño estimado que aparece junto al set.
5. Itera cambiando piezas y observando cómo se mueve el número.

## Limitaciones honestas

- **Daño estimado, no exacto**: sirve para comparar, no para predecir el daño real contra un monstruo concreto con todos sus hitzones.
- **Curva de entrada**: al hacer dos cosas, la interfaz es más densa que un builder puro.
- **Solo inglés**: sin localización.
- **Mantenimiento community**: la actualización tras cada patch depende del autor.

## Cómo empezar

Entra a mhwildshub.com sin cuenta, elige un arma y arma un set básico. Fíjate en el daño estimado y empieza a cambiar decoraciones para ver el efecto.
