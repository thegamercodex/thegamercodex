## Qué es

Rayleon Armour Builder es un solver de armaduras web para Monster Hunter Wilds. A diferencia de un builder que propone un set, Rayleon enumera todas las combinaciones de armadura y decoraciones que cumplen las skills que pediste, ordenadas por criterios como slots libres. Es gratuito, sin cuenta, y la interfaz es deliberadamente minimalista: una herramienta de búsqueda, no un hub.

## Qué problema resuelve

Cuando optimizas en serio, "un" set que cumple tus skills no alcanza: quieres ver todas las opciones para elegir la que deja más margen para skills extra o para una resistencia concreta. Hacer esa enumeración a mano es inviable. Rayleon corre el algoritmo de búsqueda completo y te muestra el espacio de soluciones entero.

## Diferenciación

WildsBuilder te da una solución limpia rápido; Rayleon te da el conjunto completo de soluciones para que decidas. MH Wilds Hub agrega cálculo de daño; Rayleon no calcula daño, se concentra en exhaustividad de la búsqueda de sets. Es la opción del optimizador que quiere control total sobre qué combinación elegir.

## Para qué la usa la gente

- **Búsqueda exhaustiva**: ver todas las formas de cumplir un set de skills, no solo la primera.
- **Maximizar slots libres**: elegir la combinación que deja más espacio para quality-of-life.
- **Encajar skills difíciles**: encontrar si una combinación específica de skills altas es siquiera posible.
- **Comparar talismanes**: ver cómo cambia el espacio de soluciones con distintos talismanes.

## Para quién NO es esta herramienta

Si recién empiezas y solo quieres un set decente sin pensar mucho, la cantidad de resultados de Rayleon puede abrumar — WildsBuilder es más amable. Si quieres guías, daño o contexto editorial, esta herramienta no es eso a propósito.

## Cómo se usa en la práctica

1. Abre mhwilds.rayleon.net.
2. Define las skills objetivo y sus niveles.
3. Especifica restricciones (arma, slots de talismán, decoraciones disponibles).
4. Corre la búsqueda y revisa la lista completa de combinaciones.
5. Ordena por slots libres o por el criterio que te importe y elige.

## Limitaciones honestas

- **Puede abrumar**: la lista completa de soluciones es mucha información para un jugador casual.
- **Sin cálculo de daño**: resuelve sets, no compara DPS.
- **Solo inglés**: interfaz sin localizar.
- **Austeridad**: no hay guías ni contexto; es una herramienta de búsqueda pura.

## Cómo empezar

Entra a mhwilds.rayleon.net, define dos o tres skills y corre la búsqueda. Ordena por slots libres para ver enseguida el valor de tener todas las soluciones a la vista.
