## What it is

Rayleon Armour Builder is a web armor solver for Monster Hunter Wilds. Unlike a builder that proposes one set, Rayleon enumerates every combination of armor and decorations that meets the skills you requested, sorted by criteria like free slots. It's free, no account, and the interface is deliberately minimalist: a search tool, not a hub.

## The problem it solves

When you optimize seriously, "a" set that meets your skills isn't enough: you want to see every option to pick the one that leaves the most room for extra skills or a specific resistance. Doing that enumeration by hand is unfeasible. Rayleon runs the full search algorithm and shows you the entire solution space.

## Differentiation

WildsBuilder gives you one clean solution fast; Rayleon gives you the full set of solutions so you decide. MH Wilds Hub adds damage calculation; Rayleon doesn't calculate damage, it concentrates on exhaustive set search. It's the optimizer's pick when you want total control over which combination to choose.

## What people use it for

- **Exhaustive search**: seeing every way to meet a skill set, not just the first.
- **Maximizing free slots**: picking the combination that leaves the most room for quality-of-life.
- **Fitting hard skills**: finding whether a specific combination of high-level skills is even possible.
- **Comparing talismans**: seeing how the solution space changes with different talismans.

## Who it isn't for

If you're new and just want a decent set without much thought, Rayleon's volume of results can overwhelm—WildsBuilder is friendlier. If you want guides, damage, or editorial context, this tool deliberately isn't that.

## How it's used in practice

1. Open mhwilds.rayleon.net.
2. Define target skills and their levels.
3. Specify constraints (weapon, talisman slots, available decorations).
4. Run the search and review the full list of combinations.
5. Sort by free slots or whatever criterion matters and pick.

## Honest limitations

- **Can overwhelm**: the full solution list is a lot of information for a casual player.
- **No damage calculation**: it solves sets, doesn't compare DPS.
- **English only**: unlocalized interface.
- **Austerity**: no guides or context; it's a pure search tool.

## How to get started

Go to mhwilds.rayleon.net, define two or three skills, and run the search. Sort by free slots to immediately see the value of having every solution in view.
