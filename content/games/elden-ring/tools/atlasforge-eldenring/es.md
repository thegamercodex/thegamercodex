## Qué es

AtlasForge es una plataforma multi-juego (Elden Ring, Cyberpunk 2077, Diablo 4, WoW Classic, etc.) que combina mapa interactivo + database de items/weapons + build planner en una sola web app. Vive en `atlasforge.gg/elden-ring`. Es gratis con tier Pro opcional.

A diferencia de Map Genie que se especializa en maps, AtlasForge integra varios features en la misma UI. La cobertura ER incluye Lands Between completas + Realm of Shadow del DLC.

## Qué problema resuelve

Para usuarios que solo quieren un mapa básico sin pagar, Map Genie tiene limitaciones notables en tier free (checkboxes no persisten, ads pesadas). AtlasForge resuelve esto con free tier más generoso: checkboxes persisten incluso sin Pro, y ads son menos intrusivas.

También resuelve el problema de cross-tool jumping: si vas a investigar un item, normalmente abris el mapa para ubicarlo + un wiki para ver stats + un planner para ver si vale para tu build. AtlasForge tiene los tres en la misma página.

## Diferenciación

Contra Map Genie pierde en mobile app (AtlasForge solo web; Map Genie tiene apps nativas) pero gana en free tier y en cross-feature integration. Contra Fextralife wiki gana en UX moderna; el wiki tiene más detail editorial pero la UI es más torpe.

## Para qué la usa la gente

**Mapa interactivo gratis**: ver coleccionables y NPCs sin pagar.

**Weapon database lookup**: stats de armas con scaling, weight, requirements directamente desde el mapa.

**Build sharing**: el planner integrado permite crear builds y compartir URLs.

**Cross-game user**: si juegas Elden Ring + Cyberpunk + Diablo 4, una sola cuenta cubre todos.

**Verificación cruzada con Map Genie**: cuando un coleccionable es ambiguo, comparar mapas resuelve.

## Para quién NO es esta herramienta

Si tu prioridad es mobile usage (jugando con celular al lado), Map Genie es mejor — apps nativas vs web responsive.

Si quieres database más completa de items (descripciones, lore, drop rates exactos), Fextralife o wiki.gg son mejores.

Si solo te interesa Elden Ring, la naturaleza multi-juego de AtlasForge agrega complexity que no usas.

## Cómo se usa en la práctica

1. Visita `atlasforge.gg/elden-ring`.
2. Crea cuenta gratis (opcional pero útil para checkboxes persistentes).
3. Selecciona "Map" para el mapa interactivo, "Database" para weapons, "Builds" para planner.
4. En map: filtros por categoría para mostrar/ocultar tipos de marcadores.
5. En database: search por arma → ver stats, scaling, requirements.
6. En builds: crea build y comparte URL.

## Limitaciones honestas

**No app mobile nativa**: solo web responsive. Para mobile companion durante juego, Map Genie tiene la edge.

**Database de items menos profunda que Fextralife**: para drop conditions, lore, y notas editoriales detalladas, Fextralife sigue siendo más completo.

**Multi-juego puede confundir**: la nav incluye otros juegos; si solo quieres ER puede sentirse cluttered.

**Updates más lentos que Map Genie**: en SOTE launch, AtlasForge tardó más que Map Genie en agregar markers nuevos.

**Tier Pro menos features uniques**: el incentivo a pagar es más débil; la mayoría usa free.

## Cómo empezar

1. Visita `atlasforge.gg/elden-ring`.
2. Crea cuenta gratis si quieres sync de checkboxes.
3. Empieza con el mapa para entender la UI.
4. Prueba la database y planner para ver si reemplaza otros tools que usas.
5. Si te convence, considera Pro para soporte; si no, free tier alcanza para mayoría de uso.
