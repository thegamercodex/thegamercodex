## Qué es

ELDEN RING Reforged (ERR) es un overhaul mod gratuito desarrollado por un equipo dedicado, distribuido vía Nexus Mods en `nexusmods.com/eldenring/mods/541`. Es uno de los dos overhauls grandes del juego (el otro es The Convergence) y se diferencia por mantener la identidad de Elden Ring intacta mientras rebalancea todo el sistema.

A diferencia de Convergence (que cambia mucho más radicalmente), ERR busca ser lo que el juego "podría haber sido" con más tiempo de balanceo y QoL.

## Qué problema resuelve

El juego base tiene problemas de balance reconocidos:
- Algunas armas dominan el meta (Bloodhound's Fang, Moonveil) eclipsando alternativas.
- Builds específicas (bleed, frost) son disproportionadamente fuertes.
- AoWs útiles son pocas; mayoría es vestigial.
- Algunos jefes son trivializables con cierto cheese.
- Multiplayer vanilla tiene matchmaking restrictivo.

ERR rebalancea todo eso. Armas que nadie usaba ganan unique movesets. Status effects son recalibrados. AoWs muertas reciben nuevas funcionalidades. Jefes son ajustados para evitar cheese strats. Y tiene su propio server multiplayer para jugar online entre usuarios de ERR.

## Diferenciación

Contra The Convergence gana en respeto al diseño original — si te gustó Elden Ring vanilla, ERR conserva esa identidad. Convergence agrega cientos de hechizos y armas nuevas; ERR rebalancea las existentes. Audiencias distintas: ERR para "más Elden Ring", Convergence para "Elden Ring distinto".

## Para qué la usa la gente

**Segunda corrida con balance moderno**: terminar el juego base + SOTE varias veces y querer una experiencia rebalanceada.

**Multiplayer online con balance**: el server propio de ERR permite invasiones, co-op y PvP entre users del mod sin riesgo de ban.

**Probar armas y builds raras**: armas que en vanilla no eran viables ganan kit competitivo.

**Endgame más profundo**: ajustes a NG+ y NG++ para mantener challenge.

**Comunidad activa**: Discord con ~100K miembros, eventos, balance discussions y feedback loop con devs.

## Para quién NO es esta herramienta

Si todavía no terminaste el juego base, no instales overhauls — la experiencia ER vanilla es referencia y ERR cambia decisiones de diseño que solo entendes después de jugarla original.

Si quieres contenido nuevo (mapas, jefes, armas que no existen en vanilla), Convergence es mejor — ERR rebalancea lo existente.

Si juegas en console, no podes — PC exclusivo.

Si tu prioridad es Seamless Co-op puro, hay fricción al combinar ERR con Seamless: configurable pero requiere reading.

## Cómo se usa en la práctica

1. Instala Mod Engine 2 primero (`github.com/soulsmods/ModEngine2`).
2. Baja la última versión de ERR desde `nexusmods.com/eldenring/mods/541`.
3. Sigue el README detallado del mod — incluye structure de archivos para Mod Engine 2.
4. Configura `config_eldenring.toml` siguiendo las instrucciones.
5. Lanza con el bat correspondiente.
6. Para multiplayer, conectate al ERR Custom Server siguiendo el setup en el Discord oficial del mod.

## Limitaciones honestas

**Curva de re-aprendizaje**: builds que conocías de vanilla pueden no funcionar igual. Armas nerfeadas o buffeadas requieren testing.

**Compatibility con otros mods**: ERR es invasivo (cambia muchos archivos); combinarlo con mods que toquen los mismos params genera conflicts. La compatibility se mantiene con un set seleccionado de mods amigables.

**Actualización pesada**: cada release de ERR es grande (~GB), y el ritmo varía.

**Server side dependency**: el multiplayer online de ERR depende del custom server. Si el server tiene downtime, el multiplayer no funciona (single-player sí).

**No oficial**: aunque FromSoftware tolera mods de PC, no hay garantía contractual.

## Cómo empezar

1. Termina el juego base + idealmente SOTE primero.
2. Instala Mod Engine 2.
3. Visita `nexusmods.com/eldenring/mods/541` y descarga ERR.
4. Lee el README — es denso pero necesario.
5. Únete al Discord de ERR (`discord.com/invite/eldenringreforged`) para troubleshooting.
6. Empieza con una run dedicada a ERR (no save vanilla).
