## What it is

Nexus Mods is the largest distribution platform for PC single-player game mods, with presence in Skyrim, Fallout, Witcher, Dragon Age, and obviously Elden Ring. The ER subdomain (`nexusmods.com/eldenring`) hosts 5000+ mods with a comments system, votes, bug reports, and versioning.

Free account: rate-limited downloads. Premium (~$50/year): full-speed downloads + no ads. Most modders publish here first before any other hub.

## What it solves

Finding Elden Ring mods without Nexus means searching scattered Discords, personal GitHubs, and links in Reddit threads. Nexus consolidates everything: tag search, category filters (gameplay, audio, weapons, models, UI), vote sorting, and community-reported bugs in comments.

It also solves versioning: each mod publishes versions with a visible changelog, and you can download older versions if the latest breaks something.

## What people use it for

**Browse new mods**: see what's published this week, sort by trending or vote count.

**Verify quality before installing**: comments quickly reveal if a mod has serious problems.

**Download big overhauls**: ELDEN RING Reforged, The Convergence, Seamless Co-op — all live on Nexus.

**Report bugs to mod authors**: the bug-report system notifies the author.

**Update mods**: Nexus tracks what you have installed and notifies of updates (if you use Vortex as manager).

## Who shouldn't use it

If you play on console (PS5/Xbox), mods don't apply — Nexus is PC-exclusive.

If you want cosmetic mods only (skins/textures), Nexus has everything but you'll also find them on other more-curated platforms.

If you dislike interacting with account systems (even free), there are mods on GitHub that don't require a Nexus login.

## How it's used in practice

1. Visit `nexusmods.com/eldenring`.
2. Create a free account (required for downloading).
3. Verify email.
4. Browse by filters (Most Endorsed, Most Downloads, Recently Added, Recently Updated).
5. On a mod's page, read Description + Comments + Bugs before installing.
6. Click "Manual Download" for the zip, or "Mod Manager Download" if you have Vortex.
7. Install following the mod's README (typically requires Mod Engine 2).

## Honest limitations

**Free tier speed limit**: free downloads are slow (~1MB/s). For big mods (Convergence ~5GB) it takes. Premium fixes this.

**Free tier ads**: visible pop-ups and banners. Premium removes them.

**Variable quality**: anyone can publish; abandoned mods with unstable versions exist. Filtering by endorsements helps.

**Occasional toxic comments**: like any large community, there are rants and harassment. Mod authors sometimes close comments for this reason.

**DMCA policy**: Nexus occasionally takes down mods on developer requests (FromSoftware hasn't done this with ER but could).

## How to start

1. Visit `nexusmods.com/eldenring`.
2. Create a free account.
3. Browse "Most Endorsed" to see the staples (Seamless Co-op, ERR, Convergence).
4. Start with a simple mod to test the flow (a texture pack).
5. When you understand Mod Engine 2 and the structure, scale up to big overhauls.
