## Qué es

Map Genie es una plataforma de mapas interactivos para juegos open-world (Skyrim, Witcher 3, Elden Ring, Cyberpunk 2077, Hogwarts Legacy, GTA, y más). El mapa de Skyrim cubre el mundo completo (Skyrim + Solstheim del DLC Dragonborn) con todas las locations relevantes marcadas.

Funcionalmente: mapa zoomable estilo Google Maps, filtros por categoría (shouts, dragons, treasure maps, books, ingredients, smithing materials, daedric quests, etc.), search por nombre, tracking de "found/not found" por marker. Free tier accesible, Premium opcional.

## Qué problema resuelve

Skyrim tiene 500+ locations relevantes para exploración 100%:
- 30+ shouts (cada uno en una location específica).
- 80+ books que dan skill bonuses.
- Smithing materials de calidad (ej: Quicksilver Ore) hidden en cuevas específicas.
- Daedric quest triggers (ej: dónde matar al noble específico).
- Treasure maps que el juego no marca en el mapa default.
- Aetherium Shards, Dragon Priest masks, Stones of Barenziah.

Memorizar todas esas locations es imposible. Map Genie es la base de datos visual organizada.

## Diferenciación

Frente a **UESP**: UESP tiene la información en texto pero no visualizable. Si quieres el shout "Whirlwind Sprint", UESP te dice "en High Hrothgar" pero no en qué parte. Map Genie te muestra el pin exacto.

Frente a **in-game map**: el mapa del juego marca solo locations que ya visitaste. Map Genie te muestra todo desde el inicio (con opción de filtrar lo encontrado).

Frente a **mods de "iHUD" y "More Informative Console"**: estos te dan info on-the-fly pero requieren modlist. Map Genie es web, funciona también para players en console.

## Para qué la usa la gente

**100% completion runs**: si quieres cumplir todos los achievements y findings, Map Genie es la lista visual ordenada.

**Buscar locations específicas**: "dónde está el shout Become Ethereal" → search → pin en mapa.

**Trackear progreso de coleccionables**: con cuenta gratis, marcás cada item como found. Sync entre devices.

**Planning de rutas eficientes**: si vas a hacer una pasada de "todos los Stones of Barenziah", el mapa muestra todos en simultáneo y puedes trazar ruta óptima.

**Reference para guías**: cuando sigues una guide que dice "ir al cave norte de X", Map Genie te ayuda a localizar X visualmente.

## Para quién NO es esta herramienta

Si te gusta exploración blind (no spoilers, descubrir todo por azar), Map Genie te arruina la experiencia. Es para completionists.

Si juegas un único playthrough sin querer 100%, no necesitas Map Genie.

Si tu modlist agrega cells nuevas o cambia drásticamente las locations, Map Genie refleja vanilla — no aplica a Enderal, Beyond Skyrim, etc.

## Cómo se usa en la práctica

1. Abre `mapgenie.io/skyrim` en cualquier browser.
2. La primera carga es el mapa completo zoomable.
3. Filtros en el sidebar: marca las categorías que te interesan (Shouts, Dragons, Daedric Quests, etc.). El resto se oculta.
4. Click en un pin para info: nombre, descripción corta, link a UESP para detalle profundo.
5. Para tracking, creá cuenta gratis. Cada pin tiene checkbox "found" — márcalo cuando lo encuentras in-game.
6. Premium ($5/mes o $20 lifetime) desbloquea features avanzadas: notes per pin, más maps, sin ads.

## Limitaciones honestas

**Solo vanilla**. Mods que cambian world layout no se reflejan. Para Enderal o Beyond Skyrim, no hay Map Genie equivalente.

**Subscription model agresivo**. Pop-ups para Premium son frecuentes. Free tier es funcional pero limitado en features.

**Falta de granularity en algunos pins**. Un cave grande puede tener un solo pin "Daedric quest" cuando hay 5 ítems relevantes adentro. Para detalle interior, UESP complementa.

**Mobile experience limitada**. El mapa es zoomable en mobile pero filtros sidebar son menos cómodos.

**Spoiler-heavy por naturaleza**. Si abres el mapa antes de jugar, ves todo. Difícil "ir gradual".

## Cómo empezar

1. Abre `mapgenie.io/skyrim`.
2. Sin cuenta, explorá: filtros y pins funcionan.
3. Para tracking, regístrate (gratis).
4. Para tu primer playthrough completionist, filtros recomendados: Shouts (30) + Stones of Barenziah (24) + Daedric Quests (15). Esos solos son 70 hours de gameplay.
5. Cada vez que encuentras algo, márcalo. Mantiene tu progreso entre sesiones.

Map Genie es opcional para players narrative-focused, esencial para completionists.
