Both cover tracking but of different things. aRPG Timeline tracks when each season starts; Dev Tracker tracks what devs say.

## Different scope

aRPG Timeline is a multi-game season tracker. Covers PoE 1, PoE 2, D4, LE, and others with cycle launch dates, countdowns, and calendar subscription. Broad scope in games, narrow scope in info (dates only).

Dev Tracker is LE-specific. Aggregates EHG dev posts on Reddit, Twitter, forum, and Discord in a single chronological feed. Narrow scope in games (LE only), broad scope in info (everything devs say).

## Different use case

aRPG Timeline serves to **plan cycle rotation**: if you play PoE and LE in parallel, you see when each starts → plan when to level each char.

Dev Tracker serves to **stay updated daily**: during active season, monitor what devs respond to community feedback, what changes they plan, what bugs they acknowledge.

## Calendar vs feed

aRPG Timeline offers **iCal subscription** that pushes seasons to Google/Apple/Outlook calendar. Setup once, get alerts automatically. Killer feature.

Dev Tracker is **RSS feed**. More useful for active readers who already use RSS readers. No native push notifications.

## When each wins

| Use case | Winner | Why |
|---|---|---|
| Plan multi-ARPG cycle | aRPG Timeline | Only one with multi-game tracking |
| Monitor dev posts daily | Dev Tracker | Cross-platform aggregation |
| Calendar subscription | aRPG Timeline | Unique iCal feature |
| Mid-cycle balance changes | Dev Tracker | Live dev acknowledgements |
| Pre-cycle prep for fresh char | aRPG Timeline | Actionable countdown timer |
| Bug acknowledgement tracking | Dev Tracker | Dev responses in feed |

## Recommendation

Multi-ARPG players: subscribe to aRPG Timeline's iCal. Single setup, alerts for all the games you rotate.

LE-only players during active season: bookmark Dev Tracker, check daily. Dev statements info builds/farm prioritization decisions.

For newcomers: aRPG Timeline to know when to start. Dev Tracker after leveling, when you're deep in endgame and care what devs think.

Both are free, complementary, don't compete. The question isn't "which do I use" but "when do I use which".
