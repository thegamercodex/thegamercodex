Ambos cubren tracking pero de cosas distintas. aRPG Timeline trackea cuándo arranca cada season; Dev Tracker trackea qué dicen los devs.

## Scope distinto

aRPG Timeline es multi-game season tracker. Cubre PoE 1, PoE 2, D4, LE y otros con dates de cycle launch, countdowns y calendar subscription. Es scope amplio en games, scope estrecho en info (solo dates).

Dev Tracker es LE-specific. Agrega posts de devs EHG en Reddit, Twitter, forum y Discord en single chronological feed. Scope estrecho en games (solo LE), scope amplio en info (todo lo que devs dicen).

## Use case distinto

aRPG Timeline sirve para **planificar cycle rotation**: si juegas PoE y LE en paralelo, ves cuándo arranca cada uno → planeas cuándo levear cada char.

Dev Tracker sirve para **stay updated daily**: durante season activa, monitorear qué responden devs a community feedback, qué changes planean, qué bugs reconocen.

## Calendar vs feed

aRPG Timeline ofrece **iCal subscription** que push seasons a Google/Apple/Outlook calendar. Setup once, recibes alerts automatically. Killer feature.

Dev Tracker es **RSS feed**. Más útil para active readers que ya usan RSS readers. Sin native push notifications.

## Cuándo gana cada uno

| Caso de uso | Ganador | Por qué |
|---|---|---|
| Planificar cycle multi-ARPG | aRPG Timeline | Único con multi-game tracking |
| Monitor dev posts daily | Dev Tracker | Cross-platform aggregation |
| Calendar subscription | aRPG Timeline | iCal feature único |
| Mid-cycle balance changes | Dev Tracker | Dev acknowledgements live |
| Pre-cycle prep para fresh char | aRPG Timeline | Countdown timer accionable |
| Bug acknowledgement tracking | Dev Tracker | Dev responses in feed |

## Recomendación

Player multi-ARPG: subscríbase al iCal de aRPG Timeline. Single setup, alerts para todos los juegos que rotas.

Player LE-only durante season activa: bookmark Dev Tracker, check daily. La info de dev statements informa decisions de build/farm prioritization.

Para newcomers: aRPG Timeline para saber cuándo empezar. Dev Tracker después de levear, cuando estés deep en endgame y te interese qué piensan devs.

Los dos son free, complementarios, no compiten. La pregunta no es "cuál uso" sino "cuándo uso cuál".
