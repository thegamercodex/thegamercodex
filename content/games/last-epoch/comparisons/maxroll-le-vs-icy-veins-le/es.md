Ambos hubs publican class build guides, tier lists y news editorial — pero su foco editorial es opuesto. Maxroll es ARPG-specialist (cubre PoE 1, PoE 2, D4, D2R, LE con team dedicado per game); Icy Veins es generalist multi-juego con heritage MMO (existe desde 2011 cubriendo WoW). Esto afecta depth, cadence y UX.

## Depth en LE específicamente

Maxroll dedica editorial team focused — Lizard IRL, MacroBioBoi y otros publican builds con prose larga, leveling sections, endgame variants, planner embed. Su library de LE es la más extensa entre editorial hubs.

Icy Veins cubre LE con menor library — guides organizados por las 5 clases con builds top per mastery. Quality editorial es solid pero no tiene la depth per-guide de Maxroll.

## Cadencia post-patch

Cuando EHG drops balance change, Maxroll team coordina y dentro de 24-48h tier lists y guides quedan revised. Icy Veins típicamente lagea 1-3 días — su editorial bandwidth se reparte entre WoW, D4, HSR, LE, etc.

Para players que quieren reaccionar rápido al patch, Maxroll informa antes.

## Familiarity vs nueva UX

Si vienes de WoW o D4 y ya usas Icy Veins para esos juegos, su sección LE elimina friction de aprender layout nuevo. Mismo sidebar, mismo tono editorial, misma jerarquía de info. Reduces context-switch.

Maxroll también tiene consistency cross-game pero su audience overlap con WoW MMO es menor.

## Cross-validation valor

Para decision important (qué build playear este cycle), cross-check entre Maxroll e Icy Veins da signal de confianza. Si ambos hubs declaran un build S-tier, es probable que sea — el bias compartido es menor que con un solo hub.

Si difieren, hay matiz interesante: alguno está playing favorites o reading el meta diferente.

## Mobile UX

Icy Veins UI se traduce mejor a mobile. Sus guides son más compactas y la navigation mobile-friendly. Maxroll's prose larga requires desktop para reading cómodo.

## Cuándo gana cada uno

| Caso de uso | Ganador | Por qué |
|---|---|---|
| Deep dive en LE específico | Maxroll | Editorial team dedicado a LE |
| Players desde WoW/D4 | Icy Veins | Layout familiar across games |
| Cross-validate build decision | Icy Veins | Second opinion editorial |
| Patch reaction velocity | Maxroll | Update cadence 24-48h vs 1-3 días |
| Mobile-friendly reading | Icy Veins | UI compacta mejor en touch |
| Tier list authority | Maxroll | Team ladder-validated |
| Multi-game UX consistency | Icy Veins | Mismo flow en WoW/D4/HSR/LE |

## Recomendación

Para player LE-only: Maxroll por defecto. Más depth, más velocity, más authority.

Para player que rota WoW/D4/LE: Icy Veins simplifica workflow porque no aprendes layouts distintos. Maxroll suplementa cuando necesitas más depth LE-specific.

Para serious decision making: lee ambos y cross-check. Free, mismo workflow, el effort extra de 5 minutos vale el confidence boost.
