Cuando un newcomer pregunta "qué site uso para LE", la respuesta canónica es "Maxroll o Last Epoch Tools" — pero esa formulación oculta que en realidad son dos hubs con propuestas opuestas. No reemplazan uno al otro. La mayoría de jugadores serios termina usando ambos en flujos distintos: Maxroll para deep dive del build elegido, LE Tools para todo lo demás.

Esta comparación recorre dimensiones donde gana cada uno y los flujos típicos donde combinarlos da más valor que elegir.

## La propuesta editorial

Maxroll Last Epoch (maxroll.gg/last-epoch) es la sección LE del hub editorial Maxroll, un equipo profesional con staff dedicado que también cubre PoE 1, PoE 2, D4 y D2R. La propuesta es **depth editorial**: cada build publicado pasa filtro de quality, viene con prose larga justificando cada skill/blessing/aspect, y el planner integrado deja al lector clonar y modificar.

Last Epoch Tools (lastepochtools.com) es un hub comunitario independiente que arrancó durante Early Access (2020+). La propuesta es **breadth comunitaria**: combine planner, item database exhaustiva, loot filter sharing con editor visual, builds auto-crawleados de YouTube y community submissions, character profiles browseables por account name, y ladders por season.

El tradeoff es **quality control vs amplitud**. Maxroll publica menos builds pero todos pasan filtro editorial; LE Tools publica todo lo que pase moderation básico, lo cual incluye builds excelentes pero también outdated, meme, o low-effort.

## Build guides: depth vs amplitud

Si abres maxroll.gg/last-epoch/build-guides ves ~50 builds publicados por cycle, cada uno con leveling path detallado, endgame variants, gear specifics, mecánicas explicadas y planner embed. Cada slot de gear tiene justificación: por qué este unique, por qué este affix prioritario, por qué este blessing target.

Si abres lastepochtools.com/builds ves cientos de builds auto-crawleados por cycle, sortable por author/views/likes. La depth varía drásticamente: algunos vienen con writeup completo, otros son solo planner link con un screenshot. La community filter (likes, comments) ayuda a separar quality, pero requires investment del lector.

**Para newcomer**, Maxroll gana por curaduría — abres un guide top-tier, sigues instrucciones, funciona. **Para player intermedio que ya entiende mecánicas**, LE Tools puede ganar porque ves muchas variants del mismo skill y eliges la que se acomoda a tu vision.

## Database y lookup

Acá LE Tools domina sin debate. La DB de items, uniques, prefixes, suffixes es la más completa del ecosystem — filtros por tier, clase, tipo de equipo, level requirement. Cuando estás craftando y necesitas saber qué T6 prefijos pueden rollear en un body armor de Sentinel, LE Tools lo tiene en 2 clicks.

Maxroll embeds item info dentro de sus build guides, pero no tiene browseable DB equivalente. Si quieres inspeccionar uniques fuera del contexto de un build específico, Maxroll te falla.

Algunos players intentan resolver esto usando TunkLab (lastepoch.tunklab.com) como third option — válido para affix calc profundo, pero LE Tools sigue siendo más amigable para amplitud de lookup.

## Tier lists: cuándo gana cada uno

**Maxroll publica tier lists curadas**: Class Tier List y Build Tier List actualizadas patch tras patch, con justificación per entry. El team detrás (Lizard IRL, MacroBioBoi, otros) tiene autoridad ladder-validated. Cuando dice "S-tier", suele ser.

**LE Tools tiene tier lists comunitarias**: usuarios votan, el sort emerge de community consensus. Refleja mejor la opinión amplia, pero también incluye noise de bias popular hacia builds famosos.

Para decisión pre-cycle, Maxroll es más confiable. Para entender qué builds la community está jugando masivamente, LE Tools refleja mejor el real.

## Loot filters

LE Tools tiene editor visual integrado con community sharing — defines reglas (color, sonido, hide) por affix tier, clase de item, level requirement. Sin tener que editar XML a mano, puedes crear un filter custom en 10 minutos.

Maxroll publica filters como archivos download tuned para builds específicos. Útil si copias el build entero, menos útil si quieres modificar.

Para create/edit filter own, LE Tools gana. Para grab-and-go filter que ya match tu build, Maxroll a veces es más rápido.

## Patch reaction post-balance

Aquí Maxroll tiene ventaja clara por su modelo: cuando EHG announces balance change, el editorial team coordina updates y dentro de 24-48h tier lists y guides quedan revised con analysis. LE Tools depende de community submissions — el meta consensus toma 3-5 días en consolidarse.

Para players que quieren reaccionar rápido al patch (rerollar build, salir de un nerf), Maxroll informa primero.

## Character profiles y ladders

LE Tools tiene **character profiles por account**: ingresas tu nombre, ves tus chars publicados con gear y build visible. Útil para mostrar tu setup a friends sin tomar capturas. Maxroll no tiene equivalente.

LE Tools también tiene **ladders más granulares**: filtros por cycle, hardcore, solo self-found, mode. Maxroll tiene leaderboards community-maintained pero menos granular.

## Cuándo gana cada una

| Caso de uso | Ganador | Por qué |
|---|---|---|
| Deep dive con justification per slot | Maxroll | Editorial-curated prose larga |
| Lookup de item o affix específico | LE Tools | DB browseable exhaustiva |
| Crear loot filter custom | LE Tools | Editor visual + community sharing |
| Patch reaction y tier list update | Maxroll | Editorial team coordinado, lag 24-48h |
| Character profile sharing | LE Tools | Único con feature por account |
| Tier list pre-cycle decision | Maxroll | Autoridad ladder-validated |
| Discover builds creativos no-meta | LE Tools | Auto-crawl YouTube + amplia community |
| Leveling path para newcomer | Maxroll | Step-by-step con leveling sections |

## La recomendación combinada

El workflow más eficiente para player serio:

1. **Pre-cycle**: leer Maxroll Class Tier List → elegir mastery → abrir build top-tier → leer leveling section.
2. **Durante leveling**: seguir Maxroll guide step-by-step.
3. **Endgame transition**: cross-check Maxroll endgame variants con builds populares en LE Tools del mismo skill — discoverás variants creativos.
4. **Crafting**: usar LE Tools DB para lookup de affixes target y rangos.
5. **Filter**: empezar con filter de Maxroll, customizar en LE Tools editor.
6. **Character sharing**: subir char a LE Tools profile para friends/Discord.
7. **Patch reaction**: monitorear Maxroll tier lists post-patch + cross-check community builds en LE Tools.

Usando ambos así, cubres 100% del use case sin redundancia. Elegir solo uno es perder valor sin necesidad — los dos son free y complementarios.
