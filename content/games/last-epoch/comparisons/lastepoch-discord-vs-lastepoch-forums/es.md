Ambos son oficiales de Eleventh Hour Games, pero su rol en el community workflow es distinto. Discord es la community casual de daily traffic; forum es el archive estructurado para discussion formal.

## Volume y velocity

Discord (200k+ members) es high-volume, high-velocity. Channels viven en current moment, con casual chat, voice channels, reactions inmediatas. Para newcomer puede ser overwhelming — setup notification preferences es essential.

Forum (forum.lastepoch.com) es low-volume, low-velocity. Posts cooked durante horas-días. Tono más serio, less meme. Para players que prefieren async discussion, forum es mejor.

## Dev presence y depth

Acá forum gana en specific case. Cuando devs quieren explicar design decisions extensamente, lo hacen via **Developer Blogs** en forum. Posts long-form con context, philosophy, future plans. Discord no recibe ese tipo de content — los devs simplifican mensajes para chat format.

Para entender depth de por qué EHG tomó X decisión, forum es la única source.

Pero para day-to-day Q&A, Discord tiene más dev y CM presence interactiva.

## Bug reports

Forum gana clearly. El bug report template force fields estructurados (repro steps, version, severity, screenshots). Útil para devs ingestar reports y tracking.

Discord bug reports en #help se entierran en scroll. Sin tracking proper, pueden ser ignored unless de high visibility.

Para bugs que afectan progress de tu account, forum es la opción formal correcta.

## Build Compendium

El forum tiene un thread pinned llamado "Last Epoch Build Compendium" que aggregates community builds de cada cycle. Curated por la community con links a guides, planners, videos. Single source para discovery de builds beyond Maxroll/LE Tools.

Discord no tiene equivalent curated — build discussion fluye en class channels pero sin archive.

## Searchable archive

Forum archives discussions desde Early Access (2018+). Google indexa threads y son searchable forever. Si quieres saber qué se discutió hace 3 años sobre X mechanic, forum lo tiene.

Discord es ephemeral. Hard de search histórico.

## Cuándo gana cada uno

| Caso de uso | Ganador | Por qué |
|---|---|---|
| Real-time announcement reactions | Discord | Velocity, channels live |
| Dev blog long-form | Forum | Devs publican here, no en Discord |
| Bug report formal | Forum | Template estructurado + tracking |
| Build Compendium curado | Forum | Pinned thread único en su tipo |
| Searchable archive | Forum | 8+ años de threads indexed |
| Fast Q&A | Discord | Class channels responden en minutos |
| LFG / coordination | Discord | Velocity para party making |

## Recomendación

Usar los dos en flujos distintos:

- **Discord**: daily check para real-time updates, LFG, Q&A, pulse comunitaria.
- **Forum**: weekly/bi-weekly check de Developer Blogs y bug report formal cuando sea necesario.

Para newcomers: Discord primero. Forum cuando empieces a have opinions formales o necesites archive search.

Para hardcore: ambos active. Forum para depth, Discord para velocity.
