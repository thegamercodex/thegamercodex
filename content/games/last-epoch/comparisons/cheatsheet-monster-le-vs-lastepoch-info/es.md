Ambas son "reference tools" para Last Epoch pero sirven momentos opuestos del workflow. Cheat Sheet es single-page format para glance rápido; TunkLab es multi-section database para deep lookup técnico.

## Formato y propósito

Cheat sheet (cheatsheet.monster/lastepoch) condensa la info más consultada del juego en una sola página visual. Tablas de blessings por timeline, affix tier ranges, dungeon mods, resistances. El value es **velocity de glance** — abrir, ver, decidir, sin clicks.

TunkLab (lastepoch.tunklab.com) es database multi-section. Equipment, Affixes, Uniques, Skills, Classes, Monolith, Factions, plus calculators. El value es **depth técnico** — abrir, buscar, deep dive en stat ranges precisos y formulas.

Uno reemplaza al otro solo si tu use case es muy limitado en una dimensión.

## In-game decisions

Cheat sheet gana clearly. Cuando estás about to push monolith timeline X y necesitas saber qué blessings rolean, abres el cheat sheet en segunda monitor, ves la matrix, decidís en 5 segundos.

TunkLab require navegar a Monolith section → encontrar la timeline → leer info. Slower para in-game momento.

## Theorycraft profundo

TunkLab gana. Cuando estás modelando build y necesitas saber exactly qué T7 prefixes pueden rollear en un body armor de Sentinel, o calcular effective HP con tus resistances actuales, TunkLab tiene depth y calculators.

Cheat sheet es summary visual, no tiene depth para análisis serio.

## Printability

Cheat sheet diseñada para print bien. Players hardcore que juegan en single monitor lo tienen impreso al lado del setup. La organización single-column de tables funciona en paper.

TunkLab no está formatted para print. Multi-page output sería raro.

## Cuándo gana cada uno

| Caso de uso | Ganador | Por qué |
|---|---|---|
| Glance in-game rápido | Cheat sheet | Single-page para 5 sec lookup |
| Deep technical lookup | TunkLab | Database exhaustiva |
| Calculator interactivo | TunkLab | Único con defense/ward calcs |
| Print para reference físico | Cheat sheet | Designed para impresión |
| Refresh post-pausa larga | Cheat sheet | Document único leíble en 10 min |
| Comprehensive theorycraft | TunkLab | Stat formulas precisas |

## Recomendación

No es elegir uno. Workflow ideal:

- **Cheat sheet abierto en segundo screen** durante gameplay activo. Glance sin pausar.
- **TunkLab abierto en browser tab** cuando estás theorycrafting o planeando build serio.

Para newcomers: ambos pueden esperar hasta que entiendas mecánicas básicas. Empieza con Maxroll/LE Tools, después agregás estas reference tools cuando llegues a endgame y necesitas más precision.
