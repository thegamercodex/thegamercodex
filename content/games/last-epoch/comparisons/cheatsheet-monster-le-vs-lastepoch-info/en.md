Both are "reference tools" for Last Epoch but serve opposite workflow moments. Cheat Sheet is single-page format for fast glance; TunkLab is multi-section database for deep technical lookup.

## Format and purpose

Cheat sheet (cheatsheet.monster/lastepoch) condenses the game's most-consulted info on a single visual page. Tables of blessings per timeline, affix tier ranges, dungeon mods, resistances. The value is **glance velocity** — open, see, decide, no clicks.

TunkLab (lastepoch.tunklab.com) is a multi-section database. Equipment, Affixes, Uniques, Skills, Classes, Monolith, Factions, plus calculators. The value is **technical depth** — open, search, deep dive into precise stat ranges and formulas.

One replaces the other only if your use case is very limited on one dimension.

## In-game decisions

Cheat sheet wins clearly. When you're about to push monolith timeline X and need to know which blessings roll, you open the cheat sheet on a second monitor, see the matrix, decide in 5 seconds.

TunkLab requires navigating to Monolith section → finding the timeline → reading info. Slower for in-game moment.

## Deep theorycraft

TunkLab wins. When you're modeling a build and need to know exactly which T7 prefixes can roll on a Sentinel body armor, or compute effective HP with your current resistances, TunkLab has depth and calculators.

Cheat sheet is a visual summary, doesn't have depth for serious analysis.

## Printability

Cheat sheet designed to print well. Hardcore players who play on a single monitor have it printed next to their setup. The single-column table organization works on paper.

TunkLab isn't formatted for print. Multi-page output would be odd.

## When each wins

| Use case | Winner | Why |
|---|---|---|
| Fast in-game glance | Cheat sheet | Single-page for 5-sec lookup |
| Deep technical lookup | TunkLab | Exhaustive database |
| Interactive calculator | TunkLab | Only one with defense/ward calcs |
| Print for physical reference | Cheat sheet | Designed for printing |
| Refresh after long break | Cheat sheet | Single readable document in 10 min |
| Comprehensive theorycraft | TunkLab | Precise stat formulas |

## Recommendation

Don't pick one. Ideal workflow:

- **Cheat sheet open on a second screen** during active gameplay. Glance without pausing.
- **TunkLab open in a browser tab** when theorycrafting or planning a serious build.

For newcomers: both can wait until you understand basic mechanics. Start with Maxroll/LE Tools, then add these reference tools when you reach endgame and need more precision.
