## What it is

ArreatSummit.gg is an editorial hub for Last Epoch with several sections: build guides, build planner, item and unique database, price guide, loot filters, and dungeon guides. It's run by the ArreatSummit Team independently but with **explicit Eleventh Hour Games endorsement** declared on the site.

The name pays homage to the historic "Arreat Summit" site which was the official Diablo II guide hosted by Blizzard. The modern version keeps that tone: editorial professional with developer backing.

Main sections:
- **Build Guides**: curated builds with leveling + endgame coverage.
- **Build Planner**: integrated planner.
- **Game Database**: items, uniques, affixes.
- **Price Guide**: per-item-type updated pricing, sourced from The Sanctum Market Discord.
- **Loot Filters**: filters published by the community.
- **Dungeon Guides**: per-dungeon and per-boss guides.

Free, no login required.

## What problem it solves

For **trading**: meta pricing changes month over month (Merchant's Guild is per-cycle, prices fluctuate with supply and demand). Without an updated guide, you sell cheap and pay expensive. ArreatSummit Price Guide consolidates Sanctum Market pricing on a single browsable page by category, without having to browse Discord.

For **build guides**: it offers an editorial alternative to Maxroll. Although the library is smaller, the builds they publish come with a clear "updated for patch X.Y" flag, useful for players who value editorial cadence over volume.

For **unique/affix discovery**: the database has similar scope to Last Epoch Tools, with a bias toward "what's being used now" more than "everything that exists".

## How it differs from Maxroll and LE Tools

- **Maxroll**: superior editorial depth, more builds, more tier lists. ArreatSummit is smaller but with EHG endorsement.
- **Last Epoch Tools**: DB breadth and community features (profiles, ladders, auto-crawled builds). ArreatSummit doesn't compete on that breadth.
- **ArreatSummit wins at**: price guide (the only feature neither Maxroll nor LE Tools have integrated) and dungeon-specific guides with depth.

Many serious players use all three: Maxroll/LE Tools for builds, ArreatSummit specifically for the price guide before listing items.

## What people use it for

**Price check before listing an item in Bazaar**: go to Price Guide, pick the item type, see current price range. Critical for selling at the right price.

**Verify the value of a unique with LP**: the guide has a unique section with LP/WW value to help know if legendary crafting is worth it.

**Curated build guides**: for players who prefer fewer options but with strong quality control, ArreatSummit builds work.

**Merchant's Guild-specific loot filters**: the site has filters tuned for MG faction with sellable-item highlights.

**Dungeon strategies**: the dungeon guides have specific tactics that complement Maxroll's.

## Who it's NOT for

- **Players who want build variety**: Maxroll and LE Tools have larger libraries. ArreatSummit is more selective.
- **Deep DPS theorycrafters**: the planner doesn't compute as deep as PoB-LE. For min-max, complement it.
- **Circle of Fortune players**: the price guide is 100% Merchant's Guild centric. CoF players don't use trading, so that part doesn't apply.
- **Spanish speakers who want translated UI**: English only.

## How it's used in practice

1. Go to [arreatsummit.gg/last-epoch](https://arreatsummit.gg/last-epoch).

2. **For price check**: top menu → **Database** → **Prices** → pick item type → see table with LP/WW value and price range.

3. **For builds**: menu → **Build Guides** → browse by class and mastery.

4. **For filters**: menu → **Loot Filters** → pick one tuned for your faction and mastery → download.

5. **For dungeons**: menu → **Dungeons** → guide per dungeon with video walkthrough when applicable.

6. **For database**: menu → **Database** → items by category.

## Honest limitations

**Library smaller than Maxroll**: for build variety, can't compete with the editorial flagship.

**Price guide is delayed**: prices update from Sanctum Market Discord but with a multi-hour lag. For real-time deals, go directly to Discord.

**Light planner**: doesn't compete with PoB-LE for deep theorycraft. Useful for sharing builds, not for min-max.

**English only**: no localization.

**Cycle/Merchant's Guild focus**: for Eternal Realm or builds that ignore trading, other hubs cover better.

**Updates dependent on Sanctum Market**: if that Discord goes down or breaks, the price guide becomes outdated.

## How to start

1. [arreatsummit.gg/last-epoch](https://arreatsummit.gg/last-epoch). No signup.

2. **To start trading**: go to the Price Guide directly. It's the section with the most distinctive value.

3. **For builds**: menu **Build Guides** → sort by class → click one with a clear "Updated for Cycle X" header.

4. **For combos**: ArreatSummit + Maxroll together cover well. Read build on Maxroll, complement pricing with ArreatSummit.

5. **For joining Sanctum Market**: ArreatSummit links to the Discord. If you'll trade seriously, join — price-check channels are where live updates happen.

6. **Recommended bookmark**: the home `arreatsummit.gg/last-epoch` by default takes you to recent builds and guides.
