## Qué es

Icy Veins (icy-veins.com/last-epoch) es un hub editorial multi-juego que existe desde 2011 cubriendo WoW. Se expandió a Diablo III, D4, HSR y LE entre otros. La sección de LE está organizada por las cinco clases, con guides per mastery y endgame coverage.

Para LE provee:
- **Class Builds**: organizados por las 5 clases (Sentinel, Mage, Acolyte, Primalist, Rogue), con builds top per mastery.
- **News**: patch coverage y season previews.
- **Mechanics Guides**: guides específicos como Endless Arena, Merchant's Guild, crafting basics.
- **Beginner Resources**: getting started content para newcomers.

Free, sin login required.

## Qué problema resuelve

Para players que vienen de **WoW o D4** y ya conocen Icy Veins, su sección LE elimina la friction de aprender layout de nuevo hub: misma estructura visual, mismo tono editorial, misma jerarquía de información. Reduces context-switch cuando juegas varios títulos.

Para newcomers a LE, ofrece **alternative editorial voice** a Maxroll. Mucho jugador serio lee builds en ambos hubs para cross-validate: si Maxroll e Icy Veins dicen lo mismo, tienes alta confidence; si difieren, hay matiz interesante.

## Diferenciación vs Maxroll

- **Maxroll**: foco profundo en ARPG, más builds, más cadencia, leaderboard integrado, planner integrated. Más depth en LE específicamente.
- **Icy Veins**: cobertura multi-juego con MMO heritage, news section más periodística. Menos profundo en LE pero mismo estilo a través de games.

Ambos sirven a la misma audiencia; la elección suele venir por familiaridad previa. Si nunca usaste ninguno, Maxroll gana por depth pura en LE.

## Para qué la usa la gente

**Cross-check de builds**: Lees build en Maxroll, abres mismo equivalente en Icy Veins. Si concuerdan, confianza alta.

**News digest**: la sección News tiene formato journalistico (titular + summary + más detalle), útil para keeping up sin tener que browse Discord.

**Onboarding para WoW/D4 players**: si vienes de esos juegos, Icy Veins reduce friction.

**Class-specific deep dive**: cada clase tiene su landing page con build list, guides genéricos de la clase y leveling tips.

**Mechanics specifics**: para crafting basics, Merchant's Guild explanation, Endless Arena tutorial, Icy Veins tiene one-pagers que son entry-level perfect.

## Para quién NO es esta herramienta

- **Players que ya usan Maxroll**: redundancia. Para depth, Maxroll suficiente.
- **Theorycrafters**: Icy Veins no provee tools de simulación. Es content puro.
- **Players que quieren build variety amplia**: la library es más chica que Maxroll o LE Tools.
- **Hispanohablantes que quieren español**: Icy Veins originalmente tenía traducciones partial, ahora casi 100% inglés.

## Cómo se usa en la práctica

1. Anda a [icy-veins.com/last-epoch](https://www.icy-veins.com/last-epoch/).

2. **Para builds**: home → eliges clase → ves builds list de todas las masteries.

3. **Click en build**: la estructura es Overview → Skills → Passives → Gear → Idols → Mechanics → Leveling tips.

4. **Para news**: el sidebar lista latest articles. Patch notes analysis y season previews.

5. **Para mechanics**: home tiene sección de "Game Guides" con tutoriales de sistemas.

## Limitaciones honestas

**Library más chica que Maxroll**: para variedad de builds, Maxroll y LE Tools tienen más.

**Updates menos frecuentes que Maxroll**: post-patch, Icy Veins típicamente tarda 1-3 días en actualizar tier lists vs 24-48h de Maxroll.

**Foco menor en LE vs WoW/D4**: el sitio es generalist, no LE specialist. Si solo juegas LE, Maxroll te da más value.

**No tiene planner integrated**: para abrir un build en planner, te manda a third-party (LE Tools típicamente).

**Sin community features**: no hay comments, profiles, ladders. Solo content.

**Ads display**: nivel similar a Maxroll. Manejable con adblock.

## Cómo empezar

1. [icy-veins.com/last-epoch](https://www.icy-veins.com/last-epoch/). Sin signup.

2. **Para empezar**: home → eliges clase. Ves landing de esa clase con builds y guides.

3. **Si vienes de WoW/D4**: el layout te resulta familiar al instante.

4. **Combos recomendados**: Icy Veins + Maxroll juntos. Si los dos te dicen lo mismo, tienes signal claro.

5. **Para news**: bookmark la home — el sidebar de "Latest News" se actualiza con cada artículo.

6. **Mobile-friendly**: la UI funciona bien en mobile, mejor que Maxroll en pantalla chica.
