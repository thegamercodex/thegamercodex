## Qué es

Forum.lastepoch.com es el forum oficial de Last Epoch hosteado y operado directamente por Eleventh Hour Games. Existe desde Early Access (2018+) y archiva discussions completas desde then.

Secciones principales:
- **Developer Blogs**: long-form posts de devs explicando design decisions, philosophy, future plans.
- **Announcements**: official news (subset de lo que también va a Discord).
- **General Discussion**: discussion casual con tone más serious que Reddit.
- **Builds**: forum-hosted build sharing. Tiene el "Build Compendium" curado.
- **Bug Reports**: formal bug submission con templates.
- **Feedback and Suggestions**: estructurado feedback para devs.
- **Class subforums**: discussion específica per clase.

Free para read; signup gratuito requerido para post.

## Qué problema resuelve

**Discussions persistentes y searchable**: lo que se postea en forum queda forever y aparece en Google search. Discord y Discord no tienen ese archive quality.

**Dev blogs accesibles**: cuando devs quieren explicar design decisions extensamente, lo hacen via forum (no via Discord ni Twitter). Estos posts son ground truth.

**Bug reports estructurados**: el bug report template force fields como repro steps, version, severity — útil para devs ingestar reports.

**Build compendium curado**: el "Last Epoch Build Compendium" thread es one of the most useful — lists all community builds en single thread, updated regularly. Mejor que Reddit search.

**Tone más serio que Reddit/Discord**: para discussion ojo a depth sin meme noise, forum es mejor.

## Para qué la usa la gente

**Read dev blogs**: cuando EHG announce nueva mechanic, dev blog tiene depth que announcement summary no.

**Postear bug report formal**: para issues que afectan progress, forum bug report sirve mejor que Discord para tracking.

**Browse Build Compendium**: pinned thread con lista master de builds community. Click links para abrir builds individuales.

**Feedback estructurado**: para sugerencias de design changes, post en Feedback section con argumentación.

**Search histórica**: Necesitas info de patch 0.9 → forum search la encuentra. Discord no.

## Para quién NO es esta herramienta

- **Players que quieren chat real-time**: forum es asíncrono, response time horas-días.
- **Casuales que no van a postear**: para solo browsing, Reddit más cómodo.
- **Quienes prefieren modern Reddit-style UI**: forum es Discourse-based, funcional pero dated.

## Cómo se usa en la práctica

1. Anda a [forum.lastepoch.com](https://forum.lastepoch.com/).

2. **Read sin signup**: scroll latest threads o navega secciones.

3. **Para post**: signup → email verification → ready.

4. **Para dev blog reading**: section "Developer Blogs" → ordenas por latest.

5. **Para Build Compendium**: search "Build Compendium" → pinned thread aparece → expandes.

6. **Para bug report**: section "Bug Reports" → New Topic → template aparece auto.

7. **Para search**: top right search funciona bien para keywords.

## Limitaciones honestas

**Response time slow**: posts pueden tardar horas-días en recibir engagement.

**Activity lower que Discord/Reddit**: hard core users prefer those platforms.

**UI dated**: Discourse es funcional pero feels old comparado con modern social platforms.

**No notifications efectivos**: forum sí tiene notification system pero la mayoría de users no se setea.

**Discoverability menor que Reddit**: Google indexa forum threads pero ranking suele ser menor que Reddit.

**Sin mobile app dedicada**: forum funciona en mobile browser pero no es app-quality experience.

## Cómo empezar

1. [forum.lastepoch.com](https://forum.lastepoch.com/). Sin signup para read.

2. **Para signup**: top right → register → email verify.

3. **Setup**: Lee pinned messages de "Welcome" → understand forum structure y rules.

4. **Para dev blogs**: bookmark "Developer Blogs" section → check post-patch porque ahí van dev explanations.

5. **Para builds**: bookmark Build Compendium thread.

6. **Combo recomendado**: forum para dev blogs y formal posts + Discord para real-time + Reddit para meta debate.

7. **Notifications**: una vez signup, configura notifications de threads que track y mention notifications.
