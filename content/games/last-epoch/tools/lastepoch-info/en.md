## What it is

Last Epoch Info (lastepoch.tunklab.com) is the LE section of TunkLab, a gaming-focused database platform. It maintains an exhaustive mechanics database with dedicated calculators that don't exist anywhere else.

It provides:
- **Equipment Database**: items by type (helmets, body armor, weapons, etc.) with stat ranges.
- **Affixes**: prefixes and suffixes with tier breakdowns and class restrictions.
- **Unique Items**: complete catalog with stats and notes.
- **Skills**: full per-skill active tree with nodes and effects.
- **Classes**: passive trees per class and mastery.
- **Monolith Timelines**: the 10 Monolith timelines with which blessings roll where.
- **Factions**: Merchant's Guild and Circle of Fortune info (ranks, prophecies).
- **Calculators**: defense, ward, damage — input stats and see precise outputs.

Free, no login.

## What problem it solves

For theorycrafters: when you're optimizing ward stacking or computing defense layers, you need to know **exactly** how each stat is calculated — what's additive, what's multiplicative, what order of operations applies. TunkLab has this documented with calculators that let you input values.

For builders who want to know **all the affixes that can roll on a specific slot**, TunkLab has the cleanest table (better than Last Epoch Tools for this specific task).

For curious players about **monolith blessings**: the table of which blessings roll in which timeline is required reading for planning progression.

## How it differs from Last Epoch Tools

- **TunkLab**: pure database + calculators. No planner or builds. Technical UI, no editorial sparkline.
- **Last Epoch Tools**: database + planner + builds + community features. Friendly UI, more casual.

Ideal use case: TunkLab for specific lookups ("what affixes can this item base roll"), LE Tools for everything else.

## What people use it for

**Defense calculator**: input base HP, armor, dodge, glancing blow, resistances and see exact effective HP. Critical for validating whether your build survives Tier 4 corruption.

**Ward calculator**: input ward decay rate, generation, max ward and see per-second dynamics. Ward is one of LE's most complex stats; this is the only calculator that computes it correctly.

**Damage calculator**: input base damage, multipliers, conditional bonuses and see final output. Useful for verifying claims without installing PoB.

**Affix lookup by slot**: go to Equipment → pick base type → see all possible affixes with their ranges.

**Blessings of timeline X**: the monolith section tells you which blessings roll where, useful for targeting during echoes.

## Who it's NOT for

- **Casuals who just want to copy a build**: TunkLab doesn't tell you which build to use. Just data. Go to LE Tools or Maxroll.
- **Players who want a pretty UI**: TunkLab is functional but spartan. Raw tables, little styling.
- **Players who want interactive build planning**: there's no planner. Lookup only.
- **Spanish speakers**: English only.

## How it's used in practice

1. Go to [lastepoch.tunklab.com](https://lastepoch.tunklab.com/).

2. **For item lookup**: menu → **Equipment** → filter by type → pick base → see possible affixes.

3. **For a specific affix**: menu → **Affixes** → search by name → see tier range and restrictions.

4. **For a unique**: menu → **Uniques** → search by name or filter by slot.

5. **For a full skill tree**: menu → **Skills** → pick skill → see all nodes and effects.

6. **For a calculator**: menu → **Tools** → pick specific calc → input stats → output.

7. **For monolith**: menu → **Monolith** → see timelines and blessings.

## Honest limitations

**Dated UI**: the design is functional but not modern. Raw tables, navigation with less polish than LE Tools.

**No planner or builds**: don't use as your primary hub. Must be a complement to another tool.

**No community features**: no sharing, profiles, ladders.

**Updates depend on TunkLab**: the site is a secondary project for the operator (who also maintains PoEDB). If TunkLab is busy on another game, LE updates can lag 1-2 weeks.

**No global search**: each section has its own search. Searching across categories requires extra clicks.

**Not mobile-first**: usable on mobile but designed for desktop.

## How to start

1. [lastepoch.tunklab.com](https://lastepoch.tunklab.com/). No signup.

2. **To begin**: home has cards to each section. Pick what you need.

3. **For theorycrafters**: bookmark Tools/Calculators directly. It's the only site that offers those specific calcs.

4. **For quick lookups**: use the search within each section.

5. **Recommended combo**: TunkLab for specific lookups + LE Tools for everything else. Together they cover database needs 100%.
