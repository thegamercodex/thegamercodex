## Qué es

Maxroll (maxroll.gg/last-epoch) es la sección de LE del hub editorial Maxroll, un equipo profesional que combina creators conocidos con staff dedicado a publicar guías curadas. Cubre ARPGs cross-game: PoE 1, PoE 2, D4, LE, D2R y Lost Ark, con editorial team compartido entre todos.

Para LE específicamente provee:
- **Build guides**: extensos por mastery, con sección de leveling + endgame + push variants.
- **Build planner**: planner web integrado donde los builds publicados se cargan automáticamente.
- **Tier lists**: clase tier list y build tier list, actualizadas patch tras patch.
- **Getting Started**: guides para newcomers cubriendo campaña, choice de clase, primer endgame.
- **Monolith & Dungeons**: guides específicos de Monolith of Fate (beginner + advanced), de cada dungeon (Lightless Arbor, Soulfire Bastion, Temporal Sanctum) y boss strategies.
- **Leaderboards**: community-maintained leaderboard actualizado cada pocos minutos, alternativa a la ladder oficial.
- **News**: análisis editorial de patches y season previews.

Free para read. Login opcional para favorites y comments.

## Qué problema resuelve

LE tiene complexity intermedio entre D4 (fácil) y PoE (extremo). Para un newcomer, el sistema de 15 masteries con árboles de pasivas independientes por skill puede paralyze — no sabes por dónde empezar.

Maxroll resuelve esto con curaduría editorial fuerte: vas, eliges clase, ves los top builds del cycle actual con tier rating, abres el build y tienes leveling path + endgame + paragon-equivalent (blessings/passive points) en una página única. Ahorra días vs assembling info desde Reddit.

Para players intermedios/avanzados, los guides de **Monolith of Fate** y **Empowered Monolith** son referencia obligatoria: explican blessing targeting, corruption push strategy, y boss strategies con depth que ningún otro hub provee.

## Diferenciación vs Last Epoch Tools

Los dos son los hubs grandes de LE, pero con enfoque opuesto:

- **Maxroll**: depth editorial. Builds publicados por staff con prose larga y justification per slot. Tier lists con análisis. Si recién empiezas o quieres entender el por qué del build, Maxroll.
- **Last Epoch Tools**: amplitud comunitaria. Auto-crawled builds, DB exhaustiva, planner sin curation. Si quieres scan rápido de meta o ver muchas builds variantes, LE Tools.

La mayoría de jugadores usa los dos: Last Epoch Tools para inspección rápida y DB lookups; Maxroll para el guide profundo del build elegido.

## Para qué la usa la gente

**Elegir mastery pre-cycle**: 2 semanas antes del season start, miras Class Tier List y Build Tier List de Maxroll para ver qué mastery está fuerte y planificas tu fresh character.

**Leveling build**: el guide te da leveling path optimal (skills en orden, gear baseline, blessings target) desde lvl 1 hasta endgame transition (~lvl 70).

**Endgame optimization**: una vez en cap, lees variants del build (push variant, farm variant, boss kill variant) y eliges según objective.

**Monolith planning**: el Empowered Monolith Guide explica order de timeline completion, blessing priority por timeline y corruption push strategy. Crítico para optimizar character.

**Patch reaction**: post-balance change, Maxroll actualiza tier lists en horas. Si tu build sobrevivió o si toca rerolear, te enteras ahí.

**Crafting deep dives**: guides específicos sobre legendary potential, weaver's will, sealed affixes — mecánicas de crafting que el juego enseña pobremente.

## Para quién NO es esta herramienta

- **Theorycrafters extremos**: el planner integrado es bueno pero no es Path of Building. Para simulación DPS profunda complementar con PoB for LE.
- **Hispanohablantes que quieren español**: Maxroll es inglés solamente. No hay localización.
- **Mobile-first players**: la UI es desktop-first. Los guides extensos son difíciles de leer en pantalla chica.
- **Lore enthusiasts**: este es technical content. Para lore profundo, ir a wikis (lastepoch.wiki, fandom).
- **Off-meta theorycrafting**: las builds publicadas son las "canónicas" del patch. Si quieres ver builds creativas no-meta, Last Epoch Tools tiene más variedad.

## Cómo se usa en la práctica

1. Anda a [maxroll.gg/last-epoch](https://maxroll.gg/last-epoch).

2. **Browse por clase**: menu top → **Classes** → eliges tu clase. Ves todas las masteries con builds publicados.

3. **Click en el build**: la página tiene secciones — Overview, Skills, Passives, Idols, Gear, Mechanics, Leveling, Endgame.

4. **Abre el planner del build**: link en cada guide. Lo puedes clonar a tu account para modificar.

5. **Para tier lists**: menu top → **Tier Lists** → Class o Build tier list. Cada entry tiene link al guide correspondiente.

6. **Para Monolith**: menu top → **Monolith** → Beginner Guide → Empowered Guide. Lee los dos antes de empezar Empowered.

7. **Para Dungeons**: menu top → **Dungeons** → guide por dungeon con boss strategies.

8. **Para news/patches**: home → ves latest articles incluyendo patch analysis y season previews.

## Limitaciones honestas

**Foco en endgame**: aunque hay leveling content, lo más detallado es endgame. Para los primeros 50 niveles cualquier build de Maxroll funciona — ahí la curaduría es ligera.

**Build variety limitada por curation**: solo publican builds que pasan el filtro editorial. Para builds creativas off-meta, Last Epoch Tools tiene más variedad.

**Updates rápidos pero no inmediatos**: post-patch típicamente toma 24-72 horas tener tier lists fully revised. Para reaction inmediata, mejor seguir Discord/Twitter de Maxroll team.

**Ads display**: hay banner ads y newsletter prompts. Manejable con adblock; no llega al nivel intrusivo de algunos competidores.

**Sin sistema de filter editor**: Maxroll te da filters publicados como archivos download, pero no tiene editor visual integrado. Para crear/editar tu propio filter, ir a Last Epoch Tools.

## Cómo empezar

1. [maxroll.gg/last-epoch](https://maxroll.gg/last-epoch). Sin registro para read.

2. **Si recién empiezas LE**: ve a **Getting Started** → Beginners Guide. Después **Class Tier List** para elegir mastery.

3. **Una vez elegida mastery**: Abre el build top-tier de esa mastery. Lee la sección **Leveling** primero, no la endgame.

4. **Importa el planner** si quieres modificar el build a tu situación.

5. **En endgame**: vuelve a leer las secciones **Endgame** y **Idols/Blessings** del guide para refinar.

6. **Empowered prep**: Lee Empowered Monolith Guide antes de hacer push de corruption.

7. **Bookmark Maxroll** y revísalo weekly durante season activa para tier list shifts.

8. **Para Q&A**: el Discord de Maxroll team está activo y los authors de los guides responden ahí.
