## Qué es

aRPG Timeline (arpg-timeline.com) es un tracker multi-game de seasons para Action RPGs. Cobertura incluye PoE 1, PoE 2, D4, LE y otros community-tier games. Para LE específicamente trackea cada cycle (S1, S2, S3, S4, ...) con start date y countdown live.

Features principales:
- **Per-game pages**: cada juego tiene su page con history de seasons y current/next launch.
- **Multi-game dashboard**: vista comparativa de cuándo arranca cada juego.
- **iCal subscription**: te subscribís al calendar URL → seasons aparecen automáticamente en tu Google/Apple/Outlook calendar.
- **Countdowns live**: en cada page hay timer hacia próximo launch.
- **Community catalog**: además de games mainstream, lista juegos comunitarios menos conocidos.

Free, sin signup.

## Qué problema resuelve

Si juegas varios ARPGs en rotación, planificar cuándo cuál arranca es difícil — cada juego anuncia su season en su propio site/Discord/Twitter. Cosa de oír por error que PoE arrancó "ayer" cuando ya planeabas levear LE.

aRPG Timeline soluciona esto con un single source para todos: una pagada, ves cuándo arranca cada juego, planeas rotación. La calendar subscription extends esto — sin tener que abrir el site, recibes alertas en tu calendario normal.

Para LE específico, también trackea history de cycle starts pasados — útil para predecir el próximo cycle si EHG todavía no anunció official date.

## Para qué la usa la gente

**Plan de rotation gaming**: ves cuándo arranca cada ARPG → decidís si vas a hacer fresh char en LE este cycle o esperas PoE.

**Alert de season start**: subscribís al iCal → recibes recordatorio 1 día antes del launch.

**Verificar historic timing**: Quieres saber cuánto duró el cycle pasado → la page muestra dates.

**Discovery de games**: si solo conocés mainstream, el community catalog tiene games menos famosos que podrían interesarte.

**Compartir con friends**: linkear la página de LE a un grupo de Discord para coordinar fresh char start.

## Para quién NO es esta herramienta

- **Players de un solo juego**: si solo juegas LE y nada más, el dev tracker oficial o announcements del Discord cubre.
- **Quienes no usan calendar apps**: el feature killer es la iCal sub. Sin ella, son menos useful.

## Cómo se usa en la práctica

1. Anda a [arpg-timeline.com/game/last-epoch](https://www.arpg-timeline.com/game/last-epoch).

2. **Ves countdown**: timer hacia próximo cycle.

3. **Subscribís al calendar**: link "Calendar Subscription" → copias URL iCal → pegas en Google/Apple/Outlook como subscribed calendar.

4. **Para multi-game view**: home page tiene dashboard con todos los games.

5. **Para history**: scroll en la page de LE para ver cycles pasados con sus dates.

## Limitaciones honestas

**Depende de announcements oficiales**: si EHG no announce date oficial todavía, aRPG Timeline pone "TBA" o estimate. No es Crystal ball.

**Sin notification proactiva**: el iCal te avisa en el calendar, pero no hay push notification o email alert default.

**Sin community features**: no hay comments, ratings, custom calendars per user.

**Sin info de patches mid-cycle**: solo trackea cycle starts. Para hotfixes/patches durante cycle, ir a dev tracker.

**Sin localización**: inglés solamente, aunque la info es mostly fechas/numbers.

## Cómo empezar

1. [arpg-timeline.com/game/last-epoch](https://www.arpg-timeline.com/game/last-epoch). Sin signup.

2. **Setup ideal**: copia el URL iCal → pega en Google Calendar como "Add by URL" → seasons aparecen automáticamente.

3. **Para rotation multi-game**: bookmark home page (arpg-timeline.com).

4. **Combo recomendado**: aRPG Timeline para season planning, LE Dev Tracker para mid-cycle updates.

5. **Mobile-friendly**: la UI funciona bien en mobile, útil cuando estás revisando dates rápido.
