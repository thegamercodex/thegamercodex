## What it is

Speedrun.com/last_epoch is Last Epoch's official page on speedrun.com, the reference platform for speedrun records. It maintains leaderboards per category with video-verified runs.

Main categories:
- **Any% Mastery**: complete the character's mastery (~20-50min PB).
- **Any% Idols and Passives**: complete the specific unlock quest (~1-2h).
- **Any% Campaign**: complete the entire campaign (~2-4h).
- **Any% Empowered Monolith**: reach Empowered Monolith state.
- **Misc / Legacy**: old-patch categories (Pre 0.9.1, Pre 0.8.3) for legacy interest.

Every run has video proof requirement, strategy writeup, and verification by community mods.

Free, no signup to read; signup to submit runs.

## What problem it solves

**Record verification**: if you want to know the current LE campaign world record, this is the single source. Without it, claims would be unverifiable.

**Strat sharing between runners**: every run comes with a strategy writeup → other runners can study what works.

**Optimization inspiration**: watching top runs proves what's achievable, shaving minutes off your PB → motivation.

**Category discovery**: there are old-patch categories some players still run for nostalgia (Pre 0.8.3 was the EA era).

## What people use it for

**Track world records**: when someone claims a PB, verify it against the leaderboard.

**Study a specific runner's run**: every runner profile has its run history with videos.

**Submit your run**: got a PB → record the run → submit with video proof.

**Learn route optimization**: top runs have written guides with optimized routes.

**Find the speedrun community**: the game's subforum on speedrun.com has runner-specific discussion.

## Who it's NOT for

- **Casual players**: speedrunning is niche. If you only play for loot and endgame, this doesn't apply.
- **Players who don't record gameplay**: submitting runs requires video. Without a recording setup, you can't contribute.
- **Those who don't read English**: the community operates almost exclusively in English.

## How it's used in practice

1. Go to [speedrun.com/last_epoch](https://www.speedrun.com/last_epoch).

2. **To see leaderboards**: click a category → ascending-sorted leaderboard.

3. **For video proof**: click a run → modal with embedded video.

4. **For guides**: "Guides" tab → community-written strategy guides.

5. **For forums**: "Forums" tab → game-specific discussion.

6. **To submit**: signup → upload the run → fill submission form → wait for mod verification.

## Honest limitations

**Small community**: ~50 active runners, ~89 total runs. No mass competition.

**Categories change with patches**: when there's a major patch, leaderboards sometimes wipe (happened with 0.9.1, 0.8.3). Legacy boards exist for old runs.

**Variable verification time**: your submission can take days to be verified if mods are busy.

**No live tracking**: only completed runs. No current attempts/PB tracking.

**No community features beyond leaderboards and forum**: no real-time chat, no Discord linked directly.

**Limited mobile-friendly**: speedrun.com is desktop-first.

## How to start

1. [speedrun.com/last_epoch](https://www.speedrun.com/last_epoch). No signup to read.

2. **To get interested**: watch top runs of each category → read related guides.

3. **To attempt speedrunning**: setup recording (OBS typically) → run the shortest category first (Any% Mastery).

4. **To submit**: signup on speedrun.com → upload video to YouTube → submit with URL.

5. **Recommended combo**: speedrun.com + LE Discord (#speedrun channel if it exists) + Twitch streams of runners.

6. **For community**: the game's forums section has specific discussion.
