## Qué es

Speedrun.com/last_epoch es la página oficial de Last Epoch en speedrun.com, la plataforma referencia para speedrunning records. Mantiene leaderboards por categoría con runs verified video.

Categorías principales:
- **Any% Mastery**: completar mastery del personaje (~20-50min PB).
- **Any% Idols and Passives**: completar quest specific de unlock (~1-2h).
- **Any% Campaign**: completar campaña entera (~2-4h).
- **Any% Empowered Monolith**: reach Empowered Monolith state.
- **Misc / Legacy**: categorías de patches viejos (Pre 0.9.1, Pre 0.8.3) para legacy interest.

Cada run tiene video proof requirement, descripción de strat, y verification por mods de la community.

Free, sin signup para read; signup para submit runs.

## Qué problema resuelve

**Verificación de records**: si quieres saber el actual world record de campaña LE, esta es la single source. Sin esto, claims serían unverifiable.

**Strat sharing entre runners**: cada run viene con writeup de strategy → otros runners pueden study lo que funciona.

**Inspiration para optimization**: ver runs top sentencia que es achievable shaves minutes de tu PB → motivación.

**Discovery de categorías**: hay categorías de patches viejos que algunos players todavía corren por nostalgia (Pre 0.8.3 era del juego en EA).

## Para qué la usa la gente

**Track world records**: cuando alguien claims PB, verificas contra leaderboard.

**Study run de un runner específico**: cada perfil de runner tiene su run history con videos.

**Submit your run**: si conseguiste PB → record run → submit con video proof.

**Learn route optimization**: top runs tienen written guides con routes optimizadas.

**Find speedrun community**: el subforum del juego en speedrun.com tiene discussion runner-specific.

## Para quién NO es esta herramienta

- **Players casuales**: speedrunning es nicho. Si solo juegas por loot y endgame, esto no aplica.
- **Players que no graban gameplay**: submit runs requiere video. Sin setup recording, no puedes contribuir.
- **Quienes no leen English**: la comunidad opera en inglés casi exclusivamente.

## Cómo se usa en la práctica

1. Anda a [speedrun.com/last_epoch](https://www.speedrun.com/last_epoch).

2. **Para ver leaderboards**: click en categoría → leaderboard sorted ascending.

3. **Para video proof**: click en run → modal con video embed.

4. **Para guides**: tab "Guides" → community-written strategy guides.

5. **Para forums**: tab "Forums" → discussion específica del juego.

6. **Para submit**: signup → upload run → fill submission form → wait for mod verification.

## Limitaciones honestas

**Community chica**: ~50 runners activos, ~89 runs en total. No hay competition mass.

**Categorías cambian con patches**: cuando hay major patch, leaderboards a veces wipe (pasó con 0.9.1, 0.8.3). Hay legacy boards para old runs.

**Verification time variable**: tu submission puede tardar días en ser verified si mods están busy.

**Sin live tracking**: solo runs completed. No hay current attempts/PB tracking.

**Sin community features fuera de leaderboards y forum**: no chat real-time, no Discord linked directly.

**Mobile-friendly limited**: speedrun.com es desktop-first.

## Cómo empezar

1. [speedrun.com/last_epoch](https://www.speedrun.com/last_epoch). Sin signup para read.

2. **Para empezar interest**: ver top runs de cada categoría → leer guides relacionados.

3. **Para attempt speedrunning**: setup recording (OBS típicamente) → run categoría más corta primero (Any% Mastery).

4. **Para submit**: signup en speedrun.com → upload video a YouTube → submit con URL.

5. **Combo recomendado**: speedrun.com + LE Discord (channel #speedrun si existe) + Twitch streams de runners.

6. **Para community**: forums section del game tiene discussion específica.
