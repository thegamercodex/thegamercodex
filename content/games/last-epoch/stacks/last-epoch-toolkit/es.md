Last Epoch tiene la profundidad de build de un ARPG serio —árbol de pasivas, especialización de skills, crafteo dirigido— pero el cliente apenas te acompaña a planearla. Como en otros ARPG, los jugadores que aprovechan cada cycle se apoyan en herramientas externas para diseñar, simular y referenciar sus builds. Este stack de cinco cubre ese ciclo de punta a punta.

## El flujo de un cycle

La elección de build empieza en **Maxroll (Last Epoch)**: guías editoriales con leveling y endgame que te dan un plan claro desde el día uno. Para diseñar o modificar la tuya, **Last Epoch Tools** es el planner y la base de datos central —árbol de pasivas, skills e items en una sola herramienta. Y para validar que la build aguanta, **Path of Building (Last Epoch)**, el fork del clásico de PoE, simula tu DPS y defensas con detalle.

Cuando buscas piezas concretas, **Last Epoch Info** es la base de datos de items, uniques y afijos, para saber exactamente qué perseguir. Y para no perderte el contenido nuevo, **ARPG Timeline** te da las fechas de cycles y eventos, útil para planear cuándo volver al juego.

## Por qué estas cinco

Cada una cubre una etapa del cycle:

- **Guías de build** → Maxroll
- **Planner y base de datos** → Last Epoch Tools
- **Simulación de DPS** → Path of Building (LE)
- **Referencia de items** → Last Epoch Info
- **Calendario de cycles** → ARPG Timeline

No necesitas las cinco para jugar, pero juntas convierten el armado de personaje en algo planificado en vez de prueba y error. Cada herramienta tiene su análisis completo en el codex.
