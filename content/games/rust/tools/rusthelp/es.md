## Qué es

RustHelp es un dashboard web gratuito que combina varias herramientas en una sola interfaz: wiki de items, raid calculator, crosshair generator, recycler calculator y tracker del weekly skin store. Mantenido por un equipo pequeño, free, sin login. La presentación apunta a ser todo-en-uno antes que profunda en cada área.

## Qué problema resuelve

Hay tools sueltas para cada cosa: una para raid calc, otra para crosshair, otra para recycler, otra para skins. RustHelp consolida lo más usado en una sola web. Si solo abres Rust 2-3 veces por semana y no quieres juggle bookmarks, esto te sirve.

## Diferenciación

Frente a RustLab, RustHelp es más ligero y trae tools auxiliares (crosshair, recycler) que RustLab no cubre, pero su items database es menos completa y su raid calculator más simple. Frente a Corrosion Hour, RustHelp no tiene guías editoriales — solo data y calculators. La mejor metáfora: RustHelp es un cuchillo suizo, RustLab es un set de cuchillos especializados.

## Para qué la usa la gente

- **Raid calculator rápido**: meter el target y ver costos en C4, rockets, satchel, beancan.
- **Crosshair generator**: configurar y exportar crosshair custom para Rust (es config legal, parte del cliente).
- **Recycler calculator**: meter items que vas a reciclar y ver qué recursos sales.
- **Weekly skin store tracker**: ver qué skins están a la venta esta semana en el Item Store, con precios.
- **Items lookup ligero**: stats básicos sin ir a una db más pesada.

## Para quién NO es esta herramienta

Si planeas raids complejos o quieres data exacta de monumentos, RustLab y Corrosion Hour son mejores. Si solo necesitas el wipe schedule global, RustLab lo cubre con más filters. Si juegas competitivo y necesitas crosshair generator más fino, hay clientes dedicados — RustHelp es la opción "que funciona y ya".

## Cómo se usa en la práctica

1. Entras a rusthelp.com, sin registro.
2. El home agrupa las tools por categoría (Tools, Wiki, Skins).
3. Para crosshair, "Crosshair" lleva a un editor visual con preview.
4. Para raid calc, "Raid Calculator" abre el tool standalone.
5. Para items, "Wiki" tiene buscador básico.

## Limitaciones honestas

- **Items database menos completa que RustLab**: items recién agregados pueden faltar.
- **Sin guías largas**: no hay contexto editorial, solo data y calculators.
- **Solo inglés**: sin localización.
- **Skin tracker no es precio histórico**: solo skins disponibles esta semana, no histórico de precios.

## Cómo empezar

Bookmark a rusthelp.com. Si solo vas a usar una tool específica (crosshair generator o recycler calc), bookmark directo a esa sub-page evita ruido del home.
