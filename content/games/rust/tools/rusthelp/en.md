## What it is

RustHelp is a free web dashboard that bundles several tools into one interface: items wiki, raid calculator, crosshair generator, recycler calculator, and weekly skin store tracker. Maintained by a small team, free, no login. The presentation aims for all-in-one rather than depth in any one area.

## What problem it solves

There are scattered tools for each thing: one for raid calc, another for crosshair, another for recycler, another for skins. RustHelp consolidates the most-used into one site. If you only open Rust 2-3 times a week and don't want to juggle bookmarks, this works.

## Differentiation

Against RustLab, RustHelp is lighter and brings auxiliary tools (crosshair, recycler) that RustLab doesn't cover, but its items database is less complete and its raid calculator simpler. Against Corrosion Hour, RustHelp has no editorial guides — only data and calculators. The best metaphor: RustHelp is a Swiss army knife, RustLab is a set of specialized knives.

## What people use it for

- **Quick raid calculator**: enter the target and see costs in C4, rockets, satchel, beancan.
- **Crosshair generator**: configure and export a custom crosshair for Rust (it's legal config, part of the client).
- **Recycler calculator**: enter items you'll recycle and see what resources you'll get out.
- **Weekly skin store tracker**: see what skins are for sale this week in the Item Store, with prices.
- **Light items lookup**: basic stats without going to a heavier database.

## Who this isn't for

If you plan complex raids or want exact monument data, RustLab and Corrosion Hour are better. If you just need the global wipe schedule, RustLab covers it with more filters. If you play competitive and need a finer crosshair generator, there are dedicated clients — RustHelp is the "it works, move on" option.

## How to use it

1. Open rusthelp.com, no registration.
2. The home groups tools by category (Tools, Wiki, Skins).
3. For crosshair, "Crosshair" leads to a visual editor with preview.
4. For raid calc, "Raid Calculator" opens the standalone tool.
5. For items, "Wiki" has basic search.

## Honest limitations

- **Items database less complete than RustLab**: recently added items can be missing.
- **No long-form guides**: no editorial context, just data and calculators.
- **English only**: no localization.
- **Skin tracker isn't price history**: only this week's available skins, no historical price tracking.

## Getting started

Bookmark rusthelp.com. If you'll only use one specific tool (crosshair generator or recycler calc), bookmarking directly to that subpage avoids home page noise.
