## Qué es

Codefling es un marketplace web para Rust mods: plugins, mapas custom, prefabs, models. Es paid-first — la mayoría del contenido cuesta entre $5 y $50, con algunos plugins premium en $100+ para enterprise hosts. Lanzado para llenar el gap que uMod dejaba (no acepta plugins paid), Codefling permite a devs monetizar su trabajo. Incluye sistema de support (devs responden tickets), updates lifetime con la compra, y refunds con policy razonable.

## Qué problema resuelve

uMod tiene 1400+ plugins gratis, pero la gran mayoría son hechos por hobbyists. Los plugins más complejos (economy systems con multi-currency, anti-cheat avanzado, custom raid systems, GUI panels) requieren cientos de horas de desarrollo, y los devs serios no los regalan. Codefling es donde esos plugins viven. Lo mismo con mapas: un custom map de calidad lleva 50-100+ horas de trabajo y se vende típicamente entre $20-50.

## Diferenciación

Frente a uMod (free), Codefling cubre el segment "premium": plugins más pulidos, support real, mapas que no encuentras free. Frente a comprar de devs sueltos (DM en Discord, scattered websites), Codefling estandariza: payment seguro, refunds, ratings, support tickets. Carbon recently se integró con Codefling para que las compras se instalen seamless. Para un admin serio, Codefling reduce dramatically el friction de adquirir y mantener plugins paid.

## Para qué la usa la gente

- **Plugins premium**: economy systems (Server Rewards, Bank), advanced anti-cheat (anti-EAC-bypass), custom raid systems, GUI dashboards.
- **Custom maps**: mapas de calidad para wipes especiales, con monumentos custom, puzzles, lore.
- **Prefabs sueltos**: monumentos individuales, buildings, decorations para complementar maps procedurales.
- **Models y skins**: model packs para weapons custom, NPC custom, mounts custom.
- **Bundle deals**: developers releasean bundles con descuento (ej: "Full Economy Pack" con shop + currency + jobs por $30).

## Para quién NO es esta herramienta

Si solo arrancas con server vanilla o lightly modded, los plugins free de uMod cubren todo. Si tienes budget cero, Codefling no es opción. Si dependés de plugins que ya están deprecados en Codefling (el seller pasó de mantener), refund o re-purchase con otro seller.

## Cómo se usa en la práctica

1. Entras a codefling.com, registrar cuenta.
2. Browsear por categoría: Plugins, Maps, Prefabs, Tools.
3. Cada item tiene preview, reviews, changelog y dev info.
4. Compra via Stripe o PayPal — recibes el file en tu account dashboard.
5. Para installar: download el .cs (plugin) o .map (map) y drop en la carpeta correcta del server (Oxide o Carbon).
6. Updates: dev publica nueva versión, vos download desde tu dashboard y reemplazás el file viejo.

## Limitaciones honestas

- **Cuesta plata**: no hay free tier. Plugins típicos $10-30, mapas $20-50.
- **Calidad varía por dev**: algunos sellers son responsivos y actualizan rápido, otros publican y desaparecen.
- **Refund policy es razonable pero finite**: típicamente 7-14 días con razones específicas (broken plugin, no support response).
- **Plugin paid puede romperse con parche**: si el dev abandonó, te quedaste con file useless hasta que otro venda equivalente.
- **Algunos plugins requieren plugins free de uMod como dependencies**: leer changelog del item antes de comprar.

## Cómo empezar

Para evaluar: navegar Codefling sin comprar, ver qué plugins resuenan con problemas que tienes. Para primer compra: empezar con algo cheap ($5-15) para entender el flow de purchase + install + support. Si juegas server modded grande, suscribirse al newsletter de Codefling te avisa de bundles y sales.
