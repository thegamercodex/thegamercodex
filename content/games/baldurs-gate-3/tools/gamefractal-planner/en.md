## What it is

GameFractal Character Builder is a Baldur's Gate 3 character planner that stands out for integrating a large catalog of items and boons into the build process. It runs free in the browser and also exists as an Overwolf app, which turns it into an in-game overlay.

Beyond the standard race, class, multiclass, and stats setup, GameFractal lets you fold concrete gear pieces into the build and generate a shareable link for any configuration. It covers BG3 and other games from the same domain.

## What problem it solves

In BG3 many builds are defined not just by class but by gear: an item that grants a spell level, gloves that change how damage scales, an amulet that enables a combo. A planner that ignores items leaves you with half the picture.

GameFractal targets exactly that: it lets you plan around the gear you intend to get, not just around class progression. That makes it especially useful for second-playthrough builds, where you already know what loot exists and want to squeeze it.

## Differentiation

Against EIP, GameFractal puts gear at the center. EIP is faster for deciding class structure; GameFractal is better when the build revolves around specific pieces and you want them integrated into the view.

Against BG3 Compendium, both handle inventory, but GameFractal adds the Overwolf overlay, which is the key difference if you like keeping reference on top of the game without alt-tabbing.

## What people use it for

**Planning item-dependent builds**: folding in concrete gear pieces and seeing how they affect the build.

**Using the in-game overlay**: keeping the plan visible on top of BG3 via Overwolf while you execute the level-up.

**Sharing builds by link**: passing a full configuration to someone with a single URL.

**Browsing the catalog**: using the item and boon database as reference while deciding the build's direction.

**Planning characters for a replay**: optimizing knowing in advance what loot you'll find.

## Who this tool is NOT for

If you're just starting and don't yet want to think about gear, the item catalog can feel like noise; EIP or Compendium are cleaner entries for a first build.

If you don't use Overwolf and aren't interested in the overlay, part of GameFractal's differentiating value is lost, though the web version stays perfectly usable.

## How it's used in practice

1. Open the builder in the browser, or install the Overwolf app if you want the overlay.
2. Set race, class, multiclass, and stats like any planner.
3. Add the gear pieces you plan to use from the catalog.
4. Tune the build watching how class and items interact.
5. Generate the shareable link or keep the overlay open while you play.

## Honest limitations

**Overwolf as a dependency**: the overlay requires installing the Overwolf platform, which some players prefer to avoid due to the extra software and its telemetry.

**Catalog-driven curve**: item integration adds power but also density; for a quick first plan it can be more than you need.

**English only**: the interface isn't translated.

**Accuracy subject to patches**: like any item catalog, it depends on staying current with Larian's balance changes.

## How to get started

Open GameFractal's web builder and make a standard build to get familiar. When you want to plan around gear, start adding catalog items and watch the effect. If you like the flow, install the Overwolf app to keep the plan as an overlay during your run.
