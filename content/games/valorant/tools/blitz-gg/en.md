## What it is

Blitz.gg is a multi-game platform focused on assistant tools — desktop overlay plus website — and Valorant is one of its three pillars (alongside LoL and CS2). Free with optional premium tier. The distinctive piece is the Windows desktop app that mounts on top of the game client.

Active in Valorant since 2021. Professional team behind it (funded company), not a community project.

## What problem it solves

Tracker.gg gives you data but requires opening the browser between matches. For real-time info — who's in your lobby, which agents to know, which tier list to apply — alt-tabbing breaks flow.

Blitz solves this with an overlay: info appears over the client, in agent select it shows recommended picks, lobby data, and post-game review. For intermediate players learning to read comps, it saves time.

## How it differs

Versus Tracker.gg, Blitz wins on **client integration** (overlay) and **editorial agent guides** (tier lists Tracker.gg doesn't have). Tracker.gg wins on **historical stats depth** and **global leaderboards**.

Versus Mobalytics, Blitz has the lighter overlay; Mobalytics has better editorial content.

If your priority is in-match info, Blitz. If it's post-match analysis, Tracker.gg.

## What people use it for

**Agent-select overlay**: see win rates, recommended picks, team-comp synergies in real time during the 25-second lock-in window.

**Post-match summary**: when the match ends, a popup with your performance, rank comparison, and areas to improve.

**Current-meta tier lists**: Blitz keeps weekly tier lists by map and rank tier. Useful to pick which agent to practice next.

**Match history accessible from desktop**: without opening a browser, you open Blitz and see recent history.

**Pre-made loadouts and crosshairs**: the client suggests popular crosshairs and lets you quick-copy them into the game.

## Who it's not for

If you play on console (PS5/Xbox), Blitz has no overlay for those platforms. The web still works but the main pitch dilutes.

If you're bothered by third-party apps running in the background, or your PC is modest, the overlay continually uses RAM/CPU.

If your only use is web match history, Tracker.gg covers that with a better UI without installing anything.

## How to use it in practice

1. Download the client from `blitz.gg/valorant`. Normal Windows install.
2. Login with a Blitz account (can be via Riot OAuth).
3. Open Valorant. Blitz detects the client and mounts the overlay automatically.
4. During agent select, the overlay shows tier list, comp suggestions, and opponent stats if public.
5. Post-match, popup summary.

## Honest limitations

**Overlay can have bugs**. On big Valorant patches, Blitz sometimes lags 24-48h to update to the new client. Meanwhile the overlay may not appear.

**Premium tier pushes features**. Some features (sound coverage, advanced filters) are behind the paywall. Free is functional but the upsell is visible.

**Tier lists are popular approximations**. Blitz isn't OP.GG-tier in methodology; its rankings mix algorithm with editorial curation. Don't take as gospel.

**Windows only**. Mac and Linux have no overlay; they have to use the web.

**Not localized**. English only.

## How to get started

If you play on PC, download the client and let it run in the background. Next time you launch Valorant, the overlay appears in agent select on its own. If you don't like it, a toggle in config disables it without uninstalling. For casual use, you don't need more.
