## Qué es

Blitz.gg es una plataforma multi-juego con foco en assistant tools — overlay desktop + sitio web — y Valorant es uno de sus tres pilares (junto con LoL y CS2). Free con tier premium opcional. La pieza distintiva es la app de escritorio para Windows que se monta sobre el cliente del juego.

Activo en Valorant desde 2021. Equipo profesional detrás (compañía con funding), no proyecto comunitario.

## Qué problema resuelve

Tracker.gg te da datos pero requiere abrir browser entre partidas. Para info en tiempo real — quién está en tu lobby, qué agentes saber, qué tier list aplicar — el alt-tab rompe el flow.

Blitz resuelve eso con overlay: la info aparece sobre el cliente, en agent select te muestra picks recomendados, lobby data, y post-game review. Para players intermedios que aprenden a leer composiciones, ahorra tiempo.

## Diferenciación

Frente a Tracker.gg, Blitz gana en **integración con el cliente** (overlay) y **agent guides editoriales** (tier lists que tracker.gg no tiene). Tracker.gg gana en **profundidad de stats históricos** y **leaderboards globales**.

Frente a Mobalytics, Blitz tiene el overlay más liviano; Mobalytics tiene mejor contenido editorial.

Si tu prioridad es info en partida, Blitz. Si es análisis post-partida, Tracker.gg.

## Para qué la usa la gente

**Overlay en agent select**: ves win rates, picks recomendados, sinergias del team comp en tiempo real durante el lock-in de 25 segundos.

**Stats post-partida resumidos**: al terminar el match, popup con tu performance, comparativa al rango, y áreas de mejora.

**Tier lists del meta vigente**: Blitz mantiene tier lists semanales por mapa y rank tier. Útil para decidir qué agente practicar.

**Match history accesible desde desktop**: sin abrir browser, abres Blitz y ves tu historial reciente.

**Pre-made loadouts y crosshairs**: el cliente sugiere crosshairs populares y permite copy-paste rápido al juego.

## Para quién NO es esta herramienta

Si juegas en consola (PS5/Xbox), Blitz no tiene overlay para esas plataformas. La web sigue funcionando pero la propuesta principal se diluye.

Si te molestan apps de terceros corriendo en background, o tu PC es modesto, el overlay consume RAM/CPU continuo.

Si tu único uso es match history web, Tracker.gg cubre eso con mejor UI sin instalar nada.

## Cómo se usa en la práctica

1. Bajas el cliente desde `blitz.gg/valorant`. Instalación normal Windows.
2. Login con cuenta Blitz (puede ser via Riot OAuth).
3. Abres Valorant. Blitz detecta el cliente y monta el overlay automáticamente.
4. Durante agent select, el overlay muestra tier list, comp suggestions, opponent stats si están públicos.
5. Post-partida, popup con resumen.

## Limitaciones honestas

**Overlay puede tener bugs**. En patches grandes de Valorant, Blitz a veces lagea 24-48h en updatearse al cliente nuevo. Mientras tanto el overlay puede no aparecer.

**Tier premium empuja features**. Algunos features (sound coverage, advanced filters) están detrás del paywall. Free es funcional pero la upsell está visible.

**Tier lists son aproximaciones populares**. Blitz no es OP.GG-tier en metodología; sus rankings son mix de algoritmo + curaduría editorial. No tomes como evangelio.

**Solo Windows**. Mac y Linux no tienen overlay; deben usar la web.

**No localizado**. Solo inglés.

## Cómo empezar

Si juegas en PC, descarga el cliente y dejalo correr en background. La próxima vez que entres a Valorant, el overlay aparece solo en agent select. Si no te gusta, una toggle en config lo apaga sin desinstalar. Para uso casual, no necesitas más.
