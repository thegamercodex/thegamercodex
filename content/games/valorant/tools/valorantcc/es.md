## Qué es

ValorantCC (valorantcc.com) es un sitio web simple dedicado a hostear crosshair codes de Valorant. Free, sin login, ads ligeros. Activo desde 2021. La propuesta es minimalista: grilla buscable de crosshairs (de pros, streamers, comunidad) con un botón "copy code" que lo deja listo para pegar en el juego.

Aprovecha la feature de Valorant que permite exportar/importar crosshairs como código de texto. Cualquier usuario puede generar el código del suyo y pegarlo en otro cliente.

## Qué problema resuelve

Encontrar el crosshair perfecto requiere experimentar — outline thickness, gap, color, dot, dynamic vs static. Ajustar manualmente toma horas. Lo natural es probar el de un pro que admires y ver si te queda cómodo.

ValorantCC consolida esos crosshairs. Buscas "TenZ" o "Tarik" o "yay", obtienes su crosshair code actual, click copy, paste in-game (Settings > Crosshair > Import Profile Code). Cinco segundos.

## Diferenciación

Frente a prosettings.net, ValorantCC está **especializado solo en crosshairs**. Prosettings tiene crosshairs PERO también sensitivity, mouse settings, video settings, peripherals — más amplio.

Si tu único interés es probar crosshairs de pros, ValorantCC es más rápido (UI específica, copy-paste directo). Si quieres copiar config completa de un pro (sens, video, etc.), prosettings.

Frente al sub-r/ValorantCustomCrosshairs, ValorantCC tiene mejor curaduría y búsqueda. Reddit tiene más volumen pero requiere más cavar.

## Para qué la usa la gente

**Probar crosshair de pro favorito**: search → copy code → paste in-game. Listo.

**Browse por estilo**: filtros por color, dot/no-dot, outline. Útil cuando exploras qué te queda cómodo.

**Inspiración para custom propio**: ver qué setups usan pros similar a tú para arrancar diseño propio.

**Compartir el tuyo**: si te enganchas, puedes submit el tuyo a la base de datos.

**Setup rápido en cliente nuevo**: si re-instalas Valorant o juegas en otra PC, recuperas tu crosshair vía code en lugar de reconfigurar manualmente.

## Para quién NO es esta herramienta

Si ya tienes un crosshair que te queda cómodo, no hay razón para visitar — agregas fricción innecesaria.

Si quieres config completa de pro (sens, video, peripherals), prosettings.net es mejor.

Si juegas en consola, los crosshairs son más limitados (Valorant Console permite menos custom). Probablemente no necesites un sitio externo.

## Cómo se usa en la práctica

1. Entras a `valorantcc.com`. Sin login.
2. Buscas un nombre (pro, streamer, agente que te interesa) o browseas la grilla.
3. Cuando encuentras un crosshair que te gusta, click "Copy Code".
4. Abres Valorant. Settings → Crosshair → Profiles → Import Profile Code → paste.
5. El crosshair aparece. Si no te gusta, repites el flujo.

## Limitaciones honestas

**Requiere mantener up-to-date**. Pros cambian crosshairs frecuentemente. ValorantCC depende de submissions o curador para reflejar cambios.

**Calidad de submissions variable**. La mayoría son legítimos pero hay codes "fake-pro" subidos por usuarios.

**No reemplaza experimentación propia**. Lo que le funciona a TenZ no necesariamente te va a funcionar a tú. ValorantCC da starting points, no soluciones definitivas.

**Sin features adicionales**. Single-purpose por diseño. Si esperas features tipo "compara dos crosshairs side-by-side", no las tiene.

**Solo en inglés**. Sin localización (aunque dado que es solo browse + copy, el lenguaje barrera es mínima).

## Cómo empezar

Entra a `valorantcc.com`. Busca tu pro/streamer favorito o uno con estilo similar al tuyo (Aspas si juegas Duelist agresivo, FNS si juegas Smokes). Copy code, paste en juego. Prueba un par de partidas. Si no convence, repite. En 30 minutos puedes probar 10 crosshairs de top pros y ver cuál te queda cómodo.
