---
title: Map Router vs Map Labels — which Nightreign map tool to use
description: Comparison between detailed routing web app and transparent desktop overlay. Planning vs live info.
---

Both solve seed identification but with opposite approaches. **Nightreign Map Router** is a web app with detailed planning; **Map Labels** is a transparent desktop overlay for live info.

## Planning vs live

Map Router: open the web, identify the seed, receive suggested routing. Pre-Expedition workflow.

Map Labels: app runs over the game as a transparent overlay, showing relevant labels while you play.

## Online safety

Both are online-safe (no injection, no memory reading). Map Labels is pure overlay; Map Router is web app.

## Cross-platform

Map Router: web, any OS.

Map Labels: Windows-only desktop.

## Team comp adaptation

Map Router: suggests different routes based on which Nightfarers are in party. Map Labels doesn't implement this logic.

## When each wins

| Scenario | Best option |
|---|---|
| Pre-Expedition planning | Map Router |
| Live info during play | Map Labels |
| Mac/Linux user | Map Router |
| Avoid alt-tab | Map Labels |
| Team comp-specific routing | Map Router |
| Online safety with EAC | Tie (both) |

## Verdict

**Use both**: Map Router before starting (detailed planning), Map Labels during play (live overlay). Combined workflow is what pro players do.
