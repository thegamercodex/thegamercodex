title: Map Router vs Map Labels — qué map tool de Nightreign usar
description: Comparación entre web app de routing detallado y overlay desktop transparente. Planning vs live info.
---

Ambos resuelven seed identification pero con approaches opuestos. **Nightreign Map Router** es web app con planning detallado; **Map Labels** es overlay desktop transparente para live info.

## Planning vs live

Map Router: abres la web, identificás seed, recibes routing sugerido. Workflow pre-Expedition.

Map Labels: app corre encima del juego como overlay transparente, mostrando labels relevantes mientras juegas.

## Online safety

Ambos son online-safe (no inyectan, no leen memoria). Map Labels es overlay puro; Map Router es web app.

## Cross-platform

Map Router: web, cualquier OS.

Map Labels: Windows only desktop.

## Team comp adaptation

Map Router: sugiere routes diferentes según qué Nightfarers están en party. Map Labels no implementa esa lógica.

## Cuándo gana cada uno

| Escenario | Mejor opción |
|---|---|
| Planning pre-Expedition | Map Router |
| Live info during play | Map Labels |
| Mac/Linux user | Map Router |
| Avoid alt-tab | Map Labels |
| Team comp specific routing | Map Router |
| Online safety con EAC | Empate (ambos) |

## Veredicto

**Usa ambos**: Map Router antes de empezar (planning detallado), Map Labels durante (live overlay). Workflow combined es lo que pro players hacen.
