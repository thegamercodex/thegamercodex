## Qué es

Nexus Mods (Nightreign) es la sección dedicada del hub Nexus Mods para Elden Ring Nightreign. Lanzada poco después del release del juego en 2025. Cubre ~500+ mods al 2026 — significativamente menos que ER base (~5000) pero growing.

Cuenta gratis con downloads rate-limitados; Premium para descargas a full speed.

## Qué problema resuelve

Discover modes de Nightreign sin Nexus significa buscar en threads dispersos, Discords privados y GitHub repos sueltos. Nexus consolida con search, filters, comments y bug reports.

También resuelve versioning: cada mod tiene changelog visible y podes descargar versiones viejas si la latest rompe.

## Para qué la usa la gente

**Descargar Seamless Co-op (Nightreign)**: el mod más popular para co-op extended.

**Descargar mods de rebalance**: Fun is Allowed para solo/duo gameplay viable.

**Relic editors y calculators**: Nightreign Calculator y Relic Editor para technical users.

**Map overlay tools**: Map Labels para seed identification.

**Browse de mods nuevos**: trending tab para descubrir QoL releases.

## Para quién NO es esta herramienta

Console (PS5/Xbox) no soporta mods — PC exclusivo.

Si solo quieres QoL y no estás interesado en multiplayer mods, hay menos opciones que para ER base.

Si esperas el mismo volumen de mods que ER base, vas a sorprenderte — Nightreign tiene fracción.

## Cómo se usa en la práctica

1. Visita `nexusmods.com/eldenringnightreign`.
2. Crea cuenta gratis y verifica email.
3. Browse por filtros (Most Endorsed, Recently Updated, Trending).
4. En cada mod, lee Description + Comments + Bugs antes de instalar.
5. Click Manual Download para zip; instala siguiendo README.

## Limitaciones honestas

**Ecosistema chico**: 500+ mods vs 5000+ en ER base. Para algunas categorías, opciones limitadas.

**Anti-cheat sensible**: Nightreign tiene EAC; mods requieren offline mode bypass que puede ban si lo combinas mal con online.

**Free tier rate-limited**: Descargas lentas; premium fixea.

**Comunidad menor**: comments y bug reports son menos volume que en ER base.

## Cómo empezar

1. Visita `nexusmods.com/eldenringnightreign`.
2. Crea cuenta gratis.
3. Empieza con un mod conocido (Seamless Co-op, Fun is Allowed) para entender el flow.
4. Lee Comments antes de instalar — community reporta bugs visibles ahí.
5. Para troubleshooting, el Discord de cada mod específico es mejor que el thread de comments.
