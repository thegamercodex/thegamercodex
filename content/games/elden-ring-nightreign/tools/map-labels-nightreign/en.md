## What it is

Map Labels is a desktop application that renders a transparent overlay over Elden Ring Nightreign. Distributed on Nexus Mods (`nexusmods.com/eldenringnightreign/mods/419`). The overlay doesn't inject, patch, or read game memory — it only draws a transparent window on top.

This makes it **online-safe**: compatible with Easy Anti-Cheat without ban risk.

## What it solves

Map Router (web app) requires alt-tabbing during play to consult — flow interruption. Map Labels solves this with an overlay that lives on top while you play.

It also solves seed identification: detects the map pattern quickly and shows relevant labels.

## What people use it for

**Live overlay during Expedition**: see important landmarks while exploring.

**Integrated seed finder**: identifies seed pattern in seconds.

**Configurable hotkeys**: toggle on/off as needed.

**Online-safe**: PvP-conscious users prefer it over alternatives requiring offline.

**Companion to Map Router**: use both — Map Router for detailed planning, Map Labels for live info.

## Who shouldn't use it

If you play on console, doesn't apply.

If overlays over the game bother you, you'll be frustrated — the whole app is overlay.

If you want detailed routing by team comp, Map Router is more complete.

## How it's used in practice

1. Download the app from `nexusmods.com/eldenringnightreign/mods/419`.
2. Create a Nexus account if you don't have one.
3. Extract and run the executable.
4. Configure hotkeys to preference.
5. Start Nightreign — the overlay appears on top.
6. Toggle on/off depending on context.

## Honest limitations

**Windows only**: no Mac/Linux version.

**Initial configuration**: hotkeys and display options require tweaking.

**Not as exhaustive as Map Router**: the overlay shows key info, not full analysis.

**Updates dependent on game patches**: when Bandai updates, seed format can change and the app takes time to align.

**Some imprecise labels**: seed detection works ~95% but there are occasional false positives.
