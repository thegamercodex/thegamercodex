## Qué es

Map Labels es una aplicación desktop que rendea un overlay transparente sobre Elden Ring Nightreign. Distribuida en Nexus Mods (`nexusmods.com/eldenringnightreign/mods/419`). El overlay no inyecta, no patchea, no lee memoria del juego — solo dibuja una ventana transparente encima.

Esto la hace **online-safe**: compatible con Easy Anti-Cheat sin riesgo de ban.

## Qué problema resuelve

Map Router (web app) requiere alt-tab durante el juego para consultarla — interruption del flow. Map Labels resuelve esto con overlay que vive on top mientras juegas.

También resuelve el problema de seed identification: detecta el patrón del mapa rápidamente y muestra labels relevantes.

## Para qué la usa la gente

**Overlay live durante Expedition**: ver landmarks importantes mientras exploras.

**Seed finder integrado**: identifica seed pattern en segundos.

**Hotkeys configurables**: toggle on/off según necesites.

**Online safe**: usuarios PvP-conscious lo prefieren sobre alternativas que requieren offline.

**Companion para Map Router**: usar ambos — Map Router para planning detallado, Map Labels para info live.

## Para quién NO es esta herramienta

Si juegas en console, no aplica.

Si te molestan overlays sobre juego, vas a frustrarte — toda la app es overlay.

Si quieres routing detallado por team comp, Map Router es más completo.

## Cómo se usa en la práctica

1. Baja la app desde `nexusmods.com/eldenringnightreign/mods/419`.
2. Crea cuenta Nexus si no la tenes.
3. Extrae y corre el ejecutable.
4. Configura hotkeys según preferencia.
5. Empieza Nightreign — el overlay aparece encima.
6. Toggle on/off según context.

## Limitaciones honestas

**Solo Windows**: no hay versión Mac/Linux.

**Configuración inicial**: hotkeys y display options requieren tweaking.

**No tan exhaustivo como Map Router**: el overlay muestra info clave, no análisis completo.

**Updates dependientes de game patches**: cuando Bandai actualiza, el seed format puede cambiar y la app tarda en alinearse.

**Algunos labels imprecisos**: el detect de seed funciona ~95% pero hay false positives ocasionales.

## Cómo empezar

1. Visita `nexusmods.com/eldenringnightreign/mods/419`.
2. Crea cuenta Nexus y descarga.
3. Extrae y lanza el ejecutable.
4. Configura hotkey de toggle.
5. Empieza una Expedition de testing antes de runs serios.
