## Qué es

Fun is Allowed es un overhaul mod de Nightreign distribuido en Nexus (`nexusmods.com/eldenringnightreign/mods/49`). Diseñado específicamente para hacer solo y duo runs jugables — vanilla Nightreign está balanceado para trios y las dos otras configuraciones tienen disadvantages reales.

Cubre stats, equipo inicial, damage scaling y survivability. Compatible con Seamless Co-op para extender mientras balancea.

## Qué problema resuelve

Vanilla Nightreign para solo: muy hard. Los Nightlords escalan asumiendo trio y solo significa less DPS, no healing share, no aggro distribution. La mayoría de solo players abandona al primer Nightlord challenging.

Para duos: mejor que solo pero todavía dificil — falta el third player que puede dedicarse a aggro management o healing.

Fun is Allowed ajusta esto: empiezas con Wending Grace (auto-revive), stats base mejorados, daño output adjusted. La experiencia se vuelve "challenging pero fair" en lugar de "imposible sin trio".

## Para qué la usa la gente

**Solo runs viables**: completar Nightreign en single-player sin frustration extreme.

**Duo runs balanceadas**: jugar con un amigo sin needing find a third.

**Practice runs**: aprender encounters específicos sin presión de team.

**Achievement hunting solo**: para users que necesitan ciertos achievements solo.

**Combinación con Seamless Co-op**: balancing para grupos custom de 4-5 que no son ni vanilla 3 ni full 6.

## Para quién NO es esta herramienta

Si juegas siempre en trio y tu grupo es estable, no aporta.

Si valoras "intended difficulty" de vanilla, el mod la ajusta — para puristas no encaja.

Si juegas multiplayer online vanilla, el mod fuerza offline y no podes mezclar.

## Cómo se usa en la práctica

1. Baja Fun is Allowed desde `nexusmods.com/eldenringnightreign/mods/49`.
2. Sigue el README para extraer e instalar (requiere offline mode).
3. Configura settings según prefer — el mod tiene options de "aggressive rebalance" vs "minimal tweaks".
4. Lanza Nightreign con el setup correspondiente.
5. Empieza una Expedition solo o duo y validá que el balance funcione.

## Limitaciones honestas

**Offline only**: vuelve tu save tainted para online vanilla.

**Difficulty controvertida**: algunos community members consideran que "trivializa"; otros que "fixea" balance roto. Subjective.

**Setup más complejo**: requiere Mod Engine 2 + Seamless Co-op para uso óptimo.

**Updates lentos post-patch**: el solo dev del mod tarda en ajustar tras balance changes oficiales.

**Compatibility con otros mods limitada**: cambia muchos params; conflicta con mods que toquen mismos archivos.

## Cómo empezar

1. Visita `nexusmods.com/eldenringnightreign/mods/49`.
2. Lee el README completo — incluye dependencies.
3. Instala Mod Engine 2 si no lo tenes.
4. Baja Fun is Allowed y extrae siguiendo estructura.
5. Configura settings y lanza con offline launcher.
6. Prueba en una Expedition simple antes de attempting Nightlords difíciles.
