## What it is

Relics.pro is a web app dedicated exclusively to Elden Ring Nightreign's relic system. Maintained by an independent dev with active community Discord. Free, no required login.

The core of the app is a relic optimizer: input your target build (stats, weapons, Nightfarer) and the algorithm suggests the relic set that maximizes output, prioritizing in-game obtainable relics over theoretical impossible builds.

## What it solves

Nightreign's relic system is combinatorially complex: each relic has multiple possible stat rolls, limited slots, and interaction effects. Optimizing by hand means an Excel table — slow and error-prone.

Relics.pro does the math: given your Nightfarer and target stats, which relic combination gets you closest. It also filters by obtainability (relics you can actually drop vs theoretical cosmetics).

## Differentiation

Against Mobalytics it wins on relic optimization specificity (dedicated algorithm vs generalist build planner). It loses on Nightfarer coverage (Relics.pro doesn't have editorial guides). Against Nightreign Calculator (desktop) it wins on web accessibility and build sharing.

## What people use it for

**Optimize relic loadout for specific Nightfarer**: input target build and see which relics to seek.

**Plan farming**: the algorithm suggests farmable relics, so you know what to grind.

**Share builds with community**: unique URLs per build.

**Re-optimize post-patch**: when Bandai tweaks values, re-run the optimizer.

**Compare relic options**: two relic combinations side-by-side.

## Who shouldn't use it

If you're just starting Nightreign and don't understand relics yet, Relics.pro is overwhelming — read Mobalytics first.

If your interest is editorial Nightfarer guides (which playstyle vs which Nightlord), Mobalytics or Fextralife are better.

If you don't use finely-tuned builds (just casually), the optimizer is overkill.

## How it's used in practice

1. Open `relics.pro`.
2. Pick your Nightfarer.
3. Define stat targets (or use a community preset).
4. The algorithm runs and shows the optimal relic loadout.
5. For each relic, see info on how to farm it.
6. Share the final URL if you want validation or help.

## Honest limitations

**Initial technical curve**: the optimizer assumes you understand stat targets and relic mechanics.

**No editorial guides**: the app is pure math. For "which Nightfarer is good," go to Mobalytics.

**Maintained by one person**: update cadence is good but may pause.

**Incremental DLC coverage**: Forsaken Hollows was added but some DLC-specific items took weeks.

**Not mobile-friendly**: UX is desktop-first.

## How to start

1. Visit `relics.pro`.
2. If you don't know relic mechanics, first read Mobalytics's "Builds" section.
3. Pick your Nightfarer in relics.pro.
4. For your first pass, use a build preset; then tweak stats.
5. Join the relics.pro Discord (link in footer) for technical questions.
