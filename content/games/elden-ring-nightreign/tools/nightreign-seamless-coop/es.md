## Qué es

Seamless Co-op (Nightreign) es la adaptación del mod de LukeYui para Elden Ring Nightreign. Distribuido en Nexus Mods bajo `nexusmods.com/eldenringnightreign/mods/3`. Open-source, gratis, requiere offline mode.

Lanzado poco después del release de Nightreign en 2025 y mantenido por el equipo Seamless que también mantiene la versión de ER base.

## Qué problema resuelve

Vanilla Nightreign limita parties a 3. Para grupos de amigos más grandes (4-6 players regulares), esto significa rotar quién juega. Seamless Co-op extiende el party size y mejora la coordinación in-game.

También permite duos sin restricciones — vanilla matchmaking favorece trios y duos tienen disadvantages mecánicos. El mod permite duo runs balanced.

## Para qué la usa la gente

**Party de 4-6 amigos**: extender más allá del límite vanilla.

**Duo runs balanceados**: jugar con un amigo sin las restricciones del matchmaking.

**Coordinación mejorada**: el mod incluye voice chat helpers y position sharing.

**SOTE en grupos grandes**: el DLC se siente más manejable con más players (configurable difficulty).

**Eventos comunitarios**: speedruns y challenges con groups más grandes.

## Para quién NO es esta herramienta

Console no soporta mods — PC only.

Si quieres multiplayer vanilla con randoms, el mod fuerza closed groups (passwords).

Si valoras el "intended difficulty" de Nightreign con 3, el extra party size puede trivializar.

## Cómo se usa en la práctica

1. Asegúrate de tener Nightreign instalado en PC.
2. Baja Seamless Co-op desde `nexusmods.com/eldenringnightreign/mods/3`.
3. Sigue el README para extraer archivos y configurar.
4. Define un password compartido para tu grupo en el config.
5. Lanza con el launcher dedicado.
6. Tu grupo usa el mismo password y se conecta automáticamente.

## Limitaciones honestas

**Version-locked**: cuando Bandai patchea Nightreign, el mod tarda 1-7 días en actualizarse.

**Offline only**: tu progress queda separado de online vanilla.

**Difficulty scaling debatido**: con 6 players, algunos Nightlords se trivializan; con duos balanced, otros son brutales.

**Setup más complejo que vanilla**: requiere reading del README.

**Bugs ocasionales con quests**: NPC interactions en groups grandes pueden glitchear.

## Cómo empezar

1. Visita `nexusmods.com/eldenringnightreign/mods/3`.
2. Baja la última versión (verifica compatibility con tu patch).
3. Sigue el README detallado — incluye un launcher dedicado.
4. Coordina con amigos para usar la misma versión exacta.
5. Únete al Discord de Seamless (link en página del mod) para troubleshooting.
