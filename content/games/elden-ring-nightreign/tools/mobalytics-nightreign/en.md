## What it is

Mobalytics is a multi-game gaming guide platform that extended coverage to Nightreign at launch (May 2025). The Nightreign section (`mobalytics.gg/elden-ring-nightreign`) has staff-curated builds, per-patch tier lists, an integrated build planner, and per-Nightfarer + per-Nightlord guides.

It's freemium: most content is free; premium adds advanced features. Editorial quality is consistent — writers play the game and update post-patch.

## What it solves

Nightreign is a new game with volatile meta — which Nightfarer is S-tier this patch, which relic combos dominate, which builds work vs each Nightlord. Keeping that info updated requires effort that Fextralife/wikis don't editorially prioritize — Mobalytics does.

For new players, Mobalytics solves "what should I build and why" in one click; traditional wikis have the data but not the editorial recommendation.

## Differentiation

Against Fextralife it wins on clear editorial recommendations (tier lists, recommended builds, meta analysis); it loses on exhaustive factual coverage. Against Relics.pro it wins on breadth (covers everything, not just relics) but loses on the relic optimizer's specificity.

## What people use it for

**Per-Nightfarer recommended builds**: read the guide for the Nightfarer you want to play and see which stats, relics, and weapons to prioritize.

**Post-patch tier lists**: see where each Nightfarer sits in the current meta.

**Integrated build planner**: build custom and share via URL.

**Nightlord weakness charts**: see which stat priorities work vs each Nightlord.

**DLC coverage**: Forsaken Hollows has its own section with builds and guides.

## Who shouldn't use it

If you want raw data extracted from game files (exact drop rates, frame data), Mobalytics is editorial — it doesn't expose that.

If you only want to optimize relics, Relics.pro has a better dedicated algorithm.

If ads in the free tier bother you, premium is needed for clean reading.

## How it's used in practice

1. Open `mobalytics.gg/elden-ring-nightreign`.
2. Create a free account (optional but useful for saving builds).
3. For Nightfarer-specific guides: nav → Nightfarers → pick your character.
4. For custom builds: nav → Planner → build and share URL.
5. For Nightlord strategies: nav → Nightlords → pick target boss.

## Honest limitations

**Editorial bias**: tier lists reflect staff opinions. There's community debate on some rankings.

**Free-tier ads**: present but less aggressive than Fextralife.

**Post-patch coverage sometimes lags**: big balance patches can take 1-2 weeks to reflect in every guide.

**Controlled but occasional DLC spoilers**: Mobalytics implements spoiler toggles but they sometimes fail on cross-cutting guides.

## How to start

1. Visit `mobalytics.gg/elden-ring-nightreign`.
2. Read the "Beginner Guide" if it's your first time.
3. Pick the Nightfarer you want to play and open its build guide.
4. Follow the relic and stat recommendations.
5. When you're more experienced, use the planner for custom builds.
