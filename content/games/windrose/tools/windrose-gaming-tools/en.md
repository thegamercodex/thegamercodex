## What it is

Windrose Gaming Tools (windrose.gaming.tools) is a community database launched in parallel to Windrose.tools that covers similar territory: seed-based interactive map, character builder, and full cataloging of items, ships, weapons, and biomes. The main difference is integration with an optional companion app that syncs save progress to the web map in real time.

## What problem it solves

Same problem as Windrose.tools: the procedural world needs a seed-aware tool for coordinates to make sense. Windrose Gaming Tools adds the live-sync dimension: instead of manually re-uploading the save every time you want to see updated progress, the companion app pushes changes automatically. Useful for players who move a lot between regions and want the map to reflect their exploration without re-uploads.

## Differentiation

- **Windrose.tools** is the more popular option but requires save re-upload to sync.
- Windrose Gaming Tools adds the companion app — initial overhead (install) in exchange for auto-sync.
- Both cover talents/items/map on the web. The choice today is between convenience of installing nothing (Windrose.tools) vs auto-sync (Gaming Tools).

## What people use it for

- **Live exploration tracking**: see where you are on the map in real time while playing.
- **Coordinate with co-op players**: in a multi-player session, two players can see the same updated map simultaneously.
- **Item and biome reference**: textual and visual lookup of bestiary, weapons, armor sets.
- **Character builder with integrated preview**: build the character and see the active calculated stats in-place.

## Who this tool is NOT for

If you don't want to install anything extra and an occasional manual save upload is enough, Windrose.tools is simpler. If you only want deep damage calculator, this doesn't have it — Calculators.games does.

## How it's used in practice

1. Open [windrose.gaming.tools](https://windrose.gaming.tools).
2. For basic use: click "Interactive Map", upload save file manually.
3. For live-sync: download the companion app from the site, install it on Windows, connect it with the web via token. Once connected, the map updates automatically every minute or every in-game save.
4. For character builder: click "Character Builder", build by picking gear/talents/stats, see the real-time stat preview.

## Honest limitations

- **Companion app is Windows-only**: no Mac/Linux version. Live-sync works only on Windows.
- **No persistent login for sync**: the token expires occasionally, you have to reconnect.
- **Database with occasional gaps**: very recent enemies (post-latest patch) may be missing.
- **Closed source**: like Windrose.tools, not FOSS. If the site disappears, no fork available.

## How to get started

Open [windrose.gaming.tools](https://windrose.gaming.tools). For casual no-install use, go straight to "Interactive Map" and upload your save once. If you play Windrose frequently and want auto-sync, download the companion app — initial setup is 5 minutes but after that the integration is transparent.
