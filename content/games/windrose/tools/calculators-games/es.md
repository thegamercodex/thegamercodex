## Qué es

Calculators.games es una plataforma de calculadoras gaming que cubre varios juegos; su módulo de Windrose es una de las herramientas más profundas para análisis numérico de builds. Combina un planner que distribuye los 45 stat points y los 12 talent points entre las cuatro ramas (Fencer, Crusher, Marksman, Toughguy), con un damage calculator independiente que estima TTK y DPS contra targets concretos. Es gratuito, sin login, y la data se actualiza con cada patch.

## Qué problema resuelve

Windrose tiene un combat system donde las micro-decisiones de stat allocation y armor set bonus pesan visiblemente: 5 puntos en strength vs dexterity pueden cambiar el TTK del Kraken Vanguard de 4 minutos a 3. Sin una calculadora, esta optimización es trial-and-error caro (respec limitado, ítems craftables tardan recursos). Calculators.games te deja simular el resultado antes de invertir.

## Diferenciación

Frente a Windrose.tools (la opción todo-en-uno), Calculators.games trade-off es claro: menos cobertura horizontal (no tiene mapa, no tiene item lookup), más profundidad vertical en la matemática. El damage calculator te muestra los modifiers que se aplican (base damage, weapon scaling, talent multipliers, armor mitigation, set bonuses) y permite tweaking de cada variable. Para alguien que quiere entender por qué un build performa así, no solo verlo, es la diferencia entre una caja negra y una transparente.

## Para qué la usa la gente

- **Validar un build antes del respec**: simular el DPS final con el allocation propuesto vs el actual.
- **Comparar dos armor sets**: ver cómo cambia la math con set A vs set B contra el mismo enemy.
- **Estimar TTK contra bosses específicos**: especialmente útil para Kraken Vanguard y los bosses post-game.
- **Theorycrafting puro**: jugadores que disfrutan optimizar usan la calculadora como playground.
- **Validar tier lists comunitarias**: la calculadora confirma o desmiente afirmaciones tipo "X talent es óptimo" con números.

## Para quién NO es esta herramienta

Si solo necesitas saber qué talents pickear como beginner, esto es overkill — usa Windrose.tools que tiene presets de builds populares. Si quieres ver el mapa interactivo o lookup de items, esta herramienta no los cubre.

## Cómo se usa en la práctica

1. Entra a [calculators.games/windrose](https://calculators.games/windrose).
2. Para el build planner: clic en "Build Planner", distribuye los 45 stat points en los selectores, allocate los 12 talent points, elige armor set bonuses del dropdown.
3. Para damage calculator: clic en "Damage Calculator", carga el build (o construye uno nuevo), selecciona target enemy y observe TTK + DPS estimados.
4. Comparar builds: abre dos pestañas del calculator, una con build A y otra con build B, contrasta números side-by-side.

## Limitaciones honestas

- **Algunos enemies post-launch sin data**: bosses agregados en parches muy recientes pueden no tener stat sheets completos en la calc.
- **Sin sharing fácil de builds**: a diferencia de Windrose.tools, los builds no exportan a URL compartible — hay que screenshot o copiar manualmente.
- **UI densa**: la calc muestra todos los modifiers visibles, lo cual es positivo para transparency pero abrumador para usuarios no técnicos.
- **No tiene equivalent móvil**: el sitio funciona en mobile pero la UX está pensada para desktop.

## Cómo empezar

Abre [calculators.games/windrose](https://calculators.games/windrose). Si vienes de Windrose.tools y quieres validar un build, manualmente replica el allocation en el "Build Planner" y luego abre "Damage Calculator" para ver los numbers. Si arrancas desde cero, el flujo recomendado es: lee una guía community-recommended de build, abre la calc, replica el build, experimenta con tweaks de 1-2 puntos para ver cómo cambian los números.
