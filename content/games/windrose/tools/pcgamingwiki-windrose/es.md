## Qué es

PCGamingWiki es una wiki community-editable enfocada en cobertura técnica de juegos de PC: fixes, configuraciones, hardware compatibility y workarounds para bugs. Su entry de Windrose se abrió poco después del lanzamiento y consolida problemas reportados, soluciones de la comunidad y ajustes recomendados para optimizar la experiencia. Es gratuita y libremente editable.

## Qué problema resuelve

Las wikis gameplay-first (Windrose Wiki, Fextralife) responden "qué hace este item" o "cómo derroto este boss". PCGamingWiki responde "por qué el juego crashea cuando entro a un dungeon" o "cómo mover mi save a otra PC". Es el gap técnico que el resto de la documentation no cubre.

## Diferenciación

- **Las wikis de gameplay** describen el juego desde dentro. PCGamingWiki lo describe desde la PC: archivos, paths, comandos.
- Frente a Steam forums (donde la info similar existe pero dispersa en threads), PCGamingWiki consolida en formato wiki — easier to find, less noise.
- Frente al Discord oficial, PCGamingWiki es buscable por Google y persiste — los soluciones de Discord se pierden en el scroll.

## Para qué la usa la gente

- **Resolver crashes específicos**: lookup del error code en el page y aplicar el fix sugerido.
- **Configurar HDR / 21:9 / DLSS / FSR**: settings que el menu in-game no expone pero que el .ini sí permite.
- **Mover saves a otra PC**: encontrar el path exacto en `%LOCALAPPDATA%` y backuper.
- **Verificar requisitos antes de comprar**: page lista hardware reportado como compatible/incompatible.
- **Compatibilidad con Steam Deck / Proton**: si juegas en deck, acá está la matriz de qué funciona y qué no.

## Para quién NO es esta herramienta

Si todo tu setup funciona perfecto y no quieres tocar archivos del juego, esta herramienta no agrega valor — quédate en las wikis gameplay. Si tu pregunta es "qué build es óptimo", PCGamingWiki no responde eso.

## Cómo se usa en la práctica

1. Abre [pcgamingwiki.com/wiki/Windrose](https://www.pcgamingwiki.com/wiki/Windrose).
2. La page principal tiene secciones colapsables: System requirements, Configuration files, Save game data, Video settings, Issues, etc.
3. Para un crash o bug: scroll a "Issues fixed" o "Issues unresolved" y buscar el error code o síntoma.
4. Para configuración avanzada: "Video settings" o "Input settings" para ajustes ocultos.
5. Para reportar un nuevo issue / fix encontrado: clic en "Edit" arriba, requiere account gratuito.

## Limitaciones honestas

- **Cobertura solo de issues conocidos**: si tu bug es nuevo, puede no estar documentado todavía.
- **Skew hacia setups Windows**: la wiki tiene info de Linux/Proton/macOS pero menos detallada.
- **Vocabulario técnico**: asume familiaridad con archivos .ini, paths del sistema, hardware specs.
- **Sin chat ni soporte en vivo**: PCGamingWiki es read-only desde el usuario. Si la solución sugerida no funciona, hay que ir a Discord o foros.

## Cómo empezar

Abre [pcgamingwiki.com/wiki/Windrose](https://www.pcgamingwiki.com/wiki/Windrose) y bookmárcalo. La primera vez, escanea la table of contents para conocer las secciones. La próxima vez que tengas un problema técnico, abre la page y busca el síntoma — el formato consolidado te ahorra leer 50 threads de Steam.
