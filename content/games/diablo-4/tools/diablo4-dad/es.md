## Qué es

Diablo 4 Dad (diablo4.dad) es un collection tracker comprensivo para D4 mantenido por la community. Más amplio en coverage que Diablo4codex — incluye:

- **Mounts collection**: completion % vs master list.
- **Achievements**: visible y hidden ones (in subset).
- **Altars of Lilith**: per region.
- **Lilith statues**: Renown progress.
- **Dungeons completed**: per zone.
- **Paragon glyphs collected**: items específicos del paragon system.
- **Helltide chests opened**: less obvious tracking.
- **Other niche completion metrics**.

Sync via Blizzard account login. Free.

## Qué problema resuelve

Diablo4codex cubre seasonal progress (aspects, codex, achievements). Pero hay metrics que Codex no trackea: paragon glyphs collected, altar of Lilith state, specific hidden achievement subsets, mount completion. Diablo 4 Dad fills esos gaps.

Para ultra-completionists, es indispensable. Para completionists casuales, complementa Codex (Codex para season progress + Dad para world-collection).

## Diferenciación vs Diablo4codex

- **Diablo4codex**: foco en seasonal progress + Codex of Power.
- **Diablo 4 Dad**: foco en world collection comprehensive (altars, statues, glyphs, mounts).

No competidores estrictos — diferentes scopes. Many serious completionists use ambos.

## Para qué la usa la gente

**Renown 100% per region**: necesitas specific statues + altars. Diablo 4 Dad lista lo que falta.

**Glyph collection tracking**: paragon glyphs son grindeable y D4 in-game no exposes "qué te falta" claramente.

**Mount completion**: 70+ mounts en D4, varios via achievement chain. Dad lista pending.

**Achievement hunting hidden**: para platinum trophies, hidden achievements requieren guides. Dad lista visible + some hidden.

**Comparativa con amigos**: linkeá chars, vé side-by-side stats.

## Para quién NO es esta herramienta

- **No completionist**: si no te importa "tener todo", no aporta.
- **Quien evita account login**: requiere sync con Blizzard account.
- **Eternal-only**: tracking focused en current state, no historical.
- **Quien busca builds**: este no es content tool, es tracker.

## Cómo se usa en la práctica

1. [diablo4.dad](https://diablo4.dad/).

2. **Login** via Blizzard account.

3. Sync inicial (1-2 min para chars con large collection).

4. Dashboard te muestra completion % per category.

5. Filter pending per category: lista exact lo que te falta + sources.

6. Re-sync semanal después de play sessions.

## Limitaciones honestas

**Account login required for tracking**: sin login solo browse comunitario stats. Personal tracking needs sync.

**Update lag con new patches**: nuevo content tarda days en quedar fully tracked.

**OCR / API dependent**: Blizzard no expone perfect API. Some metrics derive scraping del Lodestone equivalent.

**Sin Codex of Power**: para aspects unlocked, Diablo4codex específicamente.

**UI menos polished**: solid functional pero no top-tier modern.

## Cómo empezar

1. [diablo4.dad](https://diablo4.dad/).

2. Login con Blizzard account.

3. Sync inicial. Browse dashboard per category.

4. Filter "Pending" para list de lo que te falta.

5. Combina: Codex para aspects + season; Dad para world collection. Together cover full completion picture.

6. Re-sync periodically para keep tracking up-to-date.
