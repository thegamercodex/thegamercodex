## Qué es

Mobalytics D4 Overlay (mobalytics.gg/lol/glp/diablo-4-download) es la desktop companion app oficial de Mobalytics para D4, distribuida via la plataforma Overwolf. Te trae el content de Mobalytics — builds, tier lists, class guides — al overlay sobre el cliente de D4.

## Qué problema resuelve

Para players que usan Mobalytics como hub primary, alt-tab del juego al browser durante gameplay rompe focus. El overlay elimina ese friction: hotkey toggle, info visible, hotkey toggle off.

## Diferenciación vs D4Builds Overlay

- **Mobalytics Overlay**: content del ecosystem Mobalytics (visual cards, tier badges).
- **D4Builds Overlay**: content del ecosystem D4Builds.gg (community builds + Rob2628 curated).

Decision depende de cuál hub usas como primary. Functionally similar overlays con diferentes content sources.

## Para qué la usa la gente

**Tier list quick reference mid-gameplay**: confirm tu build sigue meta post-patch.

**Build steps following**: leveling o endgame, consultar skill priorities sin browser.

**Mobile-style cards reading**: la UI visual de Mobalytics traduce well al overlay format.

**Multi-monitor alternative**: si no tienes second monitor para guide, overlay sustituye.

## Para quién NO es esta herramienta

- **Quien no usa Mobalytics**: si Maxroll/D4Builds son tu primary, el respective overlay es better.
- **Mac/Linux/Console**: Overwolf platform es Windows-only PC.
- **Casuales sin guide reference**: irrelevant.
- **Quien evita Overwolf ads**: la plataforma monetiza con ads.

## Cómo se usa en la práctica

1. Install Overwolf desde overwolf.com.

2. Install Mobalytics D4 app desde [mobalytics.gg/lol/glp/diablo-4-download](https://mobalytics.gg/lol/glp/diablo-4-download) o Overwolf store.

3. Setup hotkey de overlay.

4. Launch D4. Toggle overlay durante gameplay.

5. Browse Mobalytics content overlaying el game.

## Limitaciones honestas

**Overwolf overhead**: plataforma install + Account creation.

**Ads platform**: Overwolf monetiza con overlay ads. Premium tier para remove.

**TOS gray area**: same que cualquier third-party overlay.

**Windows only**: macOS/Linux excluded.

**Content subset**: overlay UX simplified vs full website. Para deep dives, full website mejor.

**Performance overhead**: additional overlay process puede impact FPS en low-end hardware.

## Cómo empezar

1. Install Overwolf platform.

2. Install Mobalytics D4 app desde Overwolf store.

3. Configure hotkey overlay toggle.

4. Lanza D4, verify overlay funciona.

5. Familiarizate con UI overlay vs full Mobalytics website — overlay tiene less features pero mid-gameplay reference.

6. Si te importa diversity de sources, install both Mobalytics y D4Builds overlays para cross-reference quick.
