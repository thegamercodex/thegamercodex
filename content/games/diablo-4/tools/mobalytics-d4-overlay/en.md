## What it is

Mobalytics D4 Overlay (mobalytics.gg/lol/glp/diablo-4-download) is the official Mobalytics desktop companion app for D4, distributed via the Overwolf platform. Brings Mobalytics content — builds, tier lists, class guides — to overlay on top of the D4 client.

## What problem it solves

For players who use Mobalytics as their primary hub, alt-tab from game to browser during gameplay breaks focus. The overlay eliminates that friction: hotkey toggle, info visible, hotkey toggle off.

## How it differs from D4Builds Overlay

- **Mobalytics Overlay**: Mobalytics ecosystem content (visual cards, tier badges).
- **D4Builds Overlay**: D4Builds.gg ecosystem content (community builds + Rob2628 curated).

Decision depends on which hub you use as primary. Functionally similar overlays with different content sources.

## What people actually use it for

**Mid-gameplay tier list quick reference**: confirm your build is still meta post-patch.

**Following build steps**: leveling or endgame, consult skill priorities without browser.

**Mobile-style card reading**: Mobalytics' visual UI translates well to overlay format.

**Multi-monitor alternative**: if you don't have a second monitor for guides, overlay substitutes.

## Who it's NOT for

- **Non-Mobalytics users**: if Maxroll/D4Builds are your primary, their respective overlay is better.
- **Mac/Linux/Console**: Overwolf platform is Windows-only PC.
- **Casuals without guide reference**: irrelevant.
- **Those avoiding Overwolf ads**: the platform monetizes with ads.

## How it's actually used

1. Install Overwolf from overwolf.com.

2. Install Mobalytics D4 app from [mobalytics.gg/lol/glp/diablo-4-download](https://mobalytics.gg/lol/glp/diablo-4-download) or Overwolf store.

3. Setup overlay hotkey.

4. Launch D4. Toggle overlay during gameplay.

5. Browse Mobalytics content overlaying the game.

## Honest limitations

**Overwolf overhead**: platform install + account creation.

**Platform ads**: Overwolf monetizes with overlay ads. Premium tier to remove.

**TOS gray area**: same as any third-party overlay.

**Windows only**: macOS/Linux excluded.

**Content subset**: overlay UX simplified vs full website. For deep dives, full website better.

**Performance overhead**: additional overlay process can impact FPS on low-end hardware.

## How to get started

1. Install Overwolf platform.

2. Install Mobalytics D4 app from Overwolf store.

3. Configure overlay toggle hotkey.

4. Launch D4, verify overlay works.

5. Get familiar with overlay UI vs full Mobalytics website — overlay has fewer features but mid-gameplay reference.

6. If you care about source diversity, install both Mobalytics and D4Builds overlays for quick cross-reference.
