## Qué es

DiabloRun (diablorun.com) es una plataforma comunitaria de tracking de speedrunning y leaderboards para juegos Diablo, ahora con foco principal en D4. Permite registrar character runs, trackear stats granulares y ver leaderboards per category.

Cubre:
- **Character creation runs**: from-scratch character, tracking de XP/hour, kills, deaths.
- **Campaign speedrun**: tiempo to complete main story.
- **Season ladder**: ranking por point/level metrics.
- **Per-class records**: best runs per build/class.
- **Comparative stats**: ves rankings de community con filtros granulares.

Free, sin login required para read. Login para registrar runs.

## Qué problema resuelve

D4's competitive leaderboards in-game son limited y no exponen detail granular. Para players con interest en speedrunning, optimization de runs o competing en community leaderboards, DiabloRun centraliza tracking que Blizzard no provee directamente.

También útil para self-improvement — ves tu XP/hour vs your previous run, identificás bottlenecks.

## Diferenciación vs Diablo 4 Codex

- **DiabloRun**: foco en performance metrics + leaderboards. ¿Cuán rápido / efficient sos?
- **Diablo 4 Codex**: foco en completion metrics. ¿Qué porcentaje del codex of power tienes?

DiabloRun es performance racing. Diablo 4 Codex es completion accounting. Diferentes goals.

## Para qué la usa la gente

**Speedrunning community**: tracking de community records, world records, personal bests.

**Self-improvement**: ves tu propio run progress, identificás dónde perdés tiempo.

**Comparativa with friends**: friends-only leaderboards si tu group compite.

**Season ladder**: ranking público por season metrics.

**Statistics deep dive**: granular metrics que el juego no expone (kills per zone, time per dungeon, etc.).

## Para quién NO es esta herramienta

- **Casuales sin speedrun interest**: si no compite, no aporta.
- **Quien busca builds**: no es content tool.
- **Quien evita data tracking**: requiere tracking de runs continuo.
- **Players sin endgame seasonal**: leaderboards relevantes son durante season activa.

## Cómo se usa en la práctica

1. [diablorun.com](https://diablorun.com).

2. Browse leaderboards sin login.

3. Para tracking personal: account login + character link.

4. **Submit run** post-completion para registrar.

5. Filtros: por class, season, category (campaign, Pit, etc.).

6. Compare profile vs others.

## Limitaciones honestas

**Niche**: speedrunning community en D4 es smaller vs PoE o D2. Coverage limitada.

**Manual submission**: depende de users postear runs. Coverage no es comprehensive.

**Updates depende de community**: post-season, leaderboards refresco depende de community activity.

**UI básica**: funcional pero menos polished vs competitive game leaderboards.

**Sin verification stricta**: relies en user honor system para entry validation.

## Cómo empezar

1. [diablorun.com](https://diablorun.com).

2. Browse community leaderboards a ver si te interesa.

3. Si te llama: cuenta + character link.

4. Submit your first run post-completion para test.

5. Una vez set up, runs futuras se trackean.

6. Si solo quieres casual stats, Diablo 4 Codex puede ser mejor fit. DiabloRun es para speed-competitive specifically.
