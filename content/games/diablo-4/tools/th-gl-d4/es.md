## Qué es

TH.GL Diablo IV Map (diablo4.th.gl) es un mapa interactivo de Sanctuary creado por **Leon Machens**. La feature característica es el drawing collaborativo: dibujas routes, marks, notes encima del mapa y compartes con tu group via link permanent. También disponible como overlay in-game via Overwolf app.

## Qué problema resuelve

Para coordinar Helltide routes, dungeon clearing strategies o boss positioning con tu static, screenshots con annotations son ineficientes. TH.GL te permite dibujar live sobre el mapa, sharing real-time con tu group.

## Diferenciación vs MapGenie

- **MapGenie**: most complete POI coverage + progress tracking + mobile app. No drawing.
- **TH.GL**: drawing + sharing collaborativo. Coverage base less than MapGenie.

Para completion tracking, MapGenie. Para coordination collaborativa, TH.GL.

## Para qué la usa la gente

**Route planning con static**: dibujas Helltide route eficiente y compartes con group.

**Strategy sharing**: para dungeon clears con multi-boss, marks de boss positions y player roles.

**Tutorial visuals**: content creators usan drawing para guides — marcas POIs específicos.

**Overlay in-game**: con Overwolf, ves mapa overlay durante gameplay.

**Open source**: código auditable, contribuciones community welcome.

## Para quién NO es esta herramienta

- **Solo players sin coordination needs**: drawing es overkill.
- **Quien quiere completion tracking**: MapGenie better.
- **Casuales sin endgame**: drawing routes asume goal-oriented play.
- **Mobile-first**: drawing UI es desktop-optimized.

## Cómo se usa en la práctica

1. [diablo4.th.gl](https://diablo4.th.gl/).

2. Open map. Drawing tools en sidebar.

3. Dibuja routes, marks, annotations.

4. **Share** → genera link permanent.

5. Para overlay in-game: instala Diablo 4 Map By Leon en Overwolf.

6. Coordina drawings con static via Discord.

## Limitaciones honestas

**Smaller community**: brand menos conocido que MapGenie o Helltides.com.

**Coverage base modest**: POIs less comprehensive que MapGenie.

**Drawing UI learning curve**: drawing tools toman tiempo to master.

**Update lag con patches**: new content tarda en quedar mapped.

**Overlay setup overhead**: Overwolf platform install requirement.

## Cómo empezar

1. [diablo4.th.gl](https://diablo4.th.gl/).

2. Familiarizate con map basics.

3. Prueba drawing tools — marca Lilith statues route como test.

4. Share link a yourself, verifica que aparece correcto.

5. Para overlay: install Diablo 4 Map By Leon via Overwolf si quieres in-game integration.

6. Para coordinated play, share drawings con static — workflow most valuable cuando hay grupo activo.
