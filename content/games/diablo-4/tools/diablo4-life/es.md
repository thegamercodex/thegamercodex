## Qué es

Diablo4.life es un community hub multi-purpose para D4 — combina event timers, curated build guides, achievement trackers y misc utilities en una sola landing page. La filosofía es centralizar everything D4-related en un solo destino sin requerir login.

Cubre:
- **Event timers**: Helltide, World Boss, Legion, Tree of Whispers.
- **Build guides**: curated selection con tier indicator.
- **Class spotlight**: featured builds que rotate per season.
- **Aspect & unique browser**: lookup con drop sources.
- **Patch notes**: link a official + community discussion.
- **Misc tools**: leveling planners, paragon calc, etc.

Free, sin login required.

## Qué problema resuelve

Mientras Helltides.com cubre 1 thing well y Maxroll cubre builds, players que quieren múltiples utilities sin abrir 5 tabs aprecian un consolidated hub. Diablo4.life es esa opción — sacrifices depth in each area pero gana coverage breadth.

Para casual-to-mid players que no necesitan max-min depth, una sola tab covers most workflows.

## Diferenciación vs Helltides.com

- **Helltides.com**: laser-focused single-purpose timer.
- **Diablo4.life**: multi-tool dashboard.

Si solo quieres Helltide info, Helltides.com es más rápido. Si quieres ese + Otros events + builds + lookups, Diablo4.life consolida.

## Para qué la usa la gente

**One-stop bookmark**: en lugar de Helltides.com + Maxroll + Wowhead + Codex, una página cubre 70% de needs.

**Event timing comprehensive**: ver Helltide + world boss + Legion en una sola vista.

**Build discovery rápida**: featured builds para inspo sin abrir Maxroll's depth.

**Aspects lookup ligero**: si solo quieres ver qué aspect da X dungeon, sin abrir Wowhead.

**Mobile-friendly**: la consolidación funciona bien en mobile vs abrir 5 sites separados.

## Para quién NO es esta herramienta

- **Quien necesita depth en una sola area**: para builds depth, Maxroll. Para database, Wowhead. Diablo4.life es breadth-over-depth.
- **Quien evita sites con muchos elementos en una página**: densa por design.
- **Hardcore optimizers**: las decisions/recommendations son lighter touch que sites editorial-driven.
- **Quien busca leaderboards/community**: features de community són más light.

## Cómo se usa en la práctica

1. [diablo4.life](https://diablo4.life).

2. Home page tiene secciones: Events (top), Builds (middle), Tools (bottom).

3. Events timer es visible at-a-glance.

4. Click en una build para detail (más light que Maxroll).

5. Search bar para lookup directo de aspects/uniques/skills.

6. Para discussion/community, links a Reddit + Discord externos.

## Limitaciones honestas

**Breadth-over-depth**: nada es "el mejor" en su category. Helltide timer es OK pero Helltides.com es mejor. Builds OK pero Maxroll mejor.

**UI density**: una sola página con mucho content puede sentirse cluttered. Acostumbrarse toma tiempo.

**Updates parciales**: con tantos features, algunos quedan stale. Helltide timer siempre updated, pero builds pueden ser de 1-2 seasons atrás.

**Sin login para advanced features**: tracking personal no es central. Para eso, Diablo 4 Codex.

**Maintenance dependiente community**: como muchos community sites, depend de volunteer activity.

## Cómo empezar

1. [diablo4.life](https://diablo4.life).

2. Scroll para familiarizarte con secciones.

3. Si te gusta el formato, bookmark.

4. Use Diablo4.life como punto de entrada cuando arrancás session, después abres depth tools (Maxroll, Wowhead) según necesidad.

5. Para Helltide-only urgent checks, Helltides.com sigue siendo más rápido.

6. Si juegas casual-to-mid, Diablo4.life puede ser tu only tool — funcional sin depth excesivo.
