## Qué es

Wowhead (wowhead.com/diablo-4) es la database de Diablo IV de Wowhead Network, también dueños de la database flagship de WoW. Lanzaron D4 coverage al launch en 2023 y mantienen el mismo standard de exhaustive coverage cross-game.

Para D4 cubre:
- **Database de items**: cada legendary, unique, mythic con stats, source, drop rates conocidas.
- **Aspects**: lista completa con effects, sources (dungeon/codex), nivel requirement.
- **Skills & paragon**: cada skill con tooltip detallado, paragon nodes con descripción.
- **Achievements**: completion tracking con community stats.
- **Interactive map**: locations de altars, bosses, statues, lilith statues.
- **News + datamining**: cuando hay PTR, datamine immediately — items, balance changes, unannounced features.

Free, sin login required.

## Qué problema resuelve

D4 no expone API pública detallada, y Blizzard's official "database" es minimal. Para preguntas tipo "¿qué aspect drop de Echo of Varshan?" o "¿cuál era el old vs new tooltip de Whirlwind?", Wowhead es la única referencia confiable que mantiene archivo histórico.

Para hardcore players, su datamining feed es source de leaks early sobre seasonal content y rebalances.

## Diferenciación vs Fextralife

- **Wowhead**: database technical pura. Stats, drops, sources. Editorial limited al patch notes coverage.
- **Fextralife**: wiki community-edited con prose narrativa, walkthroughs de quests, lore.

Wowhead resuelve "qué es este item / aspect / skill". Fextralife resuelve "cómo hago esta quest" o "qué es la historia de este boss".

## Para qué la usa la gente

**Lookup de aspect**: encuentras aspect en game, quieres saber el source. Wowhead te dice de qué dungeon viene o si es codex.

**Database items**: ¿qué legendaries existen para Necromancer? Wowhead lista todos filterables por clase.

**Datamined content**: pre-patch, Wowhead publica leaks del PTR datamine. Te enteras de nuevos uniques antes que sean revealed oficial.

**Interactive map**: hunting Lilith statues, altars o specific NPCs. La map te muestra coords exactos.

**Patch coverage**: cuando sale patch, Wowhead publica article con changes documented y context.

## Para quién NO es esta herramienta

- **Quien busca builds**: Wowhead lista items, no opina sobre meta. Para builds, Maxroll/Mobalytics.
- **Quien quiere narrative/lore**: para lore deep dives, Fextralife.
- **Quien evita datamining spoilers**: Wowhead publica leaks que pueden spoilear seasonal mechanics. Si prefieres sorpresas, evitar.
- **Mobile users**: la database tiene mucha info por screen — mobile experience es OK pero no óptima.

## Cómo se usa en la práctica

1. [wowhead.com/diablo-4](https://www.wowhead.com/diablo-4).

2. **Database** menu: items, aspects, uniques, skills.

3. Search bar: escribes nombre exact o partial.

4. Cada entry tiene tabs: Overview, Source, Used in, Comments.

5. **Map** section: interactive map con filters de altars, lilith, dungeons.

6. **News**: home page lists latest articles incluyendo PTR datamine.

7. Para usuarios serios: Wowhead Premium ($1/mes) elimina ads y adds features menores.

## Limitaciones honestas

**No opinion sobre meta**: Wowhead lista. No te dice "este aspect es bueno". Para evaluation, otros sites.

**Ads moderadas a heavy**: monetizan con ads display. Tier Premium las quita.

**Database puede tener gaps**: items o aspects new añadidos en patches pueden tardar 1-3 días en aparecer fully tooltipped.

**Comments community varia in quality**: comments en items son hit-or-miss. Sometimes muy útiles, otras spam.

**Datamining spoilers default**: si sigues Wowhead casual, te vas a topar con seasonal spoilers. No es algo opt-out.

## Cómo empezar

1. [wowhead.com/diablo-4](https://www.wowhead.com/diablo-4). No login required.

2. Browse **Database** → familiarizate con la estructura.

3. Para tu clase: filtra items y aspects relevantes.

4. Prueba search: "Whirlwind" o "Andariel" para ver result depth.

5. Bookmarkea el sitio + suscribite a newsletter si quieres patch news directos.

6. Combinalo con Maxroll para builds + Wowhead para items/aspects database — esos dos cover casi todo lo que necesitas.
