## Qué es

D4builds.gg es una plataforma community-driven de build sharing para D4. Cualquier user crea cuenta y postea su build con skill tree completo, paragon board, gear pieces y aspect choices. Otros users votan, comentan y forkean variantes.

A diferencia de Maxroll o Mobalytics (editoriales con curation), D4builds.gg es abierto — no hay filtro de quality. El community voting hace el filtrado natural: builds populares suben, builds malos quedan al fondo.

Características:
- **Build editor visual**: skill tree, paragon board, gear slots, aspects.
- **Vote system**: thumbs up/down de la comunidad.
- **Filter & search**: por clase, season, vote count, recency.
- **Fork builds**: tomas un build existente, lo modificas y publicas tu variant.
- **Comments**: discusión per build entre community.

Free, sin login para read. Login required para postear/votar.

## Qué problema resuelve

Los hubs editoriales (Maxroll, Mobalytics, Icy Veins) curan calidad pero limitan variety. Si quieres ver builds off-meta, experimental, o ideas raras de la community, esos sites no las cubren — no pasan el filtro editorial.

D4builds.gg democratiza el space: todo build publishable, community decide qué bubbles up. Para players que quieren explorar más allá del top tier, o que tienen ideas no-canónicas y quieren ver si funcionan, es indispensable.

## Diferenciación vs D4 Planner

Ambos sirven como build planners. Diferencias:

- **D4builds.gg**: foco en community + sharing. La plataforma está optimizada para discovery y voting.
- **D4 Planner**: foco en planning individual. Mejor UI para mockear builds privadamente, comparativas side-by-side.

Para discover builds existentes, D4builds.gg. Para planificar tu propia build desde cero, D4 Planner.

## Para qué la usa la gente

**Discovery off-meta**: Quieres intentar un Druid melee. D4builds.gg te muestra los 3 builds más voted en esa categoría.

**Fork & customize**: Copias un build top, lo ajustas a tu gear actual o preferencia.

**Validar ideas raras**: Tienes una idea de build no canónica. Lo publicas, ves si la comunidad la upvotea.

**Comparar variants**: hay 10 builds de Necromancer Blood. ¿Cuál sigo? El que tiene más votes y comments positivos.

**Buscar leveling builds compactos**: muchos users postean builds específicamente para leveling 1-60, separadas de endgame.

## Para quién NO es esta herramienta

- **Quien busca curated top-tier exclusivo**: hay mucho ruido. Para "el build óptimo objetivo" ir a Maxroll.
- **Newcomers absolutos**: sin context, no sabes diferenciar builds buenos vs experimentales fallidos. Mejor arrancar en Maxroll y volver acá cuando entiendes meta.
- **Quien evita comentarios drama**: comments pueden volverse toxic en discusiones meta entre community fanbases.
- **Spanish-speakers**: la UI y mayoría de builds están en inglés. Hay algunos hispanic users pero comunidad mayoritariamente EN.

## Cómo se usa en la práctica

1. [d4builds.gg](https://d4builds.gg).

2. **Filter top bar**: clase, season, vote count, recency.

3. Click en un build → ves full skill tree, paragon, gear, aspects.

4. **Fork** (icon en top-right) para clonar y modificar a tu cuenta.

5. **Comment** o **Vote** si quieres engagement community.

6. Para postear tuyo: **Create Build** → editor visual.

7. Filter por **Hot** para ver lo que está trending; **Top** para histórico de mejor voted.

## Limitaciones honestas

**Quality variable**: no hay editorial filter, lo cual significa builds outdated, builds incompletas, builds clones de Maxroll. Hay que filtrar manualmente.

**Voting puede ser gamed**: bots o circle voting pueden inflar builds malos. La community lo controla pero no es perfecto.

**Outdated builds**: builds de seasons pasadas siguen apareciendo. Filter "Current Season" ayuda pero no es default siempre.

**UI menos pulida vs Maxroll**: funciona pero algunos workflows son friction-y (especialmente paragon planning en mobile).

**Sin justification**: builds postean stats y choices pero rara vez explican el "por qué". Es discovery puro, no learning depth.

## Cómo empezar

1. [d4builds.gg](https://d4builds.gg), opcionalmente registrate.

2. Filter por tu clase + "Current Season" + sort "Top".

3. Explore top 5 builds. Click cada uno para detail.

4. Comparalos con tier lists de Maxroll/Mobalytics. ¿El top de D4builds está en S tier de Maxroll? Probablemente sí.

5. Para custom: fork un build existente, ajusta a tu gear, publica si te animas.

6. Use D4builds para diversity + discovery; complementa con Maxroll para depth + justification.
