## Qué es

D4Builds Overlay (overwolf.com/app/d4builds-d4builds) es la desktop companion app oficial de **D4Builds.gg** distribuida via la plataforma Overwolf. Te permite acceder al contenido completo de D4Builds.gg —  builds curados, build planner, tier lists, community builds — overlay encima del cliente de Diablo IV.

## Qué problema resuelve

Mientras farmás endgame o pushing Pit, consultar builds web requires alt-tab que rompe focus. Overlay lo elimina: hotkey activa el overlay, ves info, hotkey lo desactiva. Useful para players que siguen guides step-by-step sin querer perder gameplay focus.

## Diferenciación vs Mobalytics D4 Overlay

- **D4Builds Overlay**: muestra D4Builds.gg content específico (builds community + curated por Rob2628).
- **Mobalytics Overlay**: muestra Mobalytics content (tier lists + builds Mobalytics-curated).

Diferentes brands, same functional category. Decision depends on cuál hub usas más.

## Para qué la usa la gente

**Build reference mid-gameplay**: durante leveling o farm, consultás skill priorities sin abrir browser.

**Tier list quick check**: pre-respec, abres overlay para confirm cur build sigue top tier.

**Community builds browsing**: explorar builds de D4Builds community without alt-tab.

**Multi-monitor users**: alternative a dedicated secondary monitor para guide reference.

## Para quién NO es esta herramienta

- **Mac / Linux users**: Overwolf es Windows-only.
- **Console players**: PC only.
- **Quien evita Overwolf**: la plataforma instalación adicional puede molestar (Overwolf monetiza con ads en overlay).
- **Casuales**: si juegas sin guide reference, no aporta.

## Cómo se usa en la práctica

1. Install Overwolf desde overwolf.com.

2. Install D4Builds app desde [overwolf.com/app/d4builds-d4builds](https://www.overwolf.com/app/d4builds-d4builds).

3. Setup hotkey para toggle overlay.

4. Launch D4. Toggle overlay para consultar content.

5. Browse builds/tier lists/planner sin perder gameplay focus.

## Limitaciones honestas

**Overwolf platform requirement**: adds another layer (install + account). Algunos users find overhead annoying.

**Overwolf ads**: la plataforma monetiza con ads en overlay. Premium tier disponible para remove.

**TOS gray area**: technically third-party overlay. Blizzard tolerates Overwolf apps en practice pero no formally approved.

**Windows only**: Mac/Linux excluded.

**Performance overhead**: overlay corre additional process. En low-end hardware puede impact FPS.

**No replace de full website**: overlay tiene UX simplified vs full d4builds.gg site.

## Cómo empezar

1. Install Overwolf platform.

2. Install D4Builds app desde Overwolf store.

3. Configura hotkey de overlay toggle.

4. Lanza D4 + verify que el overlay funciona during gameplay.

5. Familiarizate con UI overlay — menos features que website pero suficiente para mid-gameplay reference.

6. Si Overwolf ads molestan, considerá Premium o usa D4Builds.gg website + alt-tab según prefieras.
