## What it is

D4Builds Overlay (overwolf.com/app/d4builds-d4builds) is the official desktop companion app from **D4Builds.gg** distributed via the Overwolf platform. Lets you access D4Builds.gg's complete content — curated builds, build planner, tier lists, community builds — overlaid on top of the Diablo IV client.

## What problem it solves

While farming endgame or pushing Pit, consulting web builds requires alt-tab that breaks focus. The overlay eliminates that: hotkey activates the overlay, see info, hotkey deactivates. Useful for players following step-by-step guides without wanting to lose gameplay focus.

## How it differs from Mobalytics D4 Overlay

- **D4Builds Overlay**: shows specific D4Builds.gg content (community builds + curated by Rob2628).
- **Mobalytics Overlay**: shows Mobalytics content (tier lists + Mobalytics-curated builds).

Different brands, same functional category. Decision depends on which hub you use more.

## What people actually use it for

**Mid-gameplay build reference**: during leveling or farm, consult skill priorities without opening browser.

**Quick tier list check**: pre-respec, open overlay to confirm current build is still top tier.

**Community builds browsing**: explore D4Builds community builds without alt-tab.

**Multi-monitor users**: alternative to dedicated secondary monitor for guide reference.

## Who it's NOT for

- **Mac / Linux users**: Overwolf is Windows-only.
- **Console players**: PC only.
- **Those avoiding Overwolf**: the platform's additional installation can annoy (Overwolf monetizes with overlay ads).
- **Casuals**: if you play without guide reference, doesn't add anything.

## How it's actually used

1. Install Overwolf from overwolf.com.

2. Install D4Builds app from [overwolf.com/app/d4builds-d4builds](https://www.overwolf.com/app/d4builds-d4builds).

3. Setup hotkey for overlay toggle.

4. Launch D4. Toggle overlay to consult content.

5. Browse builds/tier lists/planner without losing gameplay focus.

## Honest limitations

**Overwolf platform requirement**: adds another layer (install + account). Some users find overhead annoying.

**Overwolf ads**: the platform monetizes with overlay ads. Premium tier available to remove.

**TOS gray area**: technically third-party overlay. Blizzard tolerates Overwolf apps in practice but not formally approved.

**Windows only**: Mac/Linux excluded.

**Performance overhead**: overlay runs additional process. On low-end hardware may impact FPS.

**Doesn't replace full website**: overlay has simplified UX vs full d4builds.gg site.

## How to get started

1. Install Overwolf platform.

2. Install D4Builds app from Overwolf store.

3. Configure overlay toggle hotkey.

4. Launch D4 + verify overlay works during gameplay.

5. Get familiar with overlay UI — fewer features than website but enough for mid-gameplay reference.

6. If Overwolf ads bother you, consider Premium or use D4Builds.gg website + alt-tab as you prefer.
