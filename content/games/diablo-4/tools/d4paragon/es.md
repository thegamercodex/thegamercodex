## Qué es

D4Paragon (d4-paragon.com) es una herramienta web dedicada a la optimización del paragon system de D4. Más allá de un build planner general (skill tree + paragon + gear), D4Paragon se enfoca solamente en el paragon: 5+ boards, glyph placement, rare nodes, board rotation, attribute stacking.

## Qué problema resuelve

El paragon system de D4 tiene complexity creciente — cada nuevo level añade boards, glyphs cap at level 100+, y rare nodes específicos pueden multiplicar power non-linear. Planificar manualmente o con un planner general es tedioso. D4Paragon te da UI focused para mockear sin distractions.

## Diferenciación vs D4 Planner

- **D4Paragon**: solo paragon. UI specialized.
- **D4 Planner**: planner full (skills + paragon + gear) con paragon as one feature.

Si tu bottleneck es paragon optimization specifically, D4Paragon es más eficiente. Para planning full build, D4 Planner.

## Para qué la usa la gente

**Pre-respec planning**: respec costs en endgame son altos. D4Paragon te permite mock changes antes de spend gold.

**Push optimization**: para Pit 150+ where cada % matters, paragon details specific maximizan ceiling.

**Glyph swap analysis**: ¿este glyph nuevo en mi rare node es upgrade real? D4Paragon te muestra impact stat exact.

**Board rotation experimentation**: el paragon system permite múltiples boards con rotations. Planning visual te ayuda decide la mejor arrangement.

**Theorycraft compartir**: shareable links para discutir paragon ideas en Discord.

## Para quién NO es esta herramienta

- **Casuales sin endgame paragon depth**: si juegas campaign o early endgame, no aporta.
- **Quien busca full build planner**: D4 Planner o Maxroll Planner cubren full picture.
- **PvP**: paragon impacts PvP pero meta es distinto.
- **Mobile users**: paragon board rotation es difícil de operar in mobile.

## Cómo se usa en la práctica

1. [d4-paragon.com](https://d4-paragon.com).

2. New planning → selectá class.

3. Mockear board placement, glyph slots, rare nodes activations.

4. Ves stats totals reflejadas en real-time.

5. Share link → para discutir con static o mentor.

## Limitaciones honestas

**Patch lag**: post-patch, new paragon changes tardan en reflejarse en la tool.

**Sin opinion editorial**: te muestra stats. No te dice si es óptimo vs alternativas. Para validation, cross-checkear con Maxroll guides.

**Single-purpose**: no replaces full planner. Para skill tree o gear, otros tools.

**Maintenance owner-dependent**: project mantenido por individual.

**Learning curve**: paragon system inherente es complejo. Tool ayuda pero no enseña.

## Cómo empezar

1. [d4-paragon.com](https://d4-paragon.com).

2. Importá tu current paragon (o empieza from scratch).

3. Mock changes — clic en glyphs o nodes para experimentar.

4. Compará stats output entre variants.

5. Implementa in-game con confidence.

6. Cross-checkea con paragon section de Maxroll guide de tu build para validation.
