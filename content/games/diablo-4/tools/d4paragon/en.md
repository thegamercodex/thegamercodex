## What it is

D4Paragon (d4-paragon.com) is a web tool dedicated to D4's paragon system optimization. Beyond a general build planner (skill tree + paragon + gear), D4Paragon focuses only on paragon: 5+ boards, glyph placement, rare nodes, board rotation, attribute stacking.

## What problem it solves

D4's paragon system has growing complexity — each new level adds boards, glyphs cap at level 100+, and specific rare nodes can multiply power non-linearly. Manually planning or with a general planner is tedious. D4Paragon gives you a focused UI to mock without distractions.

## How it differs from D4 Planner

- **D4Paragon**: paragon only. Specialized UI.
- **D4 Planner**: full planner (skills + paragon + gear) with paragon as one feature.

If your bottleneck is paragon optimization specifically, D4Paragon is more efficient. For full build planning, D4 Planner.

## What people actually use it for

**Pre-respec planning**: endgame respec costs are high. D4Paragon lets you mock changes before spending gold.

**Push optimization**: for Pit 150+ where each % matters, specific paragon details maximize the ceiling.

**Glyph swap analysis**: is this new glyph in my rare node a real upgrade? D4Paragon shows exact stat impact.

**Board rotation experimentation**: the paragon system allows multiple boards with rotations. Visual planning helps you decide the best arrangement.

**Theorycraft sharing**: shareable links to discuss paragon ideas on Discord.

## Who it's NOT for

- **Casuals without endgame paragon depth**: if you play campaign or early endgame, doesn't add anything.
- **Those seeking a full build planner**: D4 Planner or Maxroll Planner cover the full picture.
- **PvP**: paragon impacts PvP but meta is different.
- **Mobile users**: paragon board rotation is hard to operate on mobile.

## How it's actually used

1. [d4-paragon.com](https://d4-paragon.com).

2. New planning → select class.

3. Mock board placement, glyph slots, rare node activations.

4. See totals stats reflected in real time.

5. Share link → to discuss with static or mentor.

## Honest limitations

**Patch lag**: post-patch, new paragon changes take time to reflect in the tool.

**No editorial opinion**: shows stats. Doesn't tell you if it's optimal vs alternatives. For validation, cross-check with Maxroll guides.

**Single-purpose**: doesn't replace a full planner. For skill tree or gear, other tools.

**Owner-dependent maintenance**: project maintained by an individual.

**Learning curve**: paragon system is inherently complex. Tool helps but doesn't teach.

## How to get started

1. [d4-paragon.com](https://d4-paragon.com).

2. Import your current paragon (or start from scratch).

3. Mock changes — click glyphs or nodes to experiment.

4. Compare stat output between variants.

5. Implement in-game with confidence.

6. Cross-check with the paragon section of your build's Maxroll guide for validation.
