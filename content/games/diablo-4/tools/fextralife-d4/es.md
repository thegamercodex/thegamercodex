## Qué es

Fextralife (diablo4.wiki.fextralife.com) es un wiki MediaWiki community-edited operado por Fextralife Network, conocidos por wikis de Soulslike games y MMOs. Editan profesionalmente con community contributions filtradas.

Para D4 cubre:
- **Quest walkthroughs**: cada main y side quest con prerequisites, rewards, walkthrough paso-a-paso.
- **Dungeon guides**: locations, boss encounters, drop tables.
- **NPC pages**: dialogue, locations, quest associations.
- **Class pages**: overview narrative (no stats deep).
- **Builds**: builds populares con guide structure.
- **Lore pages**: regiones, factions, Lilith, ancients.

Free, sin login required para read. Login para editar (raro para casual user).

## Qué problema resuelve

Para info narrativa o "cómo se hace algo", Wowhead's database structure es pobre. Si estás stuck en una quest, quieres saber el lore de Sanctuary, o necesitas guía paso-a-paso de un dungeon — Fextralife cubre eso mejor.

Para D4 específicamente, players migrando de single-player games (Skyrim, Souls) encuentran familiar el formato wiki narrative.

## Diferenciación vs Wowhead D4

- **Wowhead**: technical database. Items + stats + tooltips.
- **Fextralife**: narrative wiki. Quests + walkthroughs + lore.

Pregunta a Wowhead "qué stats tiene este aspect". Pregunta a Fextralife "cómo desbloqueo este aspect via quest".

## Para qué la usa la gente

**Quest stuck**: estás en una side quest de Hawezar y no sabes a dónde ir. Fextralife te da steps.

**Lore deep-dive**: quieres entender Mephisto antes del DLC. Fextralife tiene página dedicada con context.

**Dungeon walkthroughs**: nuevo dungeon en patch, no sabes mechanics. Fextralife describe boss + mob layout.

**Location hunting**: buscas un specific NPC o vendor. Fextralife te da location.

**Achievement guides**: muchos achievements requieren steps específicos. Fextralife los lista.

## Para quién NO es esta herramienta

- **Quien busca builds optimization**: builds existen pero no son foco — para tier lists, Maxroll/Mobalytics.
- **Quien busca datamining**: Fextralife no hace datamining como Wowhead. Solo content released.
- **Players que evitan ads**: Fextralife es ad-heavy. Adblock recomendado.
- **Mobile-first**: aunque responsive, pages con muchas tablas e info son rough en mobile.

## Cómo se usa en la práctica

1. [diablo4.wiki.fextralife.com](https://diablo4.wiki.fextralife.com).

2. Top navigation: Classes, Locations, Quests, Items, NPCs.

3. Search bar para lookup directo.

4. Cada page sigue formato MediaWiki: sections con headers, tables, embedded media.

5. Para quests: "Walkthrough" section es el paso-a-paso.

6. Para dungeons: bosses listados con mechanics + drops.

7. Para lore: pages de characters y factions con cross-references entre ellas.

## Limitaciones honestas

**Ads heavy**: Fextralife es de los wikis con más ads del space. La experiencia sin adblock es invasive.

**Quality inconsistente**: como community-edited, algunas pages están muy completas (popular content), otras stub (niche).

**Updates a veces lentos**: post-patch, nuevo content puede tardar weeks en quedar fully documented.

**Builds menos curados**: builds existen pero no son evaluated. Para top tier, Maxroll mejor.

**UI cluttered**: tablas + ads + community widgets pueden hacer scrolling difícil. Acostumbrarse toma tiempo.

## Cómo empezar

1. [diablo4.wiki.fextralife.com](https://diablo4.wiki.fextralife.com).

2. Browse o search por una quest o NPC que conoces.

3. Compara depth narrativo con Wowhead — Fextralife va más a "story", Wowhead a "data".

4. Para classes: navegá las páginas de clase pero espera overview, no min-max guide.

5. Use Fextralife como complemento a Wowhead + Maxroll, no replacement.

6. Si encuentras pages incompletas y quieres contribuir, login y edit (es MediaWiki standard).
