## Qué es

Mobalytics (mobalytics.gg/diablo-4) es la sección de D4 dentro del hub multi-juego Mobalytics, que cubre principalmente LoL desde 2017 y se expandió a otros titles incluido D4. La compañía está bien establecida con financing serio y UI moderna across all games.

Para D4 ofrece:
- **Tier lists per class y per build** con badges visuales (S/A/B/C tier).
- **Build cards compactas** con skills, gear summary, paragon highlights — toda info en un scroll.
- **Class guides básicas** con stat priority y leveling.
- **Patch coverage** con resúmenes editoriales.

Free, sin login required para read. Login para favorites.

## Qué problema resuelve

Maxroll y otros sites cubren D4 con prose extensa que requiere lectura. Para players que ya conocen el game y solo necesitan refresh del meta actual ("¿qué build pega esta season?"), leer 5 pantallas de prose es overkill.

Mobalytics resuelve esto con presentation visual: scroll por las builds, ves tier al toque, abres una card y tienes los essentials sin scroll infinito. Para quick decisions optimiza el tiempo de lookup.

## Diferenciación vs Maxroll

- **Maxroll**: depth + prose. Build guide es una small essay con justificación de cada slot.
- **Mobalytics**: speed + visual. Build card es una infografía compacta.

Para learning, Maxroll. Para quick reference, Mobalytics. Muchos usan ambos.

## Para qué la usa la gente

**Quick meta check**: 5 min de scroll te dan el tier list state actual.

**Comparar builds visualmente**: ves 3 builds de Necromancer side-by-side rápido en lugar de abrir 3 tabs.

**Onboarding amigos**: la UI moderna y visual es más amigable para friends que recién empiezan que la página larga de Maxroll.

**Mobile browsing**: la UI funciona mejor en mobile que sites con prose densa.

**Tier list reference**: si solo quieres saber "¿es viable Druid?" en 10 segundos, Mobalytics te da la respuesta más rápido.

## Para quién NO es esta herramienta

- **Hardcore optimizers**: cards visuales sacrifican depth. Para justificación detallada de stat priorities o paragon edge cases, Maxroll.
- **Leveling-focused**: contenido de leveling es más light vs Maxroll.
- **Players sin internet rápida**: Mobalytics es image-heavy y consume bandwidth.
- **Discusión community**: no hay comments activos como en Maxroll o Reddit. Es read-only.

## Cómo se usa en la práctica

1. [mobalytics.gg/diablo-4](https://mobalytics.gg/diablo-4).

2. Top menu: **Classes**, **Builds**, **Tier List**.

3. Click en tu clase → ves cards de builds populares con tier visible.

4. Card click → expanded view con skills, paragon nodes principales, gear list.

5. Para tier list global: **Tier List** section te da overview cross-class.

6. Patch notes / news están en home page del hub D4.

## Limitaciones honestas

**Menos depth**: la simplificación visual implica perder context. Para por qué un build funciona, Maxroll está mejor.

**Coverage menor**: builds publicados son menos que Maxroll. Solo cubren top tier; for off-meta o experimental, otros sites.

**Updates más lentos post-patch**: Mobalytics suele tardar 1-2 días más que Maxroll en revisar tier lists.

**Bias hacia visual lookahead**: la UI compact a veces simplifica decisiones complejas. Build "S tier" en Mobalytics puede tener nuance que solo se ve en Maxroll's prose.

**Multi-game site, foco distribuido**: el equipo cubre múltiples games. Cuando D4 no es priority dev-cycle, contenido refresca más lento.

## Cómo empezar

1. [mobalytics.gg/diablo-4](https://mobalytics.gg/diablo-4).

2. **Tier List** primero — overview cross-class del estado actual.

3. Elegí una clase top-tier que te gusta visualmente.

4. Browseá build cards de esa clase. Clickeá una para detail expanded.

5. Si la card te convence, considerá cross-checkear con Maxroll para depth antes de invertir en el char.

6. Para uso continuo, bookmark y refrescá weekly durante season activa.
