## Qué es

Maxroll (maxroll.gg/d4) es un hub editorial de gaming con foco en ARPGs, manejado por Maxroll Team — un grupo profesional que combina creators conocidos con editorial staff dedicado. Existe desde 2020 cubriendo originalmente Diablo III y se expandió a D4, PoE, PoE 2, Last Epoch, D2 Resurrected y Lost Ark.

Para D4 específicamente provee:
- **Build planner interactivo**: skill tree + paragon board + gear con justificación de cada slot.
- **Build guides extensas**: con leveling path, endgame variants y comparison vs alternatives.
- **Tier lists per class**: actualizadas al patch actual con notas de balance.
- **Class guides foundationales**: para newcomers que recién eligen su clase.
- **News + patch analysis**: cuando sale balance change, análisis profundo a las pocas horas.

Free, sin login para read. Login para favorites y comments.

## Qué problema resuelve

D4 tiene 6 clases, 5 specs por clase aprox, paragon board complejo con glyphs, y un sistema de aspects/uniques que multiplica build options. Sin un site curado de calidad, el casual se pierde y el competitive pierde tiempo descubriendo lo que ya está descubierto.

Maxroll resuelve esto centralizando: vas, eliges clase, ves los top 3-5 builds del patch actual con tier rating, abres el guide y tienes desde leveling hasta paragon endgame en una sola página. Ahorra horas vs assembling info de Reddit posts dispersos.

## Diferenciación vs Mobalytics

Ambos cubren builds + tier lists + guides para D4. Diferencias:

- **Maxroll**: foco en depth — guides largas con prose extensa, justificación de cada slot, leveling path explicado. Mejor para learners que quieren entender el por qué.
- **Mobalytics**: foco en speed — tier lists rápidas con cards visuales, builds expressed en formato más compacto. Mejor para quien ya entiende el game y solo necesita "qué build uso esta season".

Mucha gente usa los dos: Mobalytics para vista rápida de meta, Maxroll para deep dive del build elegido.

## Para qué la usa la gente

**Elegir clase pre-season**: 2 semanas antes del season start, lees tier lists de Maxroll para ver qué clase está fuerte y planeas tu fresh char.

**Leveling build**: el guide te da el leveling path optimal (skills to take en orden, gear baseline) hasta endgame transition.

**Endgame build optimization**: una vez en cap, ves variants del build (push variant, farm variant, Helltide variant) y eliges según tu goal.

**Patch update**: cuando sale balance change, Maxroll actualiza tier lists en horas. Su take editorial te dice si tu build sobrevivió o si toca rerolear.

**Paragon planning**: el planner permite mockear tu paragon board antes de gastar respec costs en game.

## Para quién NO es esta herramienta

- **PvP-only**: D4 PvP es marginal y Maxroll no le da espacio editorial relevante.
- **Lore enthusiasts**: este es technical content. Para lore/quest walkthroughs ir a Fextralife.
- **Players que prefieren video sobre texto**: aunque Maxroll embed videos en algunos guides, el primary medium es texto largo. Para video-first, hay YouTube creators.
- **Hardcore-only theorycrafters**: para max-min absoluto, Maxroll a veces se queda en "build canónico" sin explorar edge cases que un job-lead sí cubriría. Para eso, leer Reddit/Discord especializados.

## Cómo se usa en la práctica

1. Anda a [maxroll.gg/d4](https://maxroll.gg/d4).

2. Browse por **Classes** → eliges tu clase. Ves todas las builds publicadas con tier rating.

3. Click en el build que te interesa. La página tiene secciones: Overview, Skills, Paragon, Gear, Mechanics.

4. Abre el **Planner** del build (link en cada guide) para verlo en formato interactivo. Puedes clonarlo a tu account para modificar.

5. Para tier lists generales: **Class Tier List** y **Build Tier List** en el menu top.

6. Para news: home page lista latest articles incluyendo patch analysis y season previews.

## Limitaciones honestas

**Foco predominante en endgame**: aunque cubren leveling, lo más detallado es el endgame. Para los primeros 50 niveles puedes irte con cualquier build de Maxroll y va a funcionar.

**Build variety limitada por curation**: solo publican builds que pasan el filtro editorial. Si quieres ver builds creativas off-meta, D4builds.gg ofrece más diversidad.

**Bias hacia top tier**: las recomendaciones tienden a S/A tier builds. Para clases o specs B-tier el contenido es más escaso.

**Algunos ads/donations**: el site no es completamente clean — hay ads display y newsletter prompts. Manejable con adblock pero existe.

**Updates rápidos pero no inmediatos**: post-patch típicamente toma 24-72 horas tener tier lists fully revised. Para reaction inmediata al balance change, mejor seguir el Discord oficial de Maxroll.

## Cómo empezar

1. [maxroll.gg/d4](https://maxroll.gg/d4). No login required.

2. Si recién empiezas, ve a **Class Tier List** y elige una clase top-tier para tu primer character.

3. Anda al guide del top build de esa clase. Lee la sección **Leveling** primero.

4. Importa el planner si quieres modificarlo a tu situación específica.

5. Una vez en endgame, relees el **Endgame** y **Paragon** sections para refinar.

6. Bookmark Maxroll y revisa weekly durante season activa para ver tier list shifts.

7. Para discusión/Q&A, el Discord de Maxroll es activo — guide authors están ahí y responden.
