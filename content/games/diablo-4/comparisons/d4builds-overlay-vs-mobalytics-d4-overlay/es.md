Ambos overlays cumplen el mismo functional purpose: traer content de un hub editorial al overlay sobre Diablo IV. La elección no es funcional sino editorial — depende del hub que ya consumis.

## D4Builds Overlay

Overlay del ecosystem D4Builds.gg. Acceso a community builds voted-up, Rob2628's curated picks, planner integrado, tier list. Tono community-driven.

## Mobalytics Overlay

Overlay del ecosystem Mobalytics. Visual tier lists con S/A/B/C badges, Mobalytics-curated builds, class guides en formato modern card. Tono editorial visual.

## Cuándo cada uno

- **D4Builds Overlay**: si ya usas D4Builds.gg como primary hub. Si valorás community-driven discovery y voted-up build diversity.
- **Mobalytics Overlay**: si ya usas Mobalytics. Si valorás visual tier lists y modern UI cards.

## Tradeoff común

Ambos requieren Overwolf platform install (overhead inicial). Ambos tienen TOS gray area same que cualquier third-party overlay. Ambos consumen FPS impact en low-end hardware.

## Veredicto

No hay "ganador objectivo". Si solo usas un hub, su respective overlay. Si usas ambos hubs, install both — Overwolf permite toggling.

Functionally similar, content-source-distinct. La pregunta correcta es "qué hub usas más para builds y tier lists" — la respuesta determina el overlay.
