Para planning en D4 hay opciones. La elección entre D4Paragon y D4 Planner viene determinada por scope: ¿solo paragon, o full build?

## D4 Planner: all-purpose

Cubre el flow completo del build: skill tree, paragon board, gear pieces, aspects. UI integrada en single page. Útil cuando estás creando un build desde scratch o iterando un build completo.

## D4Paragon: paragon specialist

Solo paragon system. UI focused exclusively en boards, glyph placement, rare nodes, board rotation. Ahorra clutter para players que ya tienen skills y gear definidos y solo quieren refinar paragon.

## Cuándo cada uno

- **D4 Planner**: build new desde scratch, comparar full builds, leveling planning.
- **D4Paragon**: optimization paragon de build existente, pre-respec mockup, push-tier paragon refinement.

## Flow combinado

1. **D4 Planner** para crear o adoptar el build base.
2. **D4Paragon** para deep-dive optimization del paragon section una vez baseline está set.
3. Implement in-game.

## Veredicto

No competidores estrictos. Different scope: D4 Planner es general; D4Paragon es specialist. Serios usuarios usan ambos en sequence para distintas phases del build optimization.

Para casuales: D4 Planner alcanza. Para push-tier players con focus en paragon edge cases, D4Paragon agrega valor real.
