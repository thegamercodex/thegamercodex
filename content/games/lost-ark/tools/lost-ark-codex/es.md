## Qué es

Lost Ark Codex es una base de datos buscable, gratuita y de larga trayectoria para Lost Ark. Cataloga items, quests, skills y NPCs, y sirve URLs multi-región (us, eu, es y otras) para que jugadores de distintas versiones puedan usarla. Más allá de la base de datos, incluye un skill builder integrado que funciona también como un planner ligero para armar skills y tripods.

Es la referencia que abres cuando necesitas una respuesta precisa y cruda sobre datos del juego en lugar de orientación editorial.

## Qué problema resuelve

Cuando necesitas una cifra exacta — los stats precisos de un item, los pasos de una cadena de quests, o las particularidades de una skill y sus tripods — una guía que resume la opción "mejor" no ayuda. Necesitas el dato de fondo.

Codex resuelve ese problema de consulta. Es un catálogo buscable y estructurado de las entidades del juego, así que en lugar de revisar patch notes o tooltips dentro del juego puedes encontrar directamente los stats, ubicaciones y detalles exactos. El skill builder agrega una forma de bocetar un setup de skills sin comprometerte dentro del juego.

## Diferenciación

La comparación obvia es **Lost Ark Database**. Codex es la base de datos pura y de larga trayectoria más un skill builder — su alcance es deliberadamente acotado: consultar cosas y planear skills. Lost Ark Database es un all-in-one más amplio que combina una base de datos con guías y un mapa interactivo.

Si quieres una referencia ágil y enfocada para datos crudos y un armado rápido de skills, Codex es la herramienta más concentrada. Si prefieres tener base de datos, guías y mapa bajo un mismo techo, el más amplio Lost Ark Database cubre más terreno. Codex gana en enfoque; Database gana en amplitud.

## Para qué la usa la gente

- **Stats exactos de items:** consultar los números precisos de un item en lugar del resumen de una guía.
- **Cadenas de quests:** chequear hacia dónde lleva una línea de quests y qué requiere.
- **Detalles de skills y tripods:** leer las particularidades de una skill, incluidos los efectos de sus tripods.
- **Planificación ligera de skills:** usar el skill builder integrado para bocetar un setup antes de comprometerte dentro del juego.
- **Consultas por región:** usar la URL regional apropiada (us/eu/es/etc.) para la versión que juegas.

## Para quién NO es esta herramienta

No es la herramienta para quien busca orientación editorial de builds — qué engravings usar, qué build es meta, cómo hacer gearing de forma eficiente. Codex te da el dato crudo, no opiniones sobre cómo usarlo. Para guía curada de builds y raids, Maxroll es el destino correcto; Codex es lo que consultas una vez que ya sabes qué estás buscando.

## Cómo se usa en la práctica

1. Abre Lost Ark Codex en la URL regional que corresponda a tu servidor (us, eu, es, etc.).
2. Busca el item, quest, skill o NPC que necesitas.
3. Lee los stats exactos, la ubicación o los detalles de la entrada de la base de datos.
4. Para planear skills, abre el skill builder integrado y arma tus skills y tripods.
5. Guárdala en favoritos como referencia rápida para volver cada vez que surja una pregunta de datos.

## Limitaciones honestas

Codex es una base de datos, no una guía — te dice cuál es el dato, no qué hacer con él, así que igual vas a necesitar una fuente de guías para las decisiones de build y raid. El skill builder es ligero, así que no reemplaza a un planner completo para theorycraft serio. Como base de datos comunitaria, su vigencia depende de que se actualice tras los patches, y las entradas pueden atrasarse respecto del juego en vivo justo después de un update. Es gratis, y como en la mayoría de los sitios comunitarios conviene esperar ads que lo sostienen.

## Cómo empezar

Visita Lost Ark Codex usando la URL regional que corresponda a tu servidor — no necesitas cuenta ni descarga. Busca el item, quest, skill o NPC que necesites y lee los detalles exactos de su entrada. Si quieres planear un setup de skills, abre el skill builder integrado. Guárdala como tu referencia de datos crudos, y combínala con un sitio de guías como Maxroll para las decisiones editoriales que Codex deja afuera a propósito.
