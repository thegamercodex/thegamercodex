## What it is

Lost Ark Codex is a free, longstanding searchable database for Lost Ark. It catalogs items, quests, skills, and NPCs, and serves multi-region URLs (us, eu, es, and others) so players on different versions can use it. Beyond the database, it includes a built-in skill builder that doubles as a lightweight planner for laying out skills and tripods.

It's the reference you open when you need a precise, raw answer about game data rather than editorial guidance.

## What problem it solves

When you need an exact figure — an item's precise stats, the steps of a quest chain, or the specifics of a skill and its tripods — a guide that summarizes the "best" choice doesn't help. You need the underlying data.

Codex solves that lookup problem. It's a searchable, structured catalog of the game's entities, so instead of digging through patch notes or in-game tooltips you can find the exact stats, locations, and details directly. The skill builder adds a way to sketch out a skill setup without committing in-game.

## Differentiation

The obvious comparison is **Lost Ark Database**. Codex is the focused, longstanding pure database plus skill builder — its scope is deliberately narrow: look things up, and plan skills. Lost Ark Database is a broader all-in-one that bundles a database with guides and an interactive map.

If you want a lean, focused reference for raw data and a quick skill layout, Codex is the tighter tool. If you'd rather have database, guides, and a map under one roof, the broader Lost Ark Database covers more ground. Codex wins on focus; Database wins on breadth.

## What people use it for

- **Exact item stats:** Looking up an item's precise numbers rather than a guide's summary.
- **Quest chains:** Checking where a quest line leads and what it requires.
- **Skill and tripod details:** Reading the specifics of a skill, including its tripod effects.
- **Lightweight skill planning:** Using the built-in skill builder to sketch a setup before committing in-game.
- **Region-specific lookups:** Using the appropriate regional URL (us/eu/es/etc.) for the version you play.

## Who this tool is NOT for

This is not the tool for someone wanting editorial build guidance — which engravings to run, which build is meta, how to gear efficiently. Codex gives you the raw data, not opinions about how to use it. For curated build and raid guidance, Maxroll is the right destination; Codex is what you consult once you already know what you're looking for.

## How it's used in practice

1. Open Lost Ark Codex on the regional URL matching your server (us, eu, es, etc.).
2. Search for the item, quest, skill, or NPC you need.
3. Read the exact stats, location, or details from the database entry.
4. To plan skills, open the built-in skill builder and lay out your skills and tripods.
5. Keep it bookmarked as a quick reference to return to whenever a data question comes up.

## Honest limitations

Codex is a database, not a guide — it tells you what the data is, not what to do with it, so you'll still need a guide source for build and raid decisions. The skill builder is lightweight, so it won't replace a full planner for serious theorycraft. As a community database, its currency depends on being updated after patches, and entries can lag the live game right after an update. It's free, and as with most community sites you should expect ads supporting it.

## How to get started

Visit Lost Ark Codex using the regional URL that matches your server — no account or download required. Search for whatever item, quest, skill, or NPC you need and read the exact details from its entry. If you want to plan a skill setup, open the built-in skill builder. Bookmark it as your raw-data reference, and pair it with a guide site like Maxroll for the editorial decisions Codex deliberately leaves out.
