title: Lost Ark Codex vs Lost Ark Database — qué referencia usar
description: Dos formas de consultar los datos de Lost Ark. Una es una base de datos focalizada con skill builder; la otra un sitio todo-en-uno que suma guías y mapa.
---

Cuando necesitas buscar los stats exactos de un ítem, rastrear a dónde va una cadena de quests o revisar los tripods de una skill, recurres a un sitio de referencia. **Lost Ark Codex** y **Lost Ark Database** responden a esa necesidad, pero están construidos sobre filosofías distintas: Codex es la base de datos focalizada y de larga data, mientras que Lost Ark Database es el todo-en-uno más amplio.

## Alcance: focalizado vs todo-en-uno

Lost Ark Codex es desde hace años la base de datos consultable de la comunidad. Hace bien una sola cosa — búsquedas rápidas y precisas de ítems, quests, skills y NPCs — y suma un skill builder integrado que funciona como planificador liviano. También expone URLs por región (us, eu y una española entre ellas), lo que lo vuelve la opción más cómoda para lectores que no manejan inglés y quieren los datos en su idioma.

Lost Ark Database apunta más amplio. Junto a su base de datos empaqueta guías y un mapa interactivo propio, con la intención de ser un único destino para referencia, aprendizaje y exploración. Si prefieres no andar haciendo malabares con una base de datos, un hub de guías y un mapa por separado, pone más cosas bajo un mismo techo.

## La diferencia del skill builder

La línea más clara entre ambos es el skill builder. El de Codex te deja armar y compartir un setup de skills y tripods directamente desde la base de datos, algo que Database no iguala. Para un jugador que quiere planear una configuración sin abrir un planificador más pesado, ese agregado es una ventaja real.

## Cuándo gana cada uno

| Situación | Gana |
|---|---|
| Buscar los stats exactos de un ítem o detalle de una skill | Lost Ark Codex |
| Armar y compartir un setup de skills y tripods | Lost Ark Codex |
| Consultar la base de datos en español | Lost Ark Codex |
| Tener datos, guías y mapa sin abrir tres sitios | Lost Ark Database |
| Explorar con un mapa al lado de la base de datos | Lost Ark Database |

## El veredicto

Usa **Lost Ark Codex** cuando quieras una base de datos rápida y precisa y la comodidad de un skill builder — es la referencia más liviana y focalizada, y la que tiene datos en español. Usa **Lost Ark Database** cuando prefieras tener referencia, guías y mapa empaquetados en un solo lugar. En la práctica, la mayoría de los jugadores deja Codex abierto para consultas rápidas y recurre a un hub de guías dedicado (Maxroll) y a un mapa (Lost Ark Map) por separado — pero si prefieres un solo sitio haciendo varias tareas, Lost Ark Database es el todo-en-uno.
