## Qué es

NMSCD (No Man's Sky Community Database, según el branding) es un portal de herramientas comunitarias creado y mantenido por el equipo de AssistantNMS — el mismo grupo detrás de la companion app más popular del juego. La idea: muchas tools útiles para NMS son proyectos pequeños individuales que viven aisladas en GitHub o en sites personales. NMSCD las indexa, las hostea o linkea, y las pone bajo un dominio común.

A día de hoy contiene más de 30 tools categorizadas: generators (genera markup para páginas de wiki), calculators (conversiones de outputs de refinería, optimización de stack sizes), base helpers (planeamiento de layouts), data viewers, y conversores de glyphs/coordinates entre formatos.

Open source bajo el organization AssistantNMS en GitHub. Mantenido por 40+ voluntarios. Completamente gratis sin ads.

## Qué problema resuelve

Antes de NMSCD, las herramientas comunitarias de NMS vivían dispersas: un convertor de glyphs en una gist, una calculadora en un Tumblr, un wiki page generator en un repo abandonado. Encontrarlas requería googling y suerte; usarlas requería confiar en sites desconocidos.

NMSCD centraliza todo bajo el mismo team que construyó Assistant — o sea con cierto sello de calidad — y le da a las tools individuales un home común con UI consistente.

## Diferenciación

Frente a **Assistant for No Man's Sky**: Assistant es la companion app principal — recetas, refinería, eventos en vivo. NMSCD es el catálogo complementario de herramientas más nicho. La superposición es chica: NMSCD tiene tools que Assistant no ofrece (generators, calculators raras), mientras Assistant tiene la base de datos integrada que NMSCD no replica.

Frente a buscar en GitHub o foros directamente: NMSCD es más curado y consistente. La calidad varía pero el filtro inicial está hecho.

## Para qué la usa la gente

**Generators de wiki**: si estás documentando un planeta, ship o multi-tool en el Fandom Wiki, NMSCD tiene generators que armán el infobox markup automáticamente con los campos que tipeas.

**Calculators de crafting**: ¿cuánto Activated Indium produzco con X Indium, Y Carbon, en Z stacks? Hay calculadoras dedicadas.

**Conversores de coordinates**: NMS usa varios sistemas de coordenadas (glyphs, voxel coords, decimal coords). NMSCD tiene conversores entre todos.

**Base layout planning**: tools que te dejan plotear bases sin pasar por el juego — útil para conceptualizar antes de construir.

**Tracking colaborativo**: hay tools para mantener inventarios cross-save, listas de discoveries, tracking de progreso por expedition.

## Para quién NO es esta herramienta

Si recién arrancas NMS, NMSCD es ruido — usa Assistant primero. NMSCD es para casos específicos.

Si solo quieres respuestas rápidas en el celular durante la sesión, las tools de NMSCD suelen ser web-only (no app nativa). Para fluidez móvil, Assistant es mejor.

Si juegas 100% offline, irrelevante — todas las tools requieren conexión.

## Cómo se usa en la práctica

1. Vas a nmscd.com y miras el catalog principal: cada tool tiene su tile con nombre, descripción corta y ícono.
2. Cliqueas en la que necesitas. Cada tool es página independiente con su UI.
3. Algunas tools requieren input (tipear, pegar coordinates, seleccionar items); otras son solo lectura/exploración.
4. Compartes output (link, copy/paste el resultado al wiki, exportar JSON, etc.) según el flow.
5. No requiere login para la mayoría de las tools — son utilities stateless.

## Limitaciones honestas

**Calidad heterogénea**. Aunque NMSCD pasa por el filtro del team de AssistantNMS, las tools individuales fueron contribuidas por distintos volunteers. Algunas son excellent, otras son básicas o un poco abandonadas.

**Niche**. Si tu use case no encaja en ninguna de las 30+ tools, NMSCD no te ayuda. La cobertura es buena pero no exhaustiva.

**Web-only**. Sin app nativa. Todo vive en el browser.

**Idioma principal: inglés**. Aunque el ecosistema AssistantNMS es multilingüe, muchas tools de NMSCD tienen UI solo en inglés.

**Discoverability dentro del portal**. La home tiene un grid pero buscar exactamente la tool que quieres requiere browsing — no hay buscador potente.

**Dependencia del team principal**. Como Assistant, depende de Kurt Lourens y voluntarios. Si pausan, NMSCD ralentiza.

## Cómo empezar

Vas a nmscd.com y scrolleas el catálogo entero una vez para tener mental map de qué hay disponible. No vale la pena memorizar — pero saber que existe la categoría "calculators" te recuerda volver cuando necesitas una.

Guárdalo en marcadores. Cuando estés en una situación que Assistant no cubre (por ejemplo, generar markup para una page del Fandom), abres NMSCD y buscas.

Si te topas con una tool útil que no está en NMSCD, considera contribuir — el repo de AssistantNMS acepta PRs y suele integrar tools terceras con permiso del autor.
