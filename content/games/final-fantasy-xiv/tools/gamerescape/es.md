## Qué es

Gamerescape's FFXIV Wiki (ffxiv.gamerescape.com) es un wiki MediaWiki community-edited por Gamer Escape Network, una empresa que opera múltiples wikis de gaming. Para FFXIV específicamente, el wiki está activo desde 2010 (la versión original 1.0) y sobrevivió el reboot.

Cubre:

- **Quests**: walkthroughs detallados con prerequisites, rewards, NPCs involucrados.
- **Dungeons / Trials / Raids**: walkthroughs con mecánicas explicadas.
- **NPCs**: páginas dedicadas con dialogue snippets, ubicaciones, quest associations.
- **Items**: stats, vendors, drops, uses (más narrativo que Garland Tools).
- **Lore**: páginas extensas sobre regiones, beast tribes, primals, racial history.
- **Music tracks**: orchestrion rolls con linkeo a YouTube.

Es free, sin login (login para editar).

## Qué problema resuelve

Para info que es narrativa o requiere contexto, Garland Tools y Lodestone son insuficientes:

- "¿Cuál es el lore de este boss?" — Gamerescape tiene una página entera sobre Hraesvelgr.
- "¿Cómo se ejecuta esta side quest stuck?" — walkthrough paso a paso.
- "¿Qué orchestrion roll dropea de este dungeon?" — lista de music tracks por content.
- "¿De qué expansion es este NPC?" — context histórico claro.

Para queries informativas, Gamerescape es referencia complementaria a Garland Tools (técnico) y Lodestone (oficial).

## Diferenciación vs FFXIV Wiki (consolegameswiki / fandom)

FFXIV tiene varios wikis. Gamerescape es el dominante y mejor mantenido en inglés. Hay también:

- **Final Fantasy Wiki** (en fandom.com): cubre toda la franquicia FF; para XIV es menos profundo que Gamerescape.
- **JP Wiki** (ja.fandom): wiki japonés bien editado pero en japonés.
- **FFXIV Wiki** (consolegameswiki, abandonado): legacy site.

Para inglés serio, Gamerescape es la opción. El wiki community oficial (`finalfantasy.fandom.com`) cubre toda la franquicia pero con menos foco editorial en XIV.

## Para qué la usa la gente

**Walkthroughs de quests stuck**: estás stuck en una blue-quest o side quest. Gamerescape te da el step-by-step.

**Lore deep-dive**: estás scrolleando entre MSQ y quieres más context sobre un personaje secundario, una primal o una región. Gamerescape tiene páginas dedicadas.

**Identificar music tracks**: escuchás música in-game que te gusta. Lo buscas por dungeon/raid y encuentras el nombre del orchestrion roll y cómo conseguirlo.

**Verificar quest chains históricos**: quieres saber qué quests llevan a tal beast tribe questline o cómo unlock cierto job. Gamerescape lista los prerequisites.

**Cross-checking con Garland Tools**: cuando Garland te da data pero quieres context, Gamerescape complementa con la narrativa.

## Para quién NO es esta herramienta

- **Análisis técnico de combate**: nada acá. FFLogs/Etro/XIVAnalysis.
- **Lookup ultra-rápido de stats**: Garland Tools es más eficiente para queries puntuales.
- **Mecánicas de Savage fight**: Gamerescape suele cubrir lo basics; para detail completo necesitas guides en YouTube (MTQ Capture, Hector Hectorson) o The Balance.
- **Edición en vivo durante raid**: como referencia mid-fight es lenta. No la abrirías durante el pull.

## Cómo se usa en la práctica

1. Andá a [ffxiv.gamerescape.com](https://ffxiv.gamerescape.com).

2. La barra de búsqueda top: tipeás el nombre de quest, NPC, dungeon, item.

3. Para quests: la página típica incluye sección "Walkthrough" paso a paso, "Rewards" detallados, prerequisites.

4. Para dungeons/raids: la página describe boss mechanics en lenguaje natural (no tan detallado como un video guide, pero útil para refresher rápido).

5. Para lore: las páginas de personajes secundarios típicamente tienen toda su aparición a lo largo del MSQ documentada.

6. Para music: cada dungeon/raid tiene la lista de tracks que toca, con linkeo a YouTube y orchestrion roll source.

## Limitaciones honestas

**Walkthroughs sin video**: a diferencia de YouTube guides, Gamerescape es solo texto. Para mecánicas visuales complejas, un video sigue siendo más eficiente.

**Calidad de páginas inconsistente**: como es community-edited, algunas páginas (quests populares, raids recientes) están muy completas; otras (NPCs obscuros, sidequests viejas) están stubs.

**Updates pueden atrasar**: post-patch, contenido nuevo puede demorar semanas en quedar bien documentado. Para Live Letter info, mejor Lodestone.

**No tiene database queries**: no puedes filtrar "items que dropean en zone X con sub-stat Y". Para eso Garland Tools.

**Heavy on ads**: Gamer Escape Network monetiza con ads, lo cual hace la experiencia algo pesada visualmente. Adblock recomendado.

**No oficial**: a veces lore interpretation se mezcla con dialogue literal. Útil para context, no para citas autoritativas.

## Cómo empezar

1. Andá a [ffxiv.gamerescape.com](https://ffxiv.gamerescape.com). No necesitas login para leer.

2. Buscá un quest stuck o un NPC que te intriga. Probá la profundidad típica.

3. Para dungeons: tipo "The Aetherfont" → ves walkthrough, mechanics overview, music tracks, drops.

4. Para lore deep-dive: tipo "Hydaelyn" o "Zodiark" → páginas extensas sobre los Mother/Father Crystals.

5. Usá como complemento a Garland Tools: Garland te da el "qué" técnico, Gamerescape el "por qué" narrativo.

6. Si encuentras algo desactualizado o falta, puedes contribuir editando (login requerido) — pero la mayoría de usuarios solo leen.
