## Qué es

The Lodestone (na.finalfantasyxiv.com/lodestone) es el portal web oficial de FFXIV mantenido por Square Enix. Existe desde el lanzamiento original en 2010 y se mantuvo durante el reboot. Funciones principales:

- **Perfil de personaje**: tu Lodestone ID público con achievements, gear actual visible, mounts/minions owned (parcialmente).
- **Free Company search**: directorio de FCs con apertura abierta, filtros por servidor y datacenter.
- **Linkshell search** (más limitado en uso comunitario).
- **Character search**: buscar a otro jugador por nombre + servidor.
- **News & Patch Notes**: el feed oficial de Square Enix con patch notes completos, hotfixes, mantenimiento anunciado, y Lodestone-only stories.
- **Eorzea Database**: items, recipes y NPCs documented oficialmente (más limitado que Garland Tools pero canónico).

Es gratis y no requiere login para la mayoría de funciones (sí para postear en forums oficiales o configurar tu perfil).

## Qué problema resuelve

Para FFXIV, herramientas third-party (FFLogs, Etro, Universalis) dependen del Lodestone como fuente de verdad — pero hay flujos donde no hay third-party suficientemente confiable y necesitas el Lodestone directo:

- **Verificar el achievement de un jugador**: el Lodestone muestra achievements y títulos visibles. Útil para apply a static donde piden "Ultimate Legend" o "World First" titles.
- **Confirmar patch dates y schedules de mantenimiento**: la news oficial es el único canal autoritativo. Datos third-party pueden estar atrasados.
- **Free Company recruitment**: el directorio oficial sigue siendo el canal donde gente busca FCs.
- **Citar info oficial**: cuando hay debate sobre rate de drop, gear ilvl exact, etc. — el Lodestone es la fuente que cierra el argumento.

## Diferenciación vs Gamerescape y Garland Tools

- **Lodestone**: oficial, autoritativo, pero limitado en datos navegables (no puedes filtrar items por sub-stat fácil).
- **Gamerescape**: wiki community-edited con lore, quests, dungeon walkthroughs profundos.
- **Garland Tools**: database con filtros granulares para items, recetas, gathering nodes.

Los tres se complementan: Lodestone para news y character verification, Gamerescape para deep-dive en quests/lore, Garland Tools para queries técnicas sobre items.

## Para qué la usa la gente

**Leer patch notes**: los patch notes oficiales se publican en Lodestone antes de aparecer en cualquier news third-party. Si quieres el changelog literal de un balance change, vas acá.

**Verificar achievements y títulos**: estás considerando alguien para tu static. Buscás su nombre en Lodestone, ves sus achievements visibles, jobs maxeados, y mounts.

**Free Company hunting**: filtrás por datacenter + tu zona horaria + actividad reciente, consigues lista de FCs reclutando.

**Confirm news date / event start**: cuando un seasonal event como Heavensturn arranca, la fecha exacta está en Lodestone. No te confíes solo en third-party news.

**Mostrar tu personaje a un amigo**: el Lodestone link es la forma estándar de mostrar tu char fuera del juego.

## Para quién NO es esta herramienta

- **Análisis de combate**: Lodestone no tiene parser ni logs. Para eso es FFLogs.
- **Database queries profundas**: para "qué items dropean del Lich + sus sub-stats", Lodestone es pobre. Garland Tools mucho mejor.
- **Comparativas y planning**: Lodestone solo muestra estado actual de tu char. No planificás BiS acá.
- **Quien solo juega Free Trial**: los achievements pueden estar limitados en visibilidad para chars de Free Trial dependiendo del setting.

## Cómo se usa en la práctica

1. Andá a `na.finalfantasyxiv.com/lodestone/` (cambiá `na` por tu región: `eu`, `fr`, `de`, `jp`).

2. Para verificar a otro jugador: **Character Search** → escribes nombre + servidor.

3. Para encontrar FC: **Free Company Search** → filtros por datacenter, tag de recruitment, miembros.

4. Para leer news: la pagina principal lista las latest. Filtros para Topics, Updates, Notices, etc.

5. Para ver tu propio perfil: login con tu Square Enix account, ve a "My Page".

6. Para postear en oficial forums (raramente útil para community engagement — el discord/reddit es más activo): forums.finalfantasyxiv.com.

## Limitaciones honestas

**UI desactualizada**: el Lodestone se ve del 2010 y la navegación es lenta. Square Enix prioriza otras funcionalidades del juego sobre rehacer el portal web.

**Datos limitados visibles**: Lodestone muestra una fracción del estado del char (gear principal sí, todo el inventario no). Para análisis profundo usas herramientas third-party.

**Update lag tras patch**: a veces toma horas que el Lodestone sincronice tus achievements post-clear. No esperes verificación instantánea.

**Sin API oficial pública**: third-party tools dependen de scrapeo HTML del Lodestone, lo cual es frágil — cuando Square Enix cambia un selector, las tools se rompen temporalmente.

**Search engine débil**: buscar por achievement específico, jobs particulares o gear ilvl es difícil. La búsqueda primaria es por nombre + server.

**No es el canal de comunicación principal**: aunque sea oficial, los anuncios importantes (Live Letter, balance previews) viven en YouTube/Twitter, no en Lodestone forums.

## Cómo empezar

1. Andá a [na.finalfantasyxiv.com/lodestone/](https://na.finalfantasyxiv.com/lodestone/) (o tu región).

2. Login con tu Square Enix account → my page. Verificás que tu char está vinculado.

3. Configurá tu perfil visible (achievements, jobs, etc.) si quieres que sea público.

4. Marcalo en favoritos para chequear patch notes cada vez que salga un parche.

5. Para verificar a otro jugador, **Character Search** → name + server. Compará con su link de FFLogs/Lodestone.

6. Si buscas FC, **Free Company Search** → ajusta filtros y revisá las opciones top.

7. Si tu third-party tool (Etro, FFLogs) muestra datos raros, el Lodestone es la source of truth de qué dice el juego oficialmente.
