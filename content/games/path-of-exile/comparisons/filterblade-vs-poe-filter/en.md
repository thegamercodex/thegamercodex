---
title: FilterBlade vs PoE Filter — which loot filter generator to use
description: Short comparison between the two most-used web tools for customizing PoE loot filters.
---

Filtering loot well is one of PoE's non-obvious skills: the difference between an efficient mapping session and a frustrating one. Two web tools dominate the space: **FilterBlade** (NeverSink's official visual editor) and **PoE Filter** (a minimalist alternative generator). They have different philosophies worth understanding before you pick.

## Philosophy

**FilterBlade** is the control panel for customizing NeverSink's filter — the most-used and most-maintained filter in the PoE community. It's built for complete coverage: every drop in the game, organized by strictness tiers (Soft, Regular, Semi-Strict, Strict, Very Strict, Uber-Strict). You're choosing how much to hide within a system that assumes you want to see a lot and filter aggressively when needed.

**PoE Filter** starts from the opposite philosophy: a clean, minimal filter that respects the game's original visual aesthetic. Fewer neon colors, fewer cluttered icons, fewer intrusive sounds. It's the filter for someone who prefers to see the game's loot "as it is" but with discreet help on what matters.

## Customization

FilterBlade has the most complete customization UI: every item category editable per tier, with real-time preview, sound packs, drop sounds, mini-map icons, beams, and granular override of any specific rule. If you want to change exactly how a Headhunter looks when it drops (color, size, sound, icon), you do it in three clicks.

PoE Filter offers more limited but sufficient customization for most: configurable drop tier, native poe.ninja integration so tiers adjust to real per-league market value, and a simpler UI. If you don't need to tweak 50 specific rules, you reach a good filter with less cognitive load.

For filter builders who want total control, FilterBlade wins. For players who want "good enough" fast, PoE Filter wins.

## Maintenance and league cycle

NeverSink updates his base filter every league and significant patch, and FilterBlade reflects those changes automatically. When a league adds new items or changes drop rates, the filter supports it almost immediately. That's the upside of FilterBlade being the official tool for a project a single dev (NeverSink) maintains as a priority.

PoE Filter also updates but has less community pressure behind it. The team is smaller and updates can take longer after a big patch. The trade-off is that its simplicity means fewer things to break when GGG changes something.

## Which one?

- **If you play endgame seriously and want the game's most complete filter** → FilterBlade. It's the de facto standard for a reason.
- **If you're starting out and want a clean, discreet filter** → PoE Filter. Less visually overwhelming.
- **If native poe.ninja integration matters to you so the filter adjusts to real value** → PoE Filter. It's a distinctive feature.
- **If you want custom sound packs and extreme granular control** → FilterBlade. Only wins here.

As with many PoE comparisons, **trying both takes about 10 minutes each**. Both are web tools that generate a `.filter` file you paste into your PoE folder. Switching is trivial.
