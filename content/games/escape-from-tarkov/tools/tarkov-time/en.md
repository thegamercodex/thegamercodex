## What it is

What Time Is It In Tarkov Right Now (whattimeisitintarkovrightnow.com) is a minimalist web app that displays the current in-raid Tarkov time in real time and the next day/night transition. Tarkov has an accelerated day/night cycle (7x faster than real time), and this tool calculates the current game time from your local time.

## What problem it solves

Tarkov doesn't display the current time in the main menu — you only see deployment time when you pick a raid and enter the lobby. If you want to plan without losing time, this clock quickly tells you whether to wait for a day raid or go now to catch the night.

## Differentiation

It's a unique category — there's no established competitor doing the same. tarkov.dev and other sites show time but require more navigation. Here you land and the time is on screen at pixel 1.

## What people use it for

- **Plan day raids** for maps where visibility helps (Shoreline, Streets).
- **Wait for night** for stealth raids with NVG where darkness gives an edge.
- **Event timing** that only occurs at specific hours (e.g. cultists at night).
- **Team coordination** when the plan depends on a specific in-game hour.

## Who this tool isn't for

If you don't care about the day/night cycle and queue raids when you can, this is overkill. If you want more sophisticated in-game time tracking with events, some overlays cover that integrated.

## How it's used in practice

1. Visit whattimeisitintarkovrightnow.com.
2. The page shows the current in-raid time and the next day/night transition.
3. Bookmark or open it on a second screen while planning a raid.
4. Adjust your deployment timing if you want a specific light condition.

## Honest limitations

- **Time only**: doesn't handle events, calendars, or anything more complex.
- **English only**: the site is minimal text so the barrier is low.
- **Unofficial**: relies on the in-game day/night cycle formula, which BSG rarely changes but in theory could break with a patch.
- **No mobile app**: web only. The site is responsive so it works in mobile browsers.
