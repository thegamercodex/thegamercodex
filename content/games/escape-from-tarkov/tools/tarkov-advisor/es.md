## Qué es

Tarkov Advisor es una web app companion para Tarkov que combina tracking de tasks, planner de upgrades del hideout, sistema de stash management para inventariar items físicamente y un tier list por valor por slot que ayuda a decidir qué dejar en raid. Reporta 80,000+ usuarios activos. Login con Google. Datos vienen de la API de tarkov.dev, con updates cada hora.

## Qué problema resuelve

Tracking de progreso en Tarkov requiere varias dimensiones simultáneas: tasks, items FIR, hideout, stash y meta items. Tarkov Advisor agrupa todo en una sola UI con cross-linking entre componentes. El stash management es único — podes inventariar lo que tienes y ver qué se necesita vs qué te sobra.

## Diferenciación

Frente a TarkovTracker (open-source, minimalista, mejor team sync), Tarkov Advisor agrega capas que Tracker no tiene: tier list de items por valor de slot (ROI por espacio de stash), planner gráfico de hideout con dependency tree y stash inventory tracking. La trade-off es closed-source y team sync menos refinado.

## Para qué la usa la gente

- **Tracker visual de tasks y hideout** con UI más amigable que el minimalismo de Tracker.
- **Tier list por value-per-slot** para decidir qué loot mantener cuando el stash está lleno.
- **Stash management** para inventariar qué tienes guardado y planificar usos.
- **Planner de hideout** visual con dependency tree (qué desbloquea qué).
- **Comparación de precios de items** integrada con datos de tarkov.dev.

## Para quién NO es esta herramienta

Si valoras open-source y team sync impecable, TarkovTracker es la opción. Si solo quieres datos crudos rápidos sin layout amigable, tarkov.dev directo. Y si tu wipe es solo y casual sin obsesionar sobre value-per-slot, Tarkov Advisor es overkill.

## Cómo se usa en la práctica

1. Visita tarkovadvisor.com y login con Google.
2. El dashboard ofrece quest tracking, hideout planner y stash inventory como módulos separados.
3. Para tier list, el módulo Items te muestra ranking por value-per-slot con filtros por categoría.
4. Para stash, podes marcar items que tienes y el sistema te dice qué hideout upgrades puedes hacer ahora.
5. Las features avanzadas (sync, hideout planner avanzado) requieren login; el search de items y precios funciona sin login.

## Limitaciones honestas

- **Closed-source**: si valoras transparencia o quieres contribuir, TarkovTracker es preferible.
- **Solo en inglés**: sin localización.
- **Team sync menos maduro**: existe pero TarkovTracker tiene mejor implementación.
- **Depende de tarkov.dev**: si la API source cambia o falla, Tarkov Advisor se ve afectado.

## Cómo empezar

Visita tarkovadvisor.com. Login con Google para features avanzadas. Buscar items y precios funciona sin login si solo quieres probarlo.
