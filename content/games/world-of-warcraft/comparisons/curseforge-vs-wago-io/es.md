title: CurseForge vs Wago.io — el incumbent vs el desafiante moderno
description: Comparativa flagship entre el addon repository históricamente dominante y la alternativa moderna privacy-friendly. Catálogo masivo vs UX limpia, app con ads/telemetría vs app lightweight, generic addons vs WeakAuras specialization.
---

El ecosistema de addons en WoW está dividido. **CurseForge** es el incumbent histórico — 15+ años, catálogo masivo, propiedad de Overwolf desde 2020. **Wago.io** apareció como respuesta a la deterioración de UX post-Overwolf y se volvió el default para WeakAuras y para players que valoran privacy. Esta no es una elección binaria: muchos players serios usan ambos según el addon.

## El cambio que disparó Wago

CurseForge era estándar undisputed pre-2020. Cuando Overwolf compró la plataforma, introdujo cambios significativos:

- **App desktop obligatorio** para auto-updates fluidos (antes habían alternativas third-party).
- **Ads** dentro del app y la web.
- **Telemetría** del comportamiento del usuario.
- **Cambios de monetization** para authors (que algunos rechazaron).

Wago.io capturó la frustration de la community que pedía un repositorio sin esa friction. El timing coincidió con WeakAuras volviéndose central en raid setups (BfA → SL → DF), lo cual le dio a Wago un nicho específico para crecer: ser el lugar canónico de WeakAuras.

## WeakAuras: el nicho que Wago dominó

WeakAuras es uno de los addons más importantes en WoW — sistema de display custom con scripts, usado para tracking de buffs, cooldowns, mechanics de boss. Cada raid tier produce docenas de WeakAuras específicos. Wago se especializó en este caso:

- **Import codes con version tracking**: cuando el author actualiza, tú recibes notification.
- **Browse por spec/encounter** con filtros que CurseForge no replica para WeakAuras.
- **URL sharing limpio**: pegas un link y el receiver importa directo con un click.
- **Community comments y ratings** por aura específico, no por package.

Para players que viven en WeakAuras (raiders mythic, M+ pushers), Wago se volvió obvious choice.

## CurseForge: lo que sigue ganando

A pesar de las pérdidas de mindshare, CurseForge mantiene ventajas concretas:

- **Catálogo más grande**: 15+ años acumulados. Muchos addons obscuros pero todavía funcionales solo viven ahí.
- **Archive histórico**: addons abandonados pero útiles (mostly classic-era) están preservados.
- **Soporte de tooling third-party legacy**: integrations con community tools que asumieron CurseForge como única fuente.
- **Mods de other Blizzard games**: si juegas también HotS o Overwatch (mods limitados), CurseForge cubre.

## El factor app

CurseForge App (Overwolf): integra varios juegos, tiene ads, requires login. Pesado pero feature-rich.

Wago App: minimalista, focus exclusivo en WoW addons, lightweight, sin ads. Más rápido de abrir y usar.

Para players que solo juegan WoW, el Wago App es estricta mejor. Para players multi-juego (CurseForge cubre Minecraft, ESO, otros), el CurseForge App tiene more value despite los ads.

## Manual install: ambos lo permiten

Importante para puristas que prefieren cero apps: ambos sitios permiten manual download de zips para extraer al `Interface/AddOns` folder.

CurseForge degradó la UX de manual install post-Overwolf (más clicks, throttling de downloads sin app). Wago mantuvo manual install como first-class citizen. Para players que no quieren ningún app desktop, Wago es más friendly.

## Catalogo overlap

Muchos addons populares están publicados en ambos sitios. Los authors suelen mantener mirrors. Esto significa que para los top 20 addons (BigWigs, WeakAuras, Plater, Details, ElvUI, Bartender, etc.) elegir uno u otro no afecta access.

La diferencia surge en addons mid-popularidad: algunos solo en CurseForge (los más viejos sin migration), algunos solo en Wago (los más nuevos sin cross-publish).

## Decision matrix

| Caso | Plataforma |
|---|---|
| WeakAuras de current raid tier | Wago |
| Addon mainstream (Details, BigWigs, etc.) | Cualquiera — están en ambos |
| Addon obscuro pre-2020 | CurseForge |
| Quieres cero ads/telemetría | Wago |
| App multi-juego (Minecraft + WoW + ESO) | CurseForge |
| Sharing rápido de UI con guild | Wago |
| Archive histórico de addons abandonados | CurseForge |

## Recomendación práctica

Para la mayoría de players activos en 2026, **Wago como default + CurseForge como fallback** para addons que no están en Wago. Este pattern es estándar entre raiders y M+ pushers.

Si juegas WoW casualmente con 5-10 addons, puedes usar uno u otro sin mucha diferencia. Si tu setup es complejo (30+ addons, WeakAuras packs, custom Plater profiles, multiple specs), Wago va a ser más eficiente para gestionar.

Ambos son free. No hay razón técnica para no tener cuentas en ambos.
