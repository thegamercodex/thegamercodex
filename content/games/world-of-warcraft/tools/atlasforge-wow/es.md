## Qué es

AtlasForge cubre dos versiones de WoW Classic en `atlasforge.gg/wow-classic` (Season of Discovery) y `atlasforge.gg/wow-cataclysm` (Cataclysm Classic). Combina mapa interactivo, armory de characters, weapon/item database y guías editoriales.

Free tier sin paywall. Ads moderadas. Maintained por equipo dedicado.

## Qué problema resuelve

Classic players con multiple personajes en Season of Discovery y Cataclysm necesitan armory para verificar gear, mapa para localizar quests/elite mobs/rare spawns, y guías para optimization. Tener tabs separados de Wowhead, Icy Veins y un map tool es friction.

AtlasForge consolida estos en una sola UI por versión, con cuenta unificada para tracking cross-character.

## Diferenciación

Contra Wowhead gana en UX moderna y mapa visual mejor. Pierde en database depth — Wowhead es la referencia exhaustiva con 20 años de community contributions.

Contra Icy Veins: AtlasForge tiene mapa + armory que Icy Veins no implementa. Icy Veins gana en class guides escritas long-form.

## Para qué la usa la gente

**SoD playthrough tracking**: armory y mapa para tu Hardcore/PvP Season of Discovery toon.

**Cataclysm Classic completionist**: rare spawn tracking, achievement mapping.

**Cross-version user**: same plataforma para SoD y Cataclysm.

**Casual lookup**: weapon stats, quest locations.

**Cross-game**: si juegas también Elden Ring, Cyberpunk, etc., misma cuenta.

## Para quién NO es esta herramienta

Si juegas Retail WoW exclusivamente, no aplica — AtlasForge solo cubre Classic versiones.

Si quieres exhaustive database, Wowhead sigue siendo más completo.

Si tu prioridad es class guides escritas, Icy Veins o Wowhead Guides ganan.

## Cómo se usa en la práctica

1. Abre `atlasforge.gg/wow-classic` (SoD) o `wow-cataclysm` (Cata).
2. Crea cuenta gratis para sync.
3. Activa filtros del mapa por tipo (quests, elite mobs, rare spawns).
4. Para armory, ingresa character name.
5. Cross-reference con Wowhead para data exhaustiva.

## Limitaciones honestas

**Solo cubre 2 versiones Classic**: si juegas Wrath Classic o cualquier otra version, AtlasForge no aplica.

**Database menos profunda que Wowhead**: para items oscuros vas a tener que cross-reference.

**Sin character builder per-spec**: armory muestra pero no permite planning de spec.

**Updates pegados a Blizzard patches**: cada SoD phase y Cataclysm patch requiere updates del map.

## Cómo empezar

1. Visita `atlasforge.gg/wow-classic` o `wow-cataclysm` según tu version.
2. Crea cuenta gratis.
3. Empieza con armory de tu character actual para validar que detecta tu gear.
4. Activa filtros del mapa para tu current quest hub.
5. Cross-reference con Wowhead cuando necesites depth en items específicos.
