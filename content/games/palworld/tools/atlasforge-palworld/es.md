## Qué es

AtlasForge cubre Palworld en `atlasforge.gg/palworld` con mapa interactivo de Palpagos (el archipiélago del juego). Markers para Pal spawn locations, dungeons, fast travel points, resource nodes (minerales, plantas) y bosses de syndicate towers.

Free tier sin paywall. Ads moderadas. Cobertura del base game más updates del live service de Pocketpair.

## Qué problema resuelve

Palworld tiene 140+ Pals en spawn locations específicas, 13 syndicate tower bosses, dungeons que rotan diariamente y resource nodes que necesitas para base building. Sin mapa interactivo, encontrar Pals específicos para tu breeding setup es trial-and-error.

AtlasForge resuelve esto con filtros por tipo de Pal, element y location, plus checkboxes para tracking de captured Pals.

## Para qué la usa la gente

**Pal hunting específico**: filtrar por Pal y ver spawn locations exactos.

**Resource gathering**: localizar minerales y plantas para crafting.

**Boss tracking**: ver qué Syndicate towers ya completaste.

**Dungeon farming**: identificar dungeons activos del día.

**Cross-game user**: same account para Palworld + otros 4 juegos AtlasForge cubre.

## Para quién NO es esta herramienta

Si esperas breeding calculator (qué combos producir qué Pal), AtlasForge no tiene esto — busca Palworld breeding tools dedicados.

Si juegas heavily on private server con modded content, el mapa vanilla puede no reflejar tu content.

Si juegas casual sin caring de min-maxing, el mapa es overkill.

## Cómo se usa en la práctica

1. Abre `atlasforge.gg/palworld`.
2. Crea cuenta gratis para sync.
3. Para Pal hunting, search nombre del Pal target en el filter.
4. Marca catches y resources gathered.
5. Para syndicate towers, sigue priority order que sugiere el mapa.

## Limitaciones honestas

**Sin breeding mechanics**: AtlasForge cubre map, no breeding combos.

**Cobertura del DLC variable**: Pocketpair sigue agregando content y AtlasForge tarda en updatear.

**Sin mobile app nativa**: solo web responsive.

**Comunidad chica**: comments y community feedback son menos que en juegos más viejos.

## Cómo empezar

1. Visita `atlasforge.gg/palworld`.
2. Crea cuenta gratis.
3. Empieza con filtros activos solo para Pal type que quieres farmear.
4. Marca catches y vuelve cuando necesites otra round de hunting.
5. Para breeding mechanics, usa tool dedicado de Palworld breeding.
