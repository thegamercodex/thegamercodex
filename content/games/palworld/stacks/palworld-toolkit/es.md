Palworld mezcla captura de criaturas, automatización de base y survival, y cada una de esas capas tiene profundidad oculta: qué Pal sirve para qué tarea, cómo distribuir una base eficiente y qué combinaciones de breeding dan el Pal perfecto. El juego no explica casi nada de eso. Este stack de cinco herramientas convierte la prueba y error en decisiones informadas.

## Cómo se usa

La referencia base es **Palworld.gg**: el Paldex completo con stats, ubicaciones, drops y skills de cada Pal, ideal para decidir a quién capturar y para qué. Cuando necesitas datos más técnicos —recetas exactas, valores internos— **paldb.cc** es la base de datos profunda que complementa.

Para la base, **Palworld Base Planner** te deja diseñar la disposición de estructuras y la asignación de Pals antes de construir, evitando rehacer todo cuando descubres que algo no fluye. Y para conseguir Pals concretos, **xGaming Breeding Calculator** calcula qué combinaciones de breeding dan el Pal con las pasivas que buscas, en vez de cruzar al azar.

Por último, **Nexus Mods** es el hub de mods: quality of life, ajustes de balance y contenido que extiende lo que el juego base ofrece, especialmente útil en partidas largas o en servidores propios.

## Por qué estas cinco

Cada una cubre una capa del juego:

- **Referencia de Pals** → Palworld.gg + paldb.cc
- **Planificación de base** → Palworld Base Planner
- **Breeding** → xGaming Breeding Calculator
- **Mods y QoL** → Nexus Mods

No necesitas las cinco para empezar, pero juntas eliminan casi toda la prueba y error de una partida optimizada. Cada herramienta tiene su análisis completo en el codex.
