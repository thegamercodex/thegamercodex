## Qué es

Mobalytics es una plataforma multi-juego (League of Legends, Path of Exile, PoE 2) con foco en herramientas in-browser. La sección de PoE 2 (`mobalytics.gg/poe-2`) ofrece tier list de builds, builds escritas por creators partner, builds de la community vía planner abierto, y un build tracker para seguir paso a paso el progreso de una build elegida.

El planner web cubre passive tree, equipment priorities, skill gem sockets y atlas tree, y permite compartir builds por URL sin necesidad de instalar Path of Building.

## Qué problema resuelve

Para un player que quiere "una build sólida sin pelearse con software de escritorio", Mobalytics ofrece un workflow completo: encuentras la build en su tier list, la abres, lees gear/skills/passive tree en el browser, y vas siguiendo el build tracker que te marca el progreso step by step a medida que alcanzas items y nodos.

Para creators, Mobalytics es un builder más accesible: un planner web exportable es más amigable para audiencias casuales que un PoB import code. Muchos creators duplican publicación entre Maxroll/sitio propio y Mobalytics para alcanzar lectores que no quieren desktop apps.

## Diferenciación

Frente a Maxroll, Mobalytics gana en accesibilidad para players nuevos: el build tracker es una abstracción amigable que Maxroll no tiene, y el planner web está más optimizado para no-power-users. Maxroll, a cambio, gana en profundidad editorial y curación de builds.

Frente a Path of Building (escritorio), Mobalytics no compite en simulación matemática — es una capa más casual sobre el ecosistema. La regla útil: PoB para validar matemáticamente, Mobalytics para descubrir y seguir builds.

## Para qué la usa la gente

**Tier list rápida pre-league**: la tier list ranquea builds por arquetipo y dificultad. Útil para filtrar de toda la oferta de creators cuál corresponde a tu estilo.

**Build tracker step-by-step**: una vez eliges una build, el tracker te muestra checkboxes por hito (level 30, level 60, primer 6-link equivalent, etc.) con qué hacer en cada uno.

**Planner web sin instalación**: para diseñar una build casual o compartir con un amigo, abrir el planner directo en el browser es más rápido que abrir PoB. URL compartible.

**Browse community builds**: el feed de builds del community (`/community-builds`) muestra creaciones de players sin filtro editorial. Volumen alto pero curación variable — sirve para encontrar combinaciones inusuales.

**Creator profiles**: cada creator partner (Rob2628, Fubgun, ZurawGod, etc.) tiene perfil con todas sus builds publicadas en un mismo lugar.

## Para quién NO es esta herramienta

Si ya usas PoB y estás cómodo, Mobalytics no agrega mucho. El nivel de simulación que cubre es subset del de PoB. Para optimization endgame seria sigues queriendo PoB.

Si buscas guides escritas profundas con análisis editorial, Maxroll rinde más. Mobalytics es más visual y task-oriented (qué hacer ahora) y menos teorético (por qué tal decisión).

## Cómo se usa en la práctica

1. Entras a `mobalytics.gg/poe-2`. Home muestra meta builds del patch vigente, tier list y latest creator content.
2. Tier List → seleccionas dificultad / arquetipo / clase. Click en una build te lleva al detail.
3. Detail page de build: pestañas para Skills, Equipment, Passives, Atlas. Cada pestaña explica el por qué con ilustraciones y notas inline.
4. Activas el Build Tracker (botón "Track this build"). El tracker te lista los pasos hito en sidebar persistente.
5. Para crear tu propia build: Planner (`/planner/builds`). Construyes en el browser, exportas link, compartes.

## Limitaciones honestas

**Solo en inglés**. Sin localización al español.

**Bias hacia builds populares de creators partner**. La tier list y el destacado en home favorecen builds de creators que tienen relación comercial / partnership. No son malas builds, pero no es ranking imparcial.

**Profundidad de simulación menor que PoB**. El planner web cubre lo básico; cuando empiezas a optimizar (DPS exacto contra distintos enemy archetypes, comparación side-by-side de items), te quedas corto y vuelves a PoB.

**Algunas pestañas tienen ads o premium upsell**. La feature de ads-removal y unlock de partes del build tracker requieren subscripción Mobalytics+. Es claramente marcado pero existe.

**Builds del community no están curadas editorialmente**. Cualquiera publica. Espera variación de calidad alta.

## Cómo empezar

No requiere registro para browse. Entras a `mobalytics.gg/poe-2` y exploras. Si quieres Track Builds o publicar tus propias, te creas cuenta gratuita.

Para integrarlo: si eres player nuevo o casual, deja Mobalytics como hub de descubrimiento (tier list, build tracker). Para optimization seria, sigues yendo a PoB y Maxroll. Para casuales, puede ser todo lo que necesitan.
