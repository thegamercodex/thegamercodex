Tracker.gg cubre el flagship caso de stats tracking, pero hay dos alternatives con personalidades distintas. **Blitz.gg** apuesta a feature density: app desktop con overlay rico in-game y post-match analytics profundos. **Stryda.gg** apuesta a gamificación: convierte el grind en challenges concretos con XP, badges y tournaments community.

## Filosofía: analytics vs motivation

Blitz asume que el player es disciplinado y querer profundizar en data. La app desktop carga overlay live durante match y produce summaries detalladas tras cada game. Para coaching post-session — "¿por qué perdí esta engagement?" — Blitz es el destino con accuracy heatmaps, weapon breakdowns y identification de mistake moments.

Stryda asume que el player necesita motivation tangible. En lugar de mostrar stats fríos, asigna challenges: "Land 3 headshots with Wingman in your next match", "Win 2 ranked games this week". Cada completion da XP, badges, level progress. El grind se vuelve game-within-game.

## Setup complexity

Blitz: install de app Windows (50MB+), login, link Apex account, configurar overlay positions. ~5-10 minutos. La app corre background consumiendo ~200MB RAM continuo.

Stryda: cuenta gratuita web, link Apex, listo. <2 minutos. Sin install local, sin RAM persistent.

Para players con setups modestos, Stryda es lighter. Para players que quieren overlay live, Blitz es la única opción.

## El overlay diff

El overlay live de Blitz es feature killer si lo usas. Durante match, ves rank y stats de cada player al spawn, kill counter, accuracy live. Es coaching real-time — cambia decisions tipo "¿pusheo a este enemy?" basadas en data inmediata.

Stryda no tiene equivalent. Las challenges son async — chequeas progress entre matches, no durante.

## El gamification diff

Stryda tiene challenge engine que adapt al skill level del player y rotación de meta. Si tu accuracy es baja, Stryda asigna accuracy challenges. Si juegas predominantemente Pathfinder, challenges se adaptan a su kit. Esta personalización mantiene engagement con improvement durante meses.

Blitz no tiene este layer. Stats fríos, analysis profundos, pero requires disciplined self-coaching para extraer value.

## Comunidad y social

Stryda tiene community tournaments y leaderboards based en challenge completion. Players competentes que disfrutan competition social encuentran value extra.

Blitz es individual-focused. No hay social comparison nativa.

## Cuándo gana cada uno

| Caso | Recomendación |
|---|---|
| Live overlay in-match | Blitz |
| Motivación para grind sostenido | Stryda |
| Coaching post-match profundo | Blitz |
| Setup minimal sin install | Stryda |
| Social compete con friends | Stryda |
| Disciplina self-coaching | Blitz |

## Recomendación

Ambos son free con Premium tiers opcionales. Probarlos cuesta cero. Para players que respondan a goal-based motivation, Stryda es underrated. Para coaching técnico profundo, Blitz es la opción seria — especialmente si ya estás en Diamond+ y quieres squeeze marginal improvement.

Ninguno reemplaza Tracker.gg como foundational tracker. Son add-ons con focus específico — install solo si su angle resuena con tu playstyle.
