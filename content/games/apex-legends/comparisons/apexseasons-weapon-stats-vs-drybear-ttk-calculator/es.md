Las dos herramientas serias de weapon math en Apex representan dos generaciones de la community. **ApexSeasons** es la web tool moderna lanzada post-2023 con UX visual y filtros granulares. **Drybear's TTK Calculator** es el Google Sheet construido por Christopher Mykles en febrero 2019, histórico authoritative source que la community usa como reference desde el day-one.

## UX moderna vs spreadsheet raw

ApexSeasons.online tools/weapon-stats es web UI: tablas filterables, side filter por armor tier (white/blue/purple/red), comparison view side-by-side, charts visuales. Diseñado para quick lookups durante session — 30 segundos para encontrar "qué weapon mata más rápido contra purple armor".

Drybear es Google Sheets: multiple tabs (por weapon class), formulas visibles, math expuesta. Para lookup quick es más lento — hay que navegar tabs, leer cells. Pero la math está al desnudo — puedes Make a Copy y customize para casos edge.

## Authority y community trust

Drybear es citado en Reddit posts, video guides y discussions de balance desde 2019. "Source: Drybear TTK Calc" es shorthand que la community competitive reconoce. Tiene credibility legacy que tools nuevos no replicate fácil.

ApexSeasons es solid pero menos established. Editorial team mantenido vs single creator (Drybear), lo cual da más reliability de update pero menos individual brand.

## Update cadence

ApexSeasons: editorial team con cadence post-patch consistente, usually 1-3 days para reflect balance changes.

Drybear: single maintainer. Christopher Mykles tiene otros projects además del Sheet, así que lag tras patches puede ser 1-2 semanas o más para changes minor.

Para data fresca post-patch, ApexSeasons gana.

## Customization

Drybear permite Make a Copy del Sheet y editar formulas, attachments, modifiers manualmente. Útil para theorycrafters que quieren explorar "qué pasaría si nerfean X stat por Y%" o calculate ability multipliers que el spreadsheet base no incluye.

ApexSeasons no expone formulas directamente — los filters son los limits de lo que puedes query.

## Cuándo gana cada uno

| Caso | Recomendación |
|---|---|
| Quick TTK contra armor tier | ApexSeasons |
| Verificar claim citado en Reddit | Drybear |
| Comparativa visual 2-3 weapons | ApexSeasons |
| Customize math con modifiers raros | Drybear |
| Update fresco post-patch | ApexSeasons |
| Source authoritative para balance debate | Drybear |
| Mobile lookup rápido | ApexSeasons |
| Theorycrafting profundo | Drybear |

## Recomendación

Para uso diario, ApexSeasons como default por la UX. Para deep-dive theorycrafting o cuando necesites citar source authoritative, Drybear queda en bookmark complementario.

Bookmarkear ambos cuesta nada. La elección entre uno u otro depende del momento y question — no son substitutos directos.
