Los dos pilares de stats tracking en Apex Legends cubren preguntas distintas. **Tracker.gg** está construido alrededor de **tu** performance: profile individual con stats agregados, leaderboards históricos, overlay in-game opcional vía Overwolf. **Apex Legends Status (ALS)** está construido alrededor del **juego**: meta data agregada (pick rates, win rates), interactive map con loot tiers y server status en tiempo real. La elección no es entre uno u otro — la mayoría de players serios usa ambos.

## Personal vs meta: la diferencia core

Tracker.gg responde "¿cómo voy yo?". Subes tu IGN, obtienes decadas de matches procesados con KD, win rate, kills per minute, damage per match. Si juegas ranked y quieres saber tu trajectory, comparativa con otros profiles, o detectar smurfs en tu lobby, este es el destino.

ALS responde "¿qué está pasando en el juego?". Pick rates por legend al top tier, win rate de cada composición de team, qué meta domina post-patch. Si te preocupa elegir legend basándote en meta competitivo o entender por qué cierto pick está overrepresented esta semana, ALS es la fuente.

## Setup y onboarding

Tracker.gg requires opcionalmente Overwolf para el overlay in-game. Sin Overwolf, la versión web funciona perfecta — solo pierdes el overlay live. Free tier tiene ads visibles; Premium ($5/mes) los quita.

ALS no requiere nada — pure web, sin login, sin app. Solo abres la URL y la data está ahí. Ads presentes pero menos intrusive que Tracker.gg.

Para friction inicial, ALS gana. Para feature depth on your stats, Tracker.gg gana.

## El interactive map de ALS

Esta es la feature killer de ALS que ningún otro tool free replica con la misma profundidad. Para cada mapa active de current rotation, un mapa interactivo con tier de loot color-coded por POI: gold para high-tier zones, blue para mid, white para low. Permite planear drops específicamente vs adivinar.

Tracker.gg no tiene equivalent. Si necesitas info de map, ALS es obligatorio.

## El overlay de Tracker.gg

Esta es la feature killer de Tracker.gg vía Overwolf. Al iniciar Apex, el overlay activa automáticamente. Durante match, ves rank y stats core de cada player en tu lobby — útil para identificar pros, smurfs, o teammates con KD alta antes de comprometerte al engage.

ALS no tiene overlay capability. Si quieres live in-match stats, Tracker.gg es la opción.

## Workflow recomendado

Pattern típico de player serio:

1. **Pre-session**: Abrir ALS, chequear current meta legends (pick rates) + interactive map del current rotation.
2. **Durante session**: Overlay de Tracker.gg activo automáticamente con player stats live.
3. **Post-session**: Tracker.gg profile para ver tu progress, KD trends, session summary.

Tener ambos open o bookmarkeados es estándar entre Diamond+ players.

## Limitaciones honestas

**Tracker.gg**: ads agresivos sin Premium, Cloudflare gating ocasional, dependencia de cuenta EA pública.

**ALS**: single maintainer (Hugo Derave) sin team backup, API paywalled más allá de free tier, sin localizaciones.

Ninguno reemplaza al otro. La trampa es elegir uno solo y operar como si fuera suficiente.
