## Glosario WuWa (usar terminología correcta en el contenido)
- **Resonators** = personajes jugables. **Forte** = talentos. **Resonance Liberation** = ultimate.
- **Echoes** = monstruos capturados, se equipan como artefactos/relics. 5 slots, Cost 1/3/4, presupuesto 12 Cost. Main stat + substats + **Sonata effect** (set bonus 2pc/5pc) + Echo Skill (Tacet Mark).
- **Weapons**: 5 tipos — Broadblade, Sword, Pistol, Gauntlet, Rectifier.
- **Convene** = pull gacha. **Astrite** = currency tipo primogem. **Lustrous/Radiant Tide** = tickets. Pity garantizado 5★. **Resonance Chain** (Sequence S0–S6) = constelaciones.
- **Waveplate** = stamina/resina. **Tacet Fields / Tacet Discords** = dominios de farmeo. **SOL3 Phase** = exploración/mapa.
- Endgame: **Tower of Adversity** (abyss), **Whimpering Wastes**, **Holograms** (boss challenges).
